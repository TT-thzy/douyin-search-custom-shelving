版本：v4.2

状态：Active（项目统一生产标准，替代 v3.x / v4.0 / v4.1）

## 说明

本模板是 WDSS 视频生产的标准骨架，基于 **Seedance 2.0**（即梦/豆包），提示词按 **seedance-prompt-zh** 技能撰写，适用于全部视频脚本（VIDEO-xxx）。

- 生产链路：先按《视频模板.md》写 30 秒四拍脚本与旁白（≤ 120 字）→ 再按本模板转成 2 段 Seedance 提示词
- 成片固定 **30 秒 = 2 段 × 15 秒直出**（Seedance 单段上限 15 秒）
- 结构固定 4 拍：**钩子（0–3s）→ 痛点（3–15s）→ 方案（15–26s）→ 决策+CTA（26–30s）**，映射为 C1/C2 两段
- **画面一律写实优先；白模只做独立示意镜头，禁止与写实空间参考图混用**（2026-08-11 实操修订）
- **每个生成计划是独立上下文：Prompt 02 不记得 Prompt 01，每段提示词必须自包含**（2026-08-11 实操修订）

## 二、30 秒叙事结构 → 2 段映射（固定）

| 段 | 时间 | 内容 | 对应拍 | 单段任务 |
| -- | ---- | ---- | ------ | -------- |
| C1 | 0–15s | 钩子 + 痛点 | 拍1 + 拍2 | 15 秒内讲完"问题是什么 + 为什么" |
| C2 | 15–30s | 方案 + 决策 + CTA | 拍3 + 拍4 | 15 秒内讲完"怎么办 + 怎么判断" |

> 每段只放一个叙事单元，可含两三个快切小节；单段内每 5 秒一个推进。

## 三、段间一致性规则（实操铁律，2026-08-11 新增）

> 实操教训：Seedance 每次生成都是**独立上下文**，Prompt 02 无法读取 Prompt 01 的任何信息。文字写"承接 Prompt 01 / 与上段一致 / 像同一条视频继续"均无效。段间一致性只能靠**共享素材** + **自包含描述**。

1. **每段 Prompt 必须自包含**：场景、层高、结构、光线、色温、镜头、动作、音频、负面约束，**每一段都完整重写一遍**。禁止"同上、与上段一致、承接上段"等表述。
2. **一致性靠共享素材，不靠文字**：
   - 两段共用同一张 `@图片1` 空间参考图（同一间仓库）
   - 两段共用同一张 `@图片2` 风格参考图（同一视觉语言）
   - C2 首帧 = C1 末帧截图（图生视频），这是唯一的"承接"载体
3. **画面一致性要素要写进每段**：同一仓库、同一光线、同一色调——这些必须作为文字描述出现在每一段 Prompt 里，而不是"参照上一段"。
4. **旁白同样自包含**：每段 Prompt 的音频部分写本段自己的旁白全文，不引用其他段。

## 四、参考图使用规则（实操铁律，2026-08-11 新增）

> 实操教训：白模（浅灰工程示意底）与写实空间参考图同时引用时，模型会把白模灰底混进仓库背景，画面杂乱、生成内容错乱。以下规则强制遵守：

1. **写实优先**：C1、C2 主画面全部使用写实仓库画面（`@图片1` 空间 + `@图片2` 风格），方案、对比全部用写实画面表达。
2. **白模独立使用**：确需白模示意（如"三类货分区"）时，单独生成一段独立示意镜头——纯灰底、**不引用空间/风格参考图**，后期以分屏或插帧方式切入成片。
3. **同条提示词只出现一种视觉语言**：写实空间图与白模示意图禁止出现在同一条提示词里。
4. **方案演示用"动作"代替"图"**：用叉车放货、货架安装、货物上架等写实动作表达方案，比静态示意图更稳、更不易乱。
5. **分屏对比也用写实**：改造前/后对比用同一仓库的写实画面左右分屏，不用白模做对比。

## 五、Seedance Prompt 规范（seedance-prompt-zh，必读）

每条提示词按以下结构撰写，缺一不可：

### 5.1 @ 引用语法

- `@图片1`：空间参考图（写实仓库场景），每段必用
- `@图片2`：风格参考图（写实视觉语言统一）
- C2 另传 `@图片3`：C1 末帧截图（作为首帧参考，图生视频）
- 每个引用必须说明用途，不允许只写"参考@图片1"
- 白模不是常规引用素材；确需时走"独立示意镜头"流程（见第四节），**不写进主提示词的 @ 引用**

### 5.2 分时段描述（必写）

单段 15 秒拆 3 个时段，每时段只做一件事：

```
0–5秒：...
5–10秒：...
10–15秒：...
```

### 5.3 8 要素 + 音频

```
[镜头类型] [主体] [主要动作] [运镜] [场景/背景] [光照/风格] [质量控制] [负面约束]
音频：旁白原文 + 环境音 + 音画同步要求
```

### 5.4 去 AI 化要点（每条必须遵守）

1. 画面语言用"实拍感"词：纪录片质感、纪实摄影、手持微晃、自然混合光（窗光+日光灯）、中性偏暖色温、轻微胶片颗粒。
2. 加真实环境细节：地面划痕与油污、托盘磨损、货架轻微旧化、角落线管、灰尘颗粒、包装轻微破损。
3. 避免"AI 完美"：不做完美对称构图、不做无人机式顺滑运镜、允许轻微构图瑕疵与透视失真。
4. 负面约束必带：无3D渲染感、无塑料光泽、无过度饱和、无完美对称、无CG质感。
5. 画面默认无人出镜：优先用叉车/货物叙事；确需人物时共用同一人物参考图，禁面部与手部特写、多人同框。

```
5–10秒 【痛点展开：1 个具体动作，如：叉车在货物缝隙间缓慢穿行】
10–15秒 【原因揭示：上摇/横移展示浪费点，如：顶部空间空置、高度闲置】
15秒，9:16竖屏，4K，写实工业摄影，真实物理质感，纪录片质感。
镜头类型：【如：中景前推后上摇】

主要动作：【1 个核心动作，无人出镜】
运镜：【缓慢前推/上摇，轻微手持感】

质量控制：4K，自然宽容度，不过度锐化
```

### Prompt 02（15–30 秒：方案 + 决策 + CTA）——独立生成计划 2

```
以@图片1为空间参考、@图片2为风格参考，以@图片3（C1末帧截图）作为本段首帧参考（图生视频）。
本段画面无人出镜。本段为独立生成计划，以下描述完整自成一段，不依赖其他提示词。
场景与上段为同一间【行业】仓库：层高【X】米【结构】厂房，顶部日光灯管，窗光混合照明，
中性偏暖色温——以上场景描述在本段完整重写，不引用其他段。
叙事节奏：0–6秒 【方案演示：写实改造动作，如：叉车将托盘放入货架、货架安装、货物上架】
6–12秒 【前后对比：同一仓库写实画面左右分屏——左改造前 / 右改造后】
12–15秒 【决策标准画面定格，为CTA留白】
15秒，9:16竖屏，4K，写实工业摄影，真实物理质感。
镜头类型：【如：全景横移转分屏对比】
主体：前半段【写实方案演示】；后半段【同一仓库写实左右分屏对比】
主要动作：【如：叉车将托盘放入货架，镜头横向滑过对比画面】
运镜：【先横移再固定，轻微手持感】
场景/背景：同一仓库，同一光线；分屏对比段保持写实，不出现白模/示意图
光照/风格：纪实纪录片质感，中性偏暖色温，轻微胶片颗粒，地面划痕与油污延续
质量控制：4K，自然宽容度，不过度锐化
负面约束：无文字（字幕后期加）、无商标、无透视畸变、无3D渲染感、无塑料光泽、无过度饱和、无白模混入
```

> 旁白四拍配额：拍1 ≤ 15 字、拍2 ≤ 45 字、拍3 ≤ 45 字、拍4 ≤ 15 字。C1 旁白 = 拍1+拍2（≤ 60 字），C2 旁白 = 拍3+拍4（≤ 60 字）。

## 八、段间衔接方案（固定，1 处接缝）

核心原则：每段 15 秒独立生成；衔接完全靠素材（C1 末帧截图作 C2 首帧）+ 两段共用空间/风格参考图，不做文字上的"承接"。

| 接缝 | 首帧参考 | 转场方式 | 音效点 | 剪辑要点 |
| ---- | -------- | -------- | ------ | -------- |
| C1→C2 | C1 末帧截图作 C2 首帧 + 共用空间/风格参考图 | 动作匹配硬切；进入方案/对比段可用白闪缩放 + 提示音 | 切点落在环境音重音 | 尾留 0.5s，头裁 0.5~1s |

## 九、制作流程与检查清单

### 制作流程

1. 按《视频模板.md》写好四拍脚本与旁白（≤ 120 字，拍 1/2/3/4 配额 15/45/45/15）
2. 按第七节 Prompt 生成参考图（空间图必用；白模仅确需独立示意时生成）
3. 按第六节 Prompt 模板分别撰写 Prompt 01、Prompt 02——**两条各自完整、互不引用**
4. 逐段独立生成：先 C1（15 秒），导出 C1 末帧截图作为 C2 首帧素材
5. 生成 C2（15 秒）时上传：空间参考图 + 风格参考图 + C1 末帧截图（首帧参考）
6. 如确需白模示意：单独生成独立示意镜头（纯灰底），后期以分屏/插帧切入
7. 按第八节衔接表做转场，衔接处各留 0.5~1s 余量，裁掉头尾不稳定帧
8. 后期加专业配音、字幕、音效；关键数字用字幕强调

### 发布前检查清单

- [ ] 平台 AI 生成标注已添加
- [ ] 全片旁白 ≤ 120 字（四拍配额 15/45/45/15），已数过字数
- [ ] 一条视频只讲一个采购决策，方案要点 ≤ 3
- [ ] 无价格竞争话术、无厂家宣传、无真实事故画面
- [ ] 画面无人出镜（确需人物时：同一参考图、仅中远景，无面部/手部特写）
- [ ] 两条提示词均含：@引用、分时段描述、8要素、音频设计、负面约束
- [ ] **每条 Prompt 自包含：无"承接/与上段一致/同上"等依赖表述；场景光线色调已完整重写**
- [ ] **视觉语言单一：主提示词内无白模混入；白模只出现在独立示意镜头**
- [ ] 接缝转场自然、音效压点正确
- [ ] 字幕已检查错别字，关键数字正确
- [ ] 关联资产（搜索资产/WDS/案例）已核对
- [ ] 去 AI 化复查：抽查画面无塑料光泽、过度饱和、假皮肤等 AI 感，有则重生成该段
