## 说明

本模板是 WDSS 视频生产的标准骨架，基于 Seedance 2.0 模型，适用于全部视频脚本（VIDEO-xxx）。

- 每条视频按本模板填写生成，结构固定为 **4 段 × 15 秒 = 60 秒**
- 完整范例：`WDSS/内容输出/视频脚本/VIDEO-017-Seedance生产计划.md`
- 生成前先查 `搜索资产索引` 和 `案例索引`，确认关联资产
- 提示词必须按"去 AI 化要点"写实，控制 AI 感

## 二、生产标准（固定值，不修改）

| 项 | 标准 |
| -- | ---- |
| 模型 | Seedance 2.0（即梦/豆包） |
| 参考图 | Seedream 4.5 生成（9:16 竖图） |
| 单段时长 | 15 秒直出 |
| 成片时长 | 60 秒（4 段 × 15 秒） |

| 音频 | 原生音频，最终替换为专业配音 |

## 三、去 AI 化提示词要点（每条提示词必须遵守）

1. **画面语言用"实拍感"词**：纪录片质感、纪实摄影、手持微晃、自然混合光（窗光+日光灯）、中性偏暖色温、轻微胶片颗粒。
2. **加真实环境细节**：地面划痕与油污、托盘磨损、货架轻微旧化、角落线管、灰尘颗粒、包装轻微破损。
3. **人物去模特感**：真实肤质（毛孔/细纹/肤色不均）、自然小动作（停顿、眨眼、微低头）、工装磨损与汗渍。
4. **避免"AI 完美"**：不做完美对称构图、不做无人机式顺滑运镜、允许轻微构图瑕疵与透视失真。
5. **负面约束必带**：无3D渲染感、无塑料光泽、无过度饱和、无完美对称、无CG质感、无光滑假皮肤。

## 四、镜头清单（4 段 × 15 秒）

填写规则：

- 每段只放**一个叙事单元**，15 秒内讲完一件事（可含两三个快切小节）
- 画面：写清主体、动作、场景，并加入实拍感细节
- 提示词按 8 要素写：镜头类型 / 主体 / 主要动作 / 运镜 / 场景背景 / 光照风格 / 质量控制 / 负面约束
- 旁白与脚本原旁白保持一致，按段切分

| 段 | 时间 | 画面（一个叙事单元） | 旁白（切分后） | 提示词（8 要素） | 参考图 |
| -- | ---- | -------------------- | -------------- | ---------------- | ------ |
| C1 | 0–15s | 【钩子：问题场景 → 转折画面】 | 【开场旁白】 | 【待填】 | 空间+风格 |
| C2 | 15–30s | 【问题分析：快切 2~3 个画面】 | 【问题旁白】 | 【待填】 | 空间 |
| C3 | 30–45s | 【方案+决策：3D 白模/示意图】 | 【方案与标准旁白】 | 【待填】 | 白模 |
| C4 | 45–60s | 【风险提醒 → 顾问口播收尾】 | 【风险与引导旁白】 | 【待填】 | 人物+空间 |

提示词示例（C1 参考，直接替换主体即可）：

```
[镜头类型]中景前推转全景横移
[主体]【行业】仓库：前半段【问题场景，如：地面堆满货物、通道被侵占】；后半段同一仓库分区整齐【分区描述】
[主要动作]【动作，如：工人侧身穿过货物缝隙，随后叉车沿主通道行驶】
[运镜]先缓慢前推再向右横移，轻微手持感
[场景/背景]【层高】层高【结构】厂房，顶部日光灯管，窗光混合照明
[光照/风格]纪实纪录片质感，中性偏暖色温，轻微胶片颗粒，钢材反光真实，地面有划痕与油污
[质量控制]4K，自然宽容度，不过度锐化
[负面约束]无文字水印、无商标、无夸张滤镜、无3D渲染感、无塑料光泽、无过度饱和、无CG质感
```

## 六、段间衔接方案（固定，3 处接缝）

核心原则：**每段 15 秒直出；段间用"上一段末帧 → 下一段首帧参考（图生视频）"＋转场处理**。

| 接缝 | 首帧参考 | 转场方式 | 音效点 | 剪辑要点 |
| ---- | -------- | -------- | ------ | -------- |
| C1→C2 | C1 末帧作 C2 首帧 + 空间参考图 | 动作匹配硬切 | 切点落在引擎声/环境音重音 | 尾留 0.5s，头裁 0.5~1s |
| C2→C3 | 风格跳变，C3 用白模参考图直接起 | 白闪缩放 + 提示音（进入演示模式） | 白闪 0.3s | C3 开头留 0.5s 白模静止 |
| C3→C4 | C4 前半用 C3 末帧压黑；人物段用人物+空间参考图 | 黑场 + 淡入 → 拉近转写实人物 | 黑场处音乐重拍 | 人物口型不稳时保留画面、后期配音 |

## 七、制作流程与检查清单

### 制作流程

1. 按第五节 Prompt 生成 3 张参考图（或用自己的真实仓库照片）
2. 按 C1→C4 逐段生成，每段 15 秒，竖屏 9:16
3. 生成下一段前，把上一段末帧截图作为首帧参考（图生视频）
4. 按第六节衔接表做转场，衔接处各留 0.5~1s 余量，裁掉头尾不稳定帧
5. 后期加专业配音、字幕、音效；关键数字用字幕强调

### 发布前检查清单

- [ ] 平台 AI 生成标注已添加
- [ ] 无真实事故画面、无价格竞争话术
- [ ] 人物跨段形象一致（同一参考图）
- [ ] 三处接缝转场自然、音效压点正确
- [ ] 字幕已检查错别字，关键数字正确
- [ ] 关联资产（搜索资产/WDS/案例）已核对
- [ ] 去 AI 化复查：抽查画面无塑料光泽、过度饱和、假皮肤等 AI 感，有则重生成该段
