# 视频生产模板（Seedance 2.0 · 30 秒紧凑版）

版本：v5.1

状态：Active（项目统一生产标准，替代 v3.x / v4.0 / v4.1 / v4.2 / v4.3 / v4.4）

## 说明

本模板是 WDSS 视频生产的标准骨架，基于 **Seedance 2.0**（即梦/豆包），提示词按 **seedance-prompt-zh** 技能撰写，适用于全部视频脚本（VIDEO-xxx）。

- 生产链路：先按《视频模板.md》写 30 秒四拍脚本与旁白（120–130 字，下限 110）→ 再按本模板转成 2 段 Seedance 提示词
- 成片固定 **30 秒 = 2 段 × 15 秒直出**（Seedance 单段上限 15 秒）
- 结构固定 4 拍：**钩子（0–3s）→ 痛点（3–15s）→ 方案（15–26s）→ 决策+CTA（26–30s）**，映射为 C1/C2 两段
- **画面一律写实优先（靠文字描述约束）；不使用空间/风格参考图，模型按描述自由发挥；白模只做独立示意镜头**（2026-08-13 修订）
- **每个生成计划是独立上下文：Prompt 02 不记得 Prompt 01，每段提示词必须自包含**（2026-08-11 实操修订）
- **字幕/CTA 一律后期添加**：Seedance 不生成文字（AI 文字易乱码），画面全程无文字、无字幕、无水印，仅预留字幕空间（2026-08-14 实操修订）

## 二、30 秒叙事结构 → 2 段映射（固定）

| 段 | 时间 | 内容 | 对应拍 | 单段任务 |
| -- | ---- | ---- | ------ | -------- |
| C1 | 0–15s | 钩子 + 痛点 | 拍1 + 拍2 | 15 秒内讲完"问题是什么 + 为什么" |
| C2 | 15–30s | 方案 + 决策 + CTA | 拍3 + 拍4 | 15 秒内讲完"怎么办 + 怎么判断" |

> 每段只放一个叙事单元，可含两三个快切小节；单段内每 5 秒一个推进。

## 三、段间一致性规则（实操铁律，2026-08-11 新增）

> 实操教训：Seedance 每次生成都是**独立上下文**，Prompt 02 无法读取 Prompt 01 的任何信息。文字写"承接 Prompt 01 / 与上段一致 / 像同一条视频继续"均无效。段间一致性只能靠**共享素材** + **自包含描述**。

1. **每段 Prompt 必须自包含**：场景、层高、结构、光线、色温、镜头、动作、音频、负面约束，**每一段都完整重写一遍**。禁止"同上、与上段一致、承接上段"等表述。
2. **一致性靠文字自包含 + C1 末帧首帧，不靠参考图**：
   - 不使用空间/风格参考图；同一仓库、同一光线、同一色调全部靠每段文字描述统一
   - C2 首帧 = C1 末帧截图（图生视频），这是唯一的"承接"载体
3. **画面一致性要素要写进每段**：同一仓库、同一光线、同一色调——这些必须作为文字描述出现在每一段 Prompt 里，而不是"参照上一段"。
4. **旁白同样自包含**：每段 Prompt 的音频部分写本段自己的旁白全文，不引用其他段。

---

## 四、视觉语言与白模使用规则（实操铁律）

> 实操教训：白模（浅灰工程示意底）混入写实仓库画面时，模型会把白模灰底混进仓库背景，画面杂乱、生成内容错乱。以下规则强制遵守：

1. **写实优先**：C1、C2 主画面全部用写实仓库画面（由文字描述约束：实拍感、地坪划痕油污、自然混合光），方案、对比全部用写实画面表达。
2. **白模独立使用**：确需白模示意（如"三类货分区"）时，单独生成一段独立示意镜头——纯灰底、**不进入主提示词**，后期以分屏或插帧方式切入成片。
3. **同条提示词只出现一种视觉语言**：写实画面与白模示意图禁止出现在同一条提示词里。
4. **方案演示用"动作"代替"图"**：用叉车放货、货架安装、货物上架等写实动作表达方案，比静态示意图更稳、更不易乱。
5. **分屏对比也用写实**：改造前/后对比用同一仓库的写实画面左右分屏，不用白模做对比。

## 五、Seedance Prompt 规范（seedance-prompt-zh，必读）

每条提示词按以下结构撰写，缺一不可：

### 5.1 @ 引用语法

- 不使用空间/风格参考图（模型按文字描述自由发挥）
- C2 另传 `@图片3`：C1 末帧截图（作为首帧参考，图生视频）
- 每个引用必须说明用途（当前仅 C2 的 `@图片3` 首帧参考），不允许只写"参考@图片"
- 白模不是常规引用素材；确需时走"独立示意镜头"流程（见第四节），**不写进主提示词的 @ 引用**

### 5.2 分时段描述（必写）

单段 15 秒拆 3 个时段，每时段只做一件事：

```
0–5秒：...
5–10秒：...
10–15秒：...
```

### 5.3 8 要素 + 音频

```
[镜头类型] [主体] [主要动作] [运镜] [场景/背景] [光照/风格] [质量控制] [负面约束]
音频：旁白原文 + 环境音 + 音画同步要求；BGM 后期叠加（不在 Seedance 阶段生成）
```

### 5.4 去 AI 化要点（每条必须遵守）

1. 画面语言用"实拍感"词：纪录片质感、纪实摄影、手持微晃、自然混合光（窗光+日光灯）、中性偏暖色温、轻微胶片颗粒。
2. 加真实环境细节：地面划痕与油污、托盘磨损、货架轻微旧化、角落线管、灰尘颗粒、包装轻微破损。
3. 避免"AI 完美"：不做完美对称构图、不做无人机式顺滑运镜、允许轻微构图瑕疵与透视失真。
4. 负面约束必带：无3D渲染感、无塑料光泽、无过度饱和、无完美对称、无CG质感。
5. 人物出镜：允许写实人物（仓管/工人）增强场景真实感，仅中/远景、侧面/背影，禁面部与手部特写、多人同框；人物动作服务于叙事，避免 AI 假脸。

## 六、Prompt 撰写模板（按 seedance-prompt-zh 技能，直接套用）

> 提示词遵循技能基本公式：**[主体/场景] + [动作/运动] + [运镜语言] + [分时段描述] + [音频/音效] + [风格/氛围]**，末尾附质量控制与负面约束。
> 15 秒段必须分时段描述；不使用空间/风格参考图，全部按文字描述生成；每个 @ 引用必须写明用途（当前仅 C2 的 `@图片3` 首帧参考）。
> **镜头密度规则**：每 15 秒段 = 1 条连续运镜（一镜到底），镜头全程不硬切、不跳景别、不换机位；景别变化靠推/拉/摇自然过渡，分时段用「镜头连续，当前X景别」描述；确需多机位/多镜头时拆成独立段生成、后期拼接；镜头服务叙事，不为炫技。

### Prompt 01（0–15 秒：钩子 + 痛点）——独立生成计划 1

```
15秒写实工业视频，9:16竖屏，4K。本段为独立生成计划，完整自成一段、不依赖其他提示词；画面允许人物出镜（仅中远景、侧面/背影、无面部特写）；不使用参考图，全部按文字描述生成。

[主体/场景] 【行业】仓库：【层高】【结构】厂房，顶部日光灯管，窗光混合照明，地坪划痕与油污；【问题场景：地面堆满、通道被占、顶部空置】
[动作] 【1 个核心动作，如：叉车在货物缝隙间缓慢穿行】
[运镜] 一镜到底（镜头连续、不生硬跳切）：【如：平视全景起幅 → 跟随叉车横移 → 上摇展示浪费点，轻微手持感】

[分时段]（每时段补景别）
0–5秒：（镜头连续，当前全景）【钩子画面定格，痛点同框】
5–10秒：（镜头连续，当前中景）【1 个具体动作展开，镜头跟随】
10–15秒：（镜头连续，上摇至全景仰拍）【原因/浪费点揭示】

[音频] 中文普通话男性旁白，沉稳专业、语速自然、音画同步。旁白：“【钩子+痛点旁白，57–65字】”。环境音：【叉车引擎声、仓库底噪】，不盖过旁白；BGM 后期叠加。

[风格/氛围] 纪实纪录片质感，中性偏暖色温，轻微胶片颗粒，实拍感强、去AI感。
[质量控制] 4K，自然宽容度，不过度锐化，建筑与货物比例真实。
[负面约束] 无文字水印、无字幕、无商标、无3D渲染感、无塑料光泽、无过度饱和、无CG质感、无货物漂浮。
```

### Prompt 02（15–30 秒：方案 + 决策 + CTA）——独立生成计划 2

```
以@图片3（C1末帧截图）作为本段首帧参考（图生视频），不使用其他参考图。15秒写实工业视频，9:16竖屏，4K。本段为独立生成计划，完整自成一段；画面允许人物出镜（仅中远景、侧面/背影、无面部特写）。

[主体/场景] 与上段同一间【行业】仓库（本段完整重写，不引用上段）：层高【X】米【结构】厂房，顶部日光灯管，窗光混合照明，中性偏暖色温，地坪划痕油污。
[动作] 【写实方案演示动作，如：重新规划通道、叉车将托盘放入加高货架、小件放入阁楼货架】
[运镜] 一镜到底（镜头连续、不生硬跳切）：【如：全景横移展示方案 → 同仓左右分屏对比，镜头横向滑过，轻微手持感】

[分时段]（每时段补景别）
0–6秒：（镜头连续，从中景拉远至全景）【方案演示：写实改造动作】
6–12秒：（镜头连续，全景左右分屏）【前后对比：左改造前 / 右改造后】
12–15秒：（镜头连续，当前全景）【决策画面定格，预留字幕空间；不生成任何文字，字幕/CTA 后期添加】

[音频] 中文普通话男性旁白，沉稳专业、关键结论处适当停顿、音画同步。旁白：“【方案+决策+CTA旁白，57–65字】”。环境音：【货架安装声、叉车声、搬运声】，不盖过旁白；BGM 后期叠加。

[风格/氛围] 纪实纪录片质感，中性偏暖色温，轻微胶片颗粒，实拍感强、去AI感。
[质量控制] 4K，自然宽容度，不过度锐化，货架与货物比例真实。
[负面约束] 无文字、无字幕、无水印（字幕与CTA一律后期添加）、无商标、无透视畸变、无3D渲染感、无塑料光泽、无过度饱和、无白模混入。
```

> 旁白四拍配额：拍1 12–15 字、拍2 45–50 字、拍3 45–50 字、拍4 12–15 字。C1 旁白 = 拍1+拍2（57–65 字），C2 旁白 = 拍3+拍4（57–65 字），全片 120–130 字。

## 八、段间衔接方案（固定，1 处接缝）

核心原则：每段 15 秒独立生成；衔接完全靠素材（C1 末帧截图作 C2 首帧）+ 每段文字自包含描述，不使用空间/风格参考图，不做文字上的"承接"。

| 接缝 | 首帧参考 | 转场方式 | 音效点 | 剪辑要点 |
| ---- | -------- | -------- | ------ | -------- |
| C1→C2 | C1 末帧截图作 C2 首帧 | 动作匹配硬切；进入方案/对比段可用白闪缩放 + 提示音 | 切点落在环境音重音 | 尾留 0.5s，头裁 0.5~1s |

## 九、制作流程与检查清单

### 制作流程

1. 按《视频模板.md》写好四拍脚本与旁白（120–130 字，拍 1/2/3/4 配额 12–15/45–50/45–50/12–15）
2. 如确需白模示意：按第七节 Prompt 单独生成独立示意镜头；不再生成空间/风格参考图
3. 按第六节 Prompt 模板分别撰写 Prompt 01、Prompt 02——**两条各自完整、互不引用**
4. 逐段独立生成：先 C1（15 秒），导出 C1 末帧截图作为 C2 首帧素材
5. 生成 C2（15 秒）时上传：C1 末帧截图（首帧参考）
6. 如确需白模示意：单独生成独立示意镜头（纯灰底），后期以分屏/插帧切入
7. 按第八节衔接表做转场，衔接处各留 0.5~1s 余量，裁掉头尾不稳定帧
8. 后期加专业配音、轻量 BGM、字幕、音效；关键数字用字幕强调

### 发布前检查清单

- [ ] 平台 AI 生成标注已添加
- [ ] 全片旁白 120–130 字（四拍配额 12–15/45–50/45–50/12–15），已数过字数
- [ ] 一条视频只讲一个采购决策，方案要点 ≤ 3
- [ ] 无价格竞争话术、无厂家宣传、无真实事故画面
- [ ] 人物出镜合规：仅中远景、侧面/背影、无面部/手部特写、无多人同框、无AI假脸
- [ ] 两条提示词均含：分时段描述、8要素、音频设计、负面约束（无空间/风格参考图，C2 含 C1 末帧首帧参考）
- [ ] **每条 Prompt 自包含：无"承接/与上段一致/同上"等依赖表述；场景光线色调已完整重写**
- [ ] **视觉语言单一：主提示词内无白模混入；白模只出现在独立示意镜头**
- [ ] 接缝转场自然、音效压点正确
- [ ] 后期 BGM：无歌词、音量低于旁白 6–10dB、平台授权音乐
- [ ] 字幕已检查错别字，关键数字正确
- [ ] 关联资产（搜索资产/WDS/案例）已核对
- [ ] 去 AI 化复查：抽查画面无塑料光泽、过度饱和、假皮肤等 AI 感，有则重生成该段
