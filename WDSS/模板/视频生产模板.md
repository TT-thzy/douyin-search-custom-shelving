## 说明

本模板是 WDSS 视频生产的标准骨架，基于 Gemini（Veo 3.1）模型，适用于全部视频脚本（VIDEO-xxx）。

- 每条视频按本模板填写生成，结构固定为 **6 段 × 10 秒 = 60 秒**
- 完整范例：`WDSS/内容输出/视频脚本/VIDEO-017-Gemini生产计划.md`
- 生成前先查 `搜索资产索引` 和 `案例索引`，确认关联资产

## 二、生产标准（固定值，不修改）

| 项 | 标准 |
| -- | ---- |
| 模型 | Gemini 视频生成（Veo 3.1） |
| 参考图 | Nano Banana / Imagen 生成（9:16 竖图） |
| 单段时长 | 10 秒直出 |
| 成片时长 | 60 秒（6 段 × 10 秒） |
| 画幅 | 9:16 竖屏，最高 4K / 24fps |
| 音频 | 原生同步音频，最终替换为专业配音 |
| 衔接 | 上一段末帧 → 下一段首帧参考（图生视频）＋ 转场设计 |
| 统一负面约束 | 无文字水印、无商标、无夸张滤镜、无变形货架、无真实事故画面 |
| 发布前检查 | AI 标注、无事故画面、无价格竞争话术 |

## 三、镜头清单（6 段 × 10 秒）

填写规则：

- 每段只放**一个镜头、一个核心动作**，10 秒内讲完一件事
- 画面：写清主体、动作、场景
- 提示词按 8 要素写：镜头类型 / 主体 / 主要动作 / 运镜 / 场景背景 / 光照风格 / 质量控制 / 负面约束
- 旁白与脚本原旁白保持一致，一段一段切分

| 段 | 时间 | 画面（一个镜头一个动作） | 旁白（切分后） | 提示词（8 要素） | 参考图 |
| -- | ---- | ------------------------ | -------------- | ---------------- | ------ |
| G1 | 0–10s | 【钩子画面】 | 【开场旁白】 | 【待填】 | 空间+风格 |
| G2 | 10–20s | 【转折/全景画面】 | 【承接旁白】 | 【待填】 | 空间 |
| G3 | 20–30s | 【问题一特写】 | 【问题一旁白】 | 【待填】 | 空间 |
| G4 | 30–40s | 【问题二画面】 | 【问题二旁白】 | 【待填】 | 空间 |
| G5 | 40–50s | 【方案+决策：白模/示意图】 | 【方案与标准旁白】 | 【待填】 | 白模 |
| G6 | 50–60s | 【风险提醒 → 顾问口播收尾】 | 【风险与引导旁白】 | 【待填】 | 人物+空间 |

提示词示例（G1 参考，直接替换主体即可）：

```
一段10秒竖屏视频（9:16）：镜头缓慢前推（dolly in），【仓库主体画面，如：五金厂仓库地面堆满铸件、钢管和纸箱，通道被货物侵占】，一名工人侧身穿过，顶部工业灯轻微晃动。写实纪录片质感，暖白工业光，钢材反光自然，4K。不要出现文字、商标、夸张滤镜。
```

## 四、参考图生成 Prompt（Nano Banana，9:16 竖图）

### 参考图 1：仓库空间（写实，全程共用）

```
写实摄影风格，竖构图 9:16，【行业】仓库内部：【层高】层高【结构，如：钢结构厂房】，顶部工业照明灯，混凝土 C30 地坪，开阔无杂物；左侧【货架类型，如：重型横梁货架 4 层】，中间留出约 3.5 米宽叉车主通道，右侧【另一货架类型】；自然采光窗光叠加暖白工业光，钢材反光真实，轻微景深；广角镜头，空间感强，画面干净。
负面：无人物、无文字、无商标、无杂物、无夸张滤镜。
```

### 参考图 2：顾问形象（人物，G6 用）

```
写实人像摄影，竖构图 9:16，【年龄】岁左右【性别】，短发，面容亲和专业，穿【服装，如：深蓝色 Polo 衫（工装感）】，半身正面，双臂自然，微笑看向镜头；背景为虚化的【行业】仓库（货架与工业灯光虚化），自然光加柔和补光，浅景深，4K 质感。
负面：无文字、无夸张表情、无面部变形、无夸张滤镜。
```

### 参考图 3：3D 白模货架（G5 用）

```
3D 工程示意图风格，浅灰色纯背景，竖构图 9:16；【货架组，如：三组仓储货架白模并排：重型横梁货架、悬臂式货架、中型/阁楼货架】；白底蓝线高亮，45 度等轴测视角，结构线条清晰，产品渲染质感。
```

## 五、段间衔接方案（固定，5 处接缝）

核心原则：**每段 10 秒直出；段间用"上一段末帧 → 下一段首帧参考（图生视频）"＋转场处理**。

| 接缝 | 首帧参考 | 转场方式 | 音效点 | 剪辑要点 |
| ---- | -------- | -------- | ------ | -------- |
| G1→G2 | G1 末帧作 G2 首帧 + 空间参考图 | 快切 + 环境音延续 | 工业底噪不断 | 尾留 0.5s，头裁 0.5~1s |
| G2→G3 | G2 末帧作 G3 首帧 | 动作匹配硬切 | 切点落在引擎声/环境音重音 | 同上 |
| G3→G4 | G3 末帧作 G4 首帧 | 内容推进硬切，旁白承接 | 切点落在旁白节奏 | 同上 |
| G4→G5 | 风格跳变，G5 用白模参考图直接起 | 白闪缩放 + 提示音（进入演示模式） | 白闪 0.3s | G5 开头留 0.5s 白模静止 |
| G5→G6 | G6 前半用 G5 末帧压黑；人物段用人物+空间参考图 | 黑场 + 淡入 → 拉近转写实人物 | 黑场处音乐重拍 | 人物口型不稳时保留画面、后期配音 |

## 六、制作流程与检查清单

### 制作流程

1. 按第四节 Prompt 生成 3 张参考图（或用自己的真实仓库照片）
2. 按 G1→G6 逐段生成，每段 10 秒，竖屏 9:16
3. 生成下一段前，把上一段末帧截图作为首帧参考（图生视频）
4. 按第五节衔接表做转场，衔接处各留 0.5~1s 余量，裁掉头尾不稳定帧
5. 后期加专业配音、字幕、音效；关键数字用字幕强调

### 发布前检查清单

- [ ] 平台 AI 生成标注已添加
- [ ] 无真实事故画面、无价格竞争话术
- [ ] 人物跨段形象一致（同一参考图）
- [ ] 五处接缝转场自然、音效压点正确
- [ ] 字幕已检查错别字，关键数字正确
- [ ] 关联资产（搜索资产/WDS/案例）已核对
