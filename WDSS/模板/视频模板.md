# 抖音搜索视频模板（30 秒紧凑版）

版本：v1.2

状态：Active（项目统一脚本标准，替代 v0.1 长版模板）

---

## 说明

本模板是 WDSS 抖音搜索视频的统一脚本骨架。**只做 30 秒**，生产使用 **Seedance 2.0**（提示词技能：**seedance-prompt-zh**）。

- 30 秒 = 2 段 × 15 秒（Seedance 单段直出上限 15 秒，两段拼接）
- 结构固定 4 拍：**钩子 → 痛点 → 方案 → 决策 + CTA**
- 一条视频只讲 **一个采购决策**；全片旁白 ≤ 120 字
- 每条脚本必须给出：30 秒旁白全文、四拍脚本表、逐段 Seedance 提示词（分时段）
- **画面一律写实优先；白模只做独立示意镜头，禁止与写实空间参考图混用**（2026-08-11 实操修订）
- **每个生成计划独立上下文：两段 Prompt 各自自包含，互不引用**（2026-08-11 实操修订）

## 一、硬性生产标准（固定值，不修改）

| 项 | 标准 |
| -- | ---- |
| 成片时长 | 30 秒（2 段 × 15 秒直出，Seedance 2.0） |
| 模型 | Seedance 2.0（即梦/豆包）；提示词遵循 seedance-prompt-zh 技能规范 |
| 参考图 | Seedream 4.5（9:16 竖图） |
| 画幅 | 9:16 竖屏，4K |
| 音频 | Seedance 原生音频；后期替换为专业配音 |
| 旁白字数 | 全片 ≤ 120 字（约 4 字/秒），按四拍配额填写 |
| 出镜 | 默认无人出镜；确需人物仅中/远景，禁面部与手部特写 |
| 统一负面约束 | 无文字水印、无字幕、无商标、无夸张滤镜、无变形货架、无3D渲染感、无塑料光泽、无过度饱和、无CG质感、无真实事故画面 |
| 视觉语言 | **同一提示词内只允许一种视觉语言**：写实为主；白模仅独立示意镜头，不与写实空间图混用 |
| 提示词自包含 | **每条 Prompt 独立完整，禁止"承接/继续上一段"等依赖表述**（见第六节） |

## 二、30 秒内容结构（固定 4 拍）

| 拍 | 时间 | 任务 | 旁白配额 | 硬性要求 |
| -- | ---- | ---- | -------- | -------- |
| 1 钩子 | 0–3s | 直接命中搜索词，一句话点破 | ≤ 15 字 | 必须含搜索词/用户原话 |
| 2 痛点 | 3–15s | 一个核心痛点 + 原因 | ≤ 45 字 | 只讲一个问题，不铺开 |
| 3 方案 | 15–26s | 核心方案 + ≤ 3 个要点 | ≤ 45 字 | 方案要点最多 3 个 |
| 4 决策+CTA | 26–30s | 1 句决策标准 + 1 句咨询引导 | ≤ 15 字 | 给判断方法；CTA 咨询式、不推销 |

> 全片旁白合计 ≤ 120 字。写完数一遍字数，超了必须删，优先删"痛点铺开"和"方案罗列"。

---

## 三、内容紧凑原则（硬性）

1. **一条视频只讲一个采购决策**：一个核心观点，其余全是支撑，不允许并列第二主题。
2. **方案要点 ≤ 3 个**：超过 3 个即不合格，合并同类项。
3. **每句话三选一**：命中搜索 / 建立专业信任 / 推动下一步行动。做不到就删。
4. **一律删掉**：价格竞争话术、厂家宣传、泛泛行业介绍、多方案罗列、与本决策无关的风险提醒。

---

## 四、画面视觉语言规则（实操铁律，2026-08-11 新增）

> 实操教训：白模（浅灰工程示意底）与写实空间参考图同时引用时，模型会把白模灰底混进仓库背景，画面杂乱、生成内容错乱。

1. **写实优先**：方案演示、前后对比全部用写实画面表达（叉车放货、货架安装、货物上架、同一仓库左右分屏）。
2. **白模独立使用**：确需白模示意（如"货架分区"）时，单独生成独立示意镜头——纯灰底、不引用空间/风格参考图，后期以分屏或插帧方式切入成片。
3. **同条提示词只出现一种视觉语言**：主提示词内禁止白模混入。
4. **分屏对比也用写实**：改造前/后对比用同一仓库写实画面左右分屏，不用白模。

## 五、脚本填写格式（每条脚本按此填写）

### 1. 基础信息

- 视频编号：【VIDEO-xxx】
- 对应搜索资产：【资产名】
- 视频主题：【一句话说明解决什么采购决策】
- 视频关键词：≤ 4 个
- 发布标签：主标签 / 精准标签 / 行业标签

### 2. 30 秒旁白全文

【四拍旁白连读版，供配音；末尾标注总字数】

### 3. 四拍脚本表

| 拍 | 时间 | 画面（写实） | 旁白 | 字数 |
| -- | ---- | ------------ | ---- | ---- |
| 1 钩子 | 0–3s | 【痛点场景定格，写实】 | "【≤15字】" | |
| 2 痛点 | 3–15s | 【痛点展开 + 原因，1 个动作】 | "【≤45字】" | |
| 3 方案 | 15–26s | 【写实方案演示 + 写实前后对比；白模仅独立示意】 | "【≤45字】" | |
| 4 决策+CTA | 26–30s | 【决策标准画面定格】 | "【≤15字】" | |

### 4. Seedance 提示词（2 段，按 seedance-prompt-zh 规范）

- **Prompt 01（0–15 秒，钩子 + 痛点）**：分时段描述（0–5s / 5–10s / 10–15s）；8 要素；@引用；音频。独立完整。
- **Prompt 02（15–30 秒，方案 + 决策 + CTA）**：全部写实，无白模混入；场景/光线/色调完整重写；@引用含 C1 末帧截图作首帧参考。独立完整，不写"承接上一段"。

### 5. 视频标题（3 个）

- 标题1（问题 + 方向）/ 标题2（场景 + 规模）/ 标题3（避坑型）

### 6. 评论区设计（2 个预测问题 + 回复）

### 7. 私信第一句话

### 8. 关联资产（搜索资产 / WDS / 案例）

### 9. 更新记录

## 六、Seedance 2.0 提示词规范（seedance-prompt-zh）

按技能要求，每条提示词必须包含：

1. **@ 引用**：`@图片1`（空间参考）、`@图片2`（风格参考）；C2 另传 C1 末帧截图（@图片3）作首帧参考；每个引用必须说明用途；白模不写进主提示词的 @ 引用。
2. **分时段描述**：0–5s / 5–10s / 10–15s，每时段只做一件事，避免内容过载。
3. **8 要素**：镜头类型 / 主体 / 主要动作 / 运镜 / 场景背景 / 光照风格 / 质量控制 / 负面约束，另加音频设计。
4. **音频设计**：旁白原文 + 环境音 + 音画同步；环境音不盖过旁白。
5. **去 AI 化**：实拍感、自然混合光、地面划痕油污、轻微手持、允许轻微构图瑕疵；负面约束必带。
6. **自包含（独立上下文）**：Seedance 每次生成是独立上下文，Prompt 02 看不到 Prompt 01。每段 Prompt 必须完整重写场景、层高、结构、光线、色温、动作、音频、负面约束；禁止"承接 / 与上段一致 / 同上"表述。段间一致性靠共享素材：两段共用同一空间/风格参考图 + C2 用 C1 末帧截图作首帧。
