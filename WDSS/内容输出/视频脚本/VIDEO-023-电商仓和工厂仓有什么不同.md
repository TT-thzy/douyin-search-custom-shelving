# 三、视频结构（30 秒：问题核心 → 解决思路 → 前后对比）

## C1（0–15秒）问题核心

画面：电商仓按工厂仓思路装满货，拣货员满仓跑，订单堆着发不出去（写实实拍感）。

旁白（15秒）："工厂仓讲究'装得多'，电商仓讲究'取得快'。用工厂仓的思路做电商仓，货是装下了，订单却发不出去。"

## C2（15–30秒）解决思路 + 前后对比

画面：电商仓动线白模（阁楼+流利式+波次拣货通道）→ 分屏对比：满仓乱跑找货 vs 高频货近出口、按波次拣货、库位编号。

旁白（15秒）："小件多SKU用阁楼货架，高频商品用流利式货架，按波次设计拣货通道，库位编号绑定。核心是拣货效率。"

## 内容素材（供两段取用，原时长标注不再执行）

### 第一部分：问题分析

两种仓库的核心差异：

| 对比 | 工厂仓 | 电商仓 |
| ---- | ------ | ------ |
| 核心 | 存储量 | 拣货效率 |
| 货物 | 批次大、批量小 | SKU多、批量小 |
| 作业 | 整存整取 | 高频拆零 |
| 动线 | 进出货 | 拣货波次 |

### 第二部分：方案分析

电商仓配置：

- 阁楼货架：小件多 SKU，向上要空间
- 流利式货架：高频商品，先进先出拣选
- 拣货通道：按波次设计，减少行走
- 库位编号：件号/货号绑定库位

### 第三部分：决策标准

- SKU 多、单件轻 → 阁楼 + 流利式
- 订单量大 → 波次拣货 + 复核区
- 大促波峰 → 预留扩展区

### 第四部分：风险提醒

- 只重存储不重拣货，效率低
- 高频货放最远位置
- 无库位编号，靠人记忆

## 结尾

"电商仓规划的核心是拣货效率。把你的 SKU 数、订单量和货物大小发给我，帮你设计拣货动线。"

# 四、专业内容要求

- ✅ 为什么：两种仓库目标不同
- ✅ 什么时候：新建电商仓、效率下降时
- ✅ 适合谁：电商卖家、代运营仓、云仓
- ✅ 不适合谁：整进整出的工厂仓
- ✅ 成本因素：阁楼和流利式投入性价比高
- ✅ 风险因素：拣错货、大促爆仓

# 五、评论区设计

## 预测问题1

用户可能问：电商仓一定要用阁楼货架吗？

回复：不一定。SKU 多、单件轻、层高 4.5 米以上时阁楼货架性价比很高；如果都是大件、托盘货，横梁货架更合适。按货物形态判断。

## 预测问题2

用户可能问：电商仓怎么减少拣货走路？

回复：把高频商品放在拣货口附近和腰部层，按订单波次规划拣货路线，库位编号后按路径顺序拣。这几个动作通常能省下 30% 以上走路时间。
