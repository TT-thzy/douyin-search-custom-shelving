## 二、去 AI 化提示词要点（本计划已按此优化）

1. **实拍感语言**：纪录片质感、纪实摄影、手持微晃、自然混合光（窗光+日光灯）、中性偏暖色温、轻微胶片颗粒。
2. **真实环境细节**：地面划痕与油污、托盘磨损、货架轻微旧化、角落线管、灰尘颗粒、包装轻微破损。
3. **人物去模特感**：真实肤质（毛孔/细纹/肤色不均）、自然小动作（停顿、眨眼、微低头）、工装磨损与汗渍。
4. **避免 AI 完美**：不做完美对称构图、不做无人机式顺滑运镜、允许轻微构图瑕疵与透视失真。
5. **负面约束强化**：无3D渲染感、无塑料光泽、无过度饱和、无完美对称、无CG质感、无光滑假皮肤。

## 三、镜头清单（4 段 × 15 秒）

### C1（0–15s）钩子 → 转折｜写实实景

画面：0–8s 仓库乱象（中景前推，工人侧身穿过）；8–15s 同仓分区整齐（全景横移，叉车行驶）。

旁白：很多五金厂老板发现，仓库怎么收拾都乱，货越来越多，通道越堆越窄。其实不是人不勤快，是货没分类、空间没用对。

提示词：

```
[镜头类型]中景前推转全景横移
[主体]五金厂仓库：前半段地面堆满铸件、钢管、纸箱，通道被侵占；后半段同一仓库分区整齐，重件托盘区、长料悬臂区、散件货架区清晰
[主要动作]工人侧身穿过货物缝隙，随后叉车沿主通道平稳行驶
[运镜]先缓慢前推再向右横移，轻微手持感
[场景/背景]6米层高旧厂房，顶部日光灯管，窗光混合照明
[光照/风格]纪实纪录片质感，中性偏暖色温，轻微胶片颗粒，钢材反光真实，地面有划痕与油污
[质量控制]4K，自然宽容度，不过度锐化
[负面约束]无文字水印、无商标、无夸张滤镜、无3D渲染感、无塑料光泽、无过度饱和、无CG质感
```

### C2（15–30s）三类货｜写实快切

画面：0–5s 重件特写（叉车叉铸件）；5–10s 长料（钢管竖靠墙、地上散放的危险状态）；10–15s 散件抽屉。

旁白：五金厂的货分三类：重件，铸件、冲压件、模具，单件几十到几百公斤；长料，钢管、角钢、板材，几米长，竖着靠墙最危险；散件，五金配件、标准件，品种多、单件轻。

提示词：

```
[镜头类型]三连快切（特写仰拍→侧面跟随→中景推进）
[主体]三类货物依次出现：带油污和铸造毛刺的重型铸件托盘、竖靠墙散放的钢管、成排抽屉式分类盒
[主要动作]叉车叉起铸件→镜头扫过竖靠墙的钢管→工人抽出抽屉取件
[运镜]快切节奏，镜头有轻微手持晃动
[场景/背景]重件区、长料区、散件区
[光照/风格]写实工业光，中性色调，托盘和地面有磨损痕迹
[质量控制]4K
[负面约束]无真实事故、无文字、无变形货架、无3D渲染感、无过度饱和
```

参考：参考图 1（空间）

### C3（30–45s）方案 + 决策｜3D 白模（示意图段）

画面：0–3s 三组白模全景；3–10s 依次高亮（重件横梁、长料横放悬臂架、散件分区）；10–15s 50kg 分档刻度线动画。

旁白：规划核心：重件托盘化上重型横梁，长料上悬臂架横放固定，散件上中型或阁楼，模具用抽屉式。判断标准三条：超50公斤上重型；长件上悬臂；轻小件上中型或阁楼。

提示词：

```
[镜头类型]俯拍旋转转平行横移
[主体]三组货架3D白模并排（重型横梁/悬臂/中型阁楼），50kg分档刻度线滑动
[主要动作]货架依次高亮展开结构透视，刻度线从左到右
[运镜]先俯拍旋转再平行横移，速度平稳
[场景/背景]浅灰背景工程示意图风
[光照/风格]白底蓝线高亮，线条干净（示意图段允许工程渲染质感）
[质量控制]4K，结构线条清晰
[负面约束]无文字（字幕后期加）、无商标、无透视畸变
```

### C4（45–60s）风险 + 结尾｜警示示意 → 写实人物

画面：0–7s 警示示意（护栏拦截、横梁弯曲模拟）；7–15s 顾问出镜口播。

旁白：三个坑别踩：长料竖靠墙会倒；重件放轻型货架会超载变形；地坪承重不够会压裂地面。五金厂仓库规划，核心不是买什么货架，而是先把货分好类。拿不准的，把仓库尺寸和货物类型发我，帮你出初步方案。

提示词：

```
[镜头类型]中景示意转固定机位
[主体]前半段钢管倾倒被防撞护栏拦截、横梁超载弯曲的模拟动画；后半段40岁左右仓储顾问（深蓝色Polo衫，工装有磨损）站在分区整齐的仓库通道
[主要动作]警示动画演示→顾问自然说话，轻微手势，说话前有短暂停顿
[运镜]固定机位，轻微手持感
[场景/背景]浅灰警示背景转自然光仓库
[光照/风格]红蓝警示配色转写实人像：真实肤质细节、浅景深、中性偏暖
[质量控制]4K，口型与语音同步，不过度磨皮
[负面约束]无真实事故、无血迹、无文字、无口型崩坏、无光滑假皮肤、无AI感
```

## 五、段间衔接方案（3 处接缝）

核心原则：**每段 15 秒直出；段间用"上一段末帧 → 下一段首帧参考（图生视频）"＋转场处理**。

| 接缝 | 首帧参考 | 转场方式 | 音效点 | 剪辑要点 |
| ---- | -------- | -------- | ------ | -------- |
| C1→C2 | C1 末帧（叉车驶入通道全景）作 C2 首帧 + 空间参考图 | 动作匹配硬切：叉车向前 → 叉齿特写 | 切点落在引擎声/环境音重音 | 尾留 0.5s，头裁 0.5~1s |
| C2→C3 | 风格跳变，C3 用白模参考图直接起 | 白闪缩放 + 提示音（进入演示模式） | 白闪 0.3s | C3 开头留 0.5s 白模静止 |
| C3→C4 | C4 前半用 C3 末帧压黑；人物段用人物+空间参考图 | 黑场 + 淡入 → 拉近转写实人物 | 黑场处音乐重拍 | 人物口型不稳时保留画面、后期配音 |

## 六、制作流程与检查清单

### 制作流程

1. 用 Seedream 4.5 按第四节 Prompt 生成 3 张参考图（或用自己的真实仓库照片）
2. 按 C1→C4 逐段生成，每段 15 秒，竖屏 9:16
3. 生成下一段前，把上一段末帧截图作为首帧参考（图生视频）
4. 按第五节衔接表做转场，衔接处各留 0.5~1s 余量，裁掉头尾不稳定帧
5. 后期加专业配音、字幕、音效；关键数字（50kg、三类货）用字幕强调

### 发布前检查清单

- [ ] 平台 AI 生成标注已添加
- [ ] 无真实事故画面、无价格竞争话术
- [ ] 人物跨段形象一致（同一参考图）
- [ ] 三处接缝转场自然、音效压点正确
- [ ] 字幕已检查错别字，关键数字正确
- [ ] 去 AI 化复查：抽查画面无塑料光泽、过度饱和、假皮肤等 AI 感，有则重生成该段
