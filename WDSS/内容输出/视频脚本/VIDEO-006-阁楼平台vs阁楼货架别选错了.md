# 三、视频结构

## 开头3秒

"一字之差，选错多花20万。阁楼平台和阁楼货架，很多企业搞不清楚区别就去采购了，结果花了大价钱做了不匹配的方案。今天用一个视频帮你彻底搞清楚——它们到底差在哪，你应该选哪个。"

## 中间内容

### 第一部分：核心区别——四张对比维度（25秒）

**维度一：结构形式**

阁楼货架：
- "货架+楼面"组合体
- 以货架立柱和横梁为主体支撑
- 楼面铺设在货架上
- 一层是货架，二层是货架+人行走道

阁楼平台（钢平台）：
- 独立钢结构体系
- H型钢或工字钢做主梁
- 立柱独立布置，不依赖货架
- 楼面是大面积连续的钢结构平台

一句话总结：货架是"货架上加楼面"，平台是"单独搭一层钢结构楼板"。

**维度二：承重能力**

阁楼货架：
- 楼面承重：200-500kg/㎡
- 适合：人员走动+手推车+轻型货物堆放
- 不适合：叉车、重型设备、集中大荷载

阁楼平台：
- 楼面承重：500-2000kg/㎡（甚至更高）
- 适合：叉车作业、设备上楼、重型货物堆放
- 更高的承重意味着更高的结构成本

**维度三：上下通道方式**

阁楼货架：
- 人员通过楼梯上下
- 货物通过人工搬运或小型升降机
- 没有叉车通道

阁楼平台：
- 楼梯（人员）+ 货梯（货物）+ 叉车坡道（可选）
- 叉车可以直接开到二楼作业
- 通道宽度需满足叉车转弯半径

**维度四：造价差异**

阁楼货架：
- 以800平仓库为例：约15万-25万（两层）
- 单位造价约150-250元/㎡（楼面面积）

阁楼平台：
- 以800平仓库为例：约25万-45万（两层）
- 单位造价约300-500元/㎡（楼面面积）

为什么差这么多？
- 平台的结构钢材规格更大
- 平台承重设计标准更高
- 平台需要更复杂的基础处理
- 叉车坡道/货梯等配套设施成本高

### 第二部分：分别最适合什么场景？（25秒）

**选阁楼货架，当你的需求是：**

1. 多SKU拆零拣货
- 仓库有几千个SKU，每个SKU库存量不大
- 主要作业是"找货→拿货→打包"
- 典型行业：五金配件、电子元器件、日用品、医药

2. 人工作业为主
- 仓库里没有大叉车
- 拣货人员用手推车、小推车
- 货物单件重量不超过15kg

3. 核心目标：增加库位和拣货面积
- 你需要的是"更多放货的地方"
- 不要求二楼能跑叉车

4. 预算相对有限
- 要在有限预算内最大化拣货面积
- 可以接受人工上下搬运的效率

**选阁楼平台，当你的需求是：**

1. 需要大面积连续操作空间
- 你要在二楼设置分拣区、包装区、质检区
- 需要开阔的大空间，不能全是货架通道

2. 叉车或设备需要上楼
- 二楼需要用叉车搬运重型托盘
- 或者需要安装传送带、分拣设备等

3. 货物较重，超出轻型货架范围
- 单件重量50kg以上
- 需要托盘直接堆放在平台上
- 集中荷载大，不是分散存储

4. 未来可能调整二楼用途
- 平台的灵活性更高
- 今天做存储，明天可能改生产区或办公区
- 不需要重新设计结构

### 第三部分：最常见的选错案例（15秒）

选错一：做了阁楼货架，结果发现叉车进不去

某汽配厂，看到别人做阁楼货架就跟着做了。结果他们的产品单件20-40kg，人工根本搬不动，叉车又开不上二楼。最后二楼只能放最轻的包装材料，核心需求没解决。多花15万，还没解决根本问题。

选错二：做了阁楼平台，结果只用到了30%的承重

某电子元器件企业，仓库全部是小件产品，工人手拿即可。但因为"想一步到位"，花40万做了阁楼平台。实际上平台500kg/㎡的承重设计大量富裕，如果选阁楼货架可能18万就够了。多花了22万买了一个根本没用的承重性能。

选错三：把货架和平台混为一谈，低价中标后出了问题

某企业招标时只说"做阁楼"，没区分平台和货架。最低价中标方按货架标准报价，但在施工作业时发现承重不够，现场加钢加柱，最终价格比正常平台报价还高，还耽误了工期。

### 第四部分：决策路线图——三步确定你该选哪个（15秒）

第一步：确定楼上的核心用途

问自己：二楼主要用来干嘛？
- 存储+人工拣货 → 倾向阁楼货架
- 大面积作业区 + 可能有设备 → 倾向阁楼平台

第二步：确定荷载需求

问自己：二楼最重会放什么？
- 单件＜15kg，总荷载＜300kg/㎡ → 阁楼货架够用
- 有叉车、托盘、设备 → 必须阁楼平台

第三步：确定预算和灵活性需求

问自己：未来3年二楼用途会变吗？
- 不会变，就是仓库 → 按当前需求精准选
- 可能会变（改产线、改办公、改分拣）→ 平台更灵活

### 第五部分：能不能混合做？（10秒）

可以，而且很多项目就是组合方案：

- 一部分做阁楼平台：大空间区域，放重型货物或设备区
- 另一部分做阁楼货架：多SKU拣货区，最大化库位
- 平台区设置叉车坡道，货架区只留人行楼梯

前提是：
- 仓库面积够大（≥1000平），可以分区
- 前期方案设计时统一规划，不是分两次施工
- 消防和结构在一个整体方案里解决

## 结尾

"如果你正在纠结选阁楼平台还是阁楼货架，可以把仓库的用途、货物重量和预算范围发给我，我帮你分析——十几万和几十万的差别，别选错了。"

# 五、评论区设计

## 预测问题1

用户可能问：我仓库800平，高6米，货物10-30kg，选哪个？

回复：10-30kg属于中等偏重，人工长期搬运会比较吃力。关键看你们有没有叉车——如果有叉车且希望叉车上二楼，需要平台。如果愿意配置小型升降机配合人工，阁楼货架也可以。建议结合每天的搬运频次和人员配置来综合判断。

## 预测问题2

用户可能问：平台和货架能在一个项目里一起做吗？

回复：完全可以，而且很多大型项目都是组合方案。比如一楼重型区域做阁楼平台（带叉车坡道），二楼轻型区域做阁楼货架（人工拣货），用通道和楼梯连接。但需要前期统一设计，而不是分两次找人做。

## 预测问题3

用户可能问：能不能先做货架，以后不够用了再改成平台？

回复：不建议。阁楼货架的结构基础是按轻型荷载设计的，要升级成平台的承重标准，几乎等于拆了重建，成本更高。建议一开始就评估清楚需求，按最终目标一次规划到位。如果未来确实不确定，可以先做一部分平台预留扩展能力。
