## 三、段间一致性规则（实操铁律）

> Seedance 每次生成是独立上下文，Prompt 02 无法读取 Prompt 01。段间一致性靠共享素材 + 自包含描述：

1. 两段共用同一张 `@图片1` 空间参考图（同一间仓库）
2. 两段共用同一张 `@图片2` 风格参考图（同一视觉语言）
3. C2 首帧 = C1 末帧截图（图生视频）
4. 每段 Prompt 完整重写场景、层高、结构、光线、色温、动作、音频、负面约束，禁止"承接/同上"

## 九、段间衔接方案（固定，1 处接缝）

核心原则：每段 15 秒独立生成；衔接完全靠素材（C1 末帧截图作 C2 首帧）+ 两段共用空间/风格参考图，不做文字上的"承接"。

| 接缝 | 首帧参考 | 转场方式 | 音效点 | 剪辑要点 |
| ---- | -------- | -------- | ------ | -------- |
| C1→C2 | C1 末帧截图作 C2 首帧 + 共用空间/风格参考图 | 动作匹配硬切；进入方案/对比段可用白闪缩放 + 提示音 | 切点落在环境音重音 | 尾留 0.5s，头裁 0.5~1s |

## 十、制作流程与发布前检查

### 制作流程

1. 用第七节 Prompt 生成参考图（空间图必用，两段共用）；用第八节 Prompt 生成竖版＋横版两张封面
2. 先生成 C1（15 秒），导出 C1 末帧截图
3. 生成 C2（15 秒）时上传：空间参考图 + 风格参考图 + C1 末帧截图（首帧参考）
4. 按第九节衔接表做转场，衔接处各留 0.5~1s 余量，裁掉头尾不稳定帧
5. 后期按需替换专业配音、加字幕、加音效；关键数字（2米/4米/三到五成）用字幕强调

### 发布前检查清单

- [ ] 平台 AI 生成标注已添加
- [ ] 全片旁白 ≤ 120 字，一条视频只讲一个采购决策
- [ ] 无真实事故画面、无价格竞争话术
- [ ] 画面无人出镜
- [ ] 两条提示词均自包含：无"承接/与上段一致"表述；场景光线色调完整重写
- [ ] 主提示词内无白模混入（写实优先）
- [ ] 接缝转场自然、音效压点正确
- [ ] 字幕已检查错别字，关键数字（2米、4米、4.5米、5米、三到五成）正确
- [ ] 关联资产（搜索资产/WDS/案例）已核对
- [ ] 去 AI 化复查：抽查画面无塑料光泽、过度饱和、假皮肤等 AI 感，有则重生成该段
