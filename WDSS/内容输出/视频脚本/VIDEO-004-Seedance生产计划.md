## 四、Seedance Prompt 01（0–15 秒，独立生成计划 1）

```text
15秒写实工业视频，9:16竖屏，4K。本段为独立生成计划，完整自成一段、不依赖其他提示词；画面允许人物出镜（仓管/工人，仅中远景、侧面/背影、无面部特写）；不使用参考图，全部按文字描述生成。

[主体/场景] 层高约6米钢结构厂房，顶部日光灯管，窗光混合照明，地面有划痕与油污；中小型仓库：地面堆满货物、通道拥堵、顶部空置

[动作] 叉车在缝隙间穿行，货物堆边缘有托盘磨损细节

[运镜] 一镜到底（镜头连续、不生硬跳切）：先平视全景，再跟随叉车横移，后缓慢上摇，轻微手持感

[分时段]（每时段补景别）
0–5秒：（镜头连续，当前全景）中小仓库全景：货物堆满地面、通道被占、顶部空间空置，画面定格
5–10秒：（镜头连续，当前中景）叉车在货物缝隙间穿行，镜头跟随叉车横移
10–15秒：（镜头连续，上摇至全景仰拍）上摇展示顶部空置与拥堵的通道，强调搬仓之外有更省的方案

[音频] 中文普通话男性旁白，沉稳专业，语速自然，音画同步。旁白：“仓库一满就急着搬仓，几十万白花了。搬仓不是唯一办法，很多仓库靠改造就能多存不少货。五种扩容方案按投入从低到高排，别一上来就选最贵的那一个。” 环境音：叉车引擎声、货物搬运声、仓库底噪，不盖过旁白。

[风格/氛围] 纪实纪录片质感，中性偏暖色温，轻微胶片颗粒，钢材反光真实，构图有轻微不对称，实拍感强、去AI感
[质量控制] 4K，自然宽容度，不过度锐化，建筑与货物比例真实
[负面约束] 无文字水印、无字幕、无商标、无3D渲染感、无塑料光泽、无过度饱和、无CG质感、无货物漂浮、无面部特写、无多人同框
```

## 九、制作流程与发布前检查

### 制作流程

1. 用第七节 Prompt 生成竖版＋横版两张封面；不再生成空间/风格参考图（C1/C2 按文字描述自由发挥）
2. 先生成 C1（15 秒），导出 C1 末帧截图
3. 生成 C2（15 秒）时上传：C1 末帧截图（首帧参考）
4. 按第八节衔接表做转场，衔接处各留 0.5~1s 余量，裁掉头尾不稳定帧
5. 检查原生旁白：正确则保留（环境音+旁白），错字/错内容则修正或替换专业配音；加字幕、加音效；关键数字用字幕强调

### 发布前检查清单

- [ ] 平台 AI 生成标注已添加
- [ ] 全片旁白 120–130 字，一条视频只讲一个采购决策
- [ ] 无真实事故画面、无价格竞争话术
- [ ] 画面无人出镜
- [ ] 两条提示词均自包含：无"承接/与上段一致"表述；场景光线色调完整重写
- [ ] 主提示词内无白模混入（写实优先）
- [ ] 接缝转场自然、音效压点正确
- [ ] 字幕已检查错别字，关键数字正确
- [ ] 关联资产（搜索资产/WDS/案例）已核对
- [ ] 去 AI 化复查：抽查画面无塑料光泽、过度饱和、假皮肤等 AI 感，有则重生成该段
