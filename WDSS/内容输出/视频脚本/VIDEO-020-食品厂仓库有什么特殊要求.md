# 三、视频结构

## 开头3秒

"食品仓库和普通仓库最大的区别不是货架贵不贵，而是四条底线：卫生、防潮、先进先出、消防。哪条漏了都可能出大事。"

## 中间内容

### 第一部分：问题分析

食品仓库四大风险：

1. 污染：鼠虫、灰尘、异物
2. 受潮：包装变软、食品变质
3. 过期：先进先出做不到就积压
4. 火灾：包装材料易燃

### 第二部分：方案分析

- 离地存放：托盘/货架，货物不落地不靠墙
- 防潮：通风 + 除湿 + 地面防潮层
- 先进先出：流利式货架或批次库位管理
- 消防：分区、喷淋、通道专项设计

### 第三部分：决策标准

- 纸箱小件 → 流利式或阁楼货架
- 托盘货 → 横梁货架 + 批次管理
- 有保质期 → 优先能先进先出的结构

### 第四部分：风险提醒

- 货物落地，鼠虫污染
- 靠人记效期，过期积压
- 忽略消防分区，整改返工

## 结尾

"食品仓库规划，卫生和效期是底线。把你的货物形态和保质期要求发给我，帮你判断用哪种货架最合适。"

# 五、评论区设计

## 预测问题1

用户可能问：食品仓库能用药灭鼠吗？

回复：食品仓库尽量用物理方式（粘鼠板、挡鼠板、捕鼠笼）和专人管理的低毒饵站，避免污染食品。关键是封堵进入通道和离地存放。

## 预测问题2

用户可能问：食品仓库货架选流利式还是普通货架？

回复：有保质期、纸箱小件、品种多的推荐流利式货架，靠重力滑道实现先进先出；托盘货用横梁货架配合批次库位管理。
