## 一、基础信息

视频编号：VIDEO-001

对应搜索资产：问题型-仓库太小怎么办

视频主题：仓库面积不够用时，先分析空间利用率再决定方案，不要急着搬仓或扩建。

视频关键词：仓库太小怎么办、仓库扩容、仓库空间利用率、搬仓

整片旁白：很多老板发现仓库越来越小，第一反应就是搬仓。但其实 80% 的仓库不是面积不够，是空间利用率太低。先看利用率，再决定方案。如果你不知道自己的仓库适合哪种方案，可以把仓库面积、高度和货物情况发给我，我帮你分析。

## 二、镜头清单（4 段 × 15 秒）

### C1（0–15s）钩子 → 转折｜写实实景

画面：0–8s 仓库堆满货物、通道被占，老板叉腰皱眉看现场；8–15s 镜头拉起俯视，同一仓库上空空间闲置。

旁白：很多老板发现仓库越来越小，第一反应就是搬仓。但 80% 的仓库不是面积不够，是空间利用率太低。

提示词：

```
[镜头类型]中景前推转俯视拉起
[主体]五金仓库：前半段地面堆满货物、通道被侵占；后半段镜头拉起俯视，显示顶部空间大量闲置
[主要动作]老板叉腰皱眉看现场，随后镜头缓慢拉起
[运镜]前推后垂直拉起，轻微手持感
[场景/背景]层高6米旧厂房，顶部日光灯管，窗光混合照明
[光照/风格]纪实纪录片质感，中性偏暖色温，轻微胶片颗粒，地面有划痕
[质量控制]4K，自然宽容度
[负面约束]无文字水印、无商标、无夸张滤镜、无3D渲染感、无过度饱和
```

### C2（15–30s）问题分析｜写实快切

画面：快切三个原因：仓库堆满、货物只堆地面、通道过宽。

旁白：先看三个原因：业务在涨、SKU 在增；货堆在地上没用高度；通道不合理浪费面积。

提示词：

```
[镜头类型]三连快切（俯拍→侧面→特写）
[主体]仓库三个问题：堆满的仓库、只堆地面的货物、过宽通道
[主要动作]依次快切展示，镜头有轻微手持晃动
[运镜]快切节奏
[场景/背景]同仓库不同区域
[光照/风格]写实工业光，中性色调，地面磨损痕迹
[质量控制]4K
[负面约束]无文字、无变形货架、无3D渲染感
```

参考：参考图 1（空间）

### C3（30–45s）方案 + 决策｜3D 白模

画面：五组方案白模：布局优化、增加货架高度、阁楼货架、阁楼平台、搬仓扩建；利用率 50%→85% 刻度动画。

旁白：五种方案：优化布局几乎零成本、增加货架高度用层高、阁楼货架加面积、阁楼平台做大空间，最后才是搬仓扩建。先用利用率判断缺什么，再选方案。

提示词：

```
[镜头类型]俯拍旋转转平行横移
[主体]五组方案3D白模并排（布局优化/加高货架/阁楼货架/阁楼平台/搬仓扩建），空间利用率刻度线从50%升到85%
[主要动作]货架依次高亮展开结构透视
[运镜]先俯拍旋转再平行横移
[场景/背景]浅灰背景工程示意图风
[光照/风格]白底蓝线高亮
[质量控制]4K，结构线条清晰
[负面约束]无文字（字幕后期加）、无商标、无透视畸变
```

参考：参考图 3（白模）

### C4（45–60s）风险 + 结尾｜警示示意 → 写实人物

画面：警示示意：盲目搬仓的搬运车流、扩建挖地示意；随后顾问出镜口播。

旁白：别急着搬仓和扩建，先算利用率，可能十分之一的钱就能解决。拿不准的，把面积、高度和货物情况发给我。

提示词：

```
[镜头类型]中景示意转固定机位
[主体]前半段搬仓/扩建的浪费示意动画；后半段40岁左右仓储顾问站在仓库通道面对镜头
[主要动作]警示动画演示→顾问自然说话，轻微手势
[运镜]固定机位，轻微手持感
[场景/背景]浅灰警示背景转自然光仓库
[光照/风格]警示配色转写实人像，真实肤质，浅景深
[质量控制]4K，口型同步，不过度磨皮
[负面约束]无真实事故、无文字、无口型崩坏、无光滑假皮肤
```
