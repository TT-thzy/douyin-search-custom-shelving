# WDS-009 库位规划评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-009 库位规划评估标准（Location Planning Assessment Standard）

用于判断库位编号、库位分配和库容配置的合理性。

核心目标：一货一位、按需分配、账实相符。

---

# 2. 应用场景

- 库位编号建立
- 高频/低频货位分配
- 账实不符整改

---

# 3. 决策问题

1. 库位编号是否覆盖全仓？
2. 高频货是否放在易取位置？
3. 库位粒度是否匹配管理需求？

---

# 4. 评估核心指标

## 4.1 编号覆盖率

编号库位 ÷ 总库位（目标 100%）

## 4.2 货位匹配度

- 高频货 → 黄金层、近出口
- 低频货 → 高处、远端

## 4.3 库位粒度

按货号、批次、客户分层级管理。

---

# 5. 判断参考

- 覆盖率 < 90% → 先补编号
- 高频货在远端 → 调整货位
- 找货时间 > 3 分钟 → 库位管理不足

---

# 6. 评估流程

盘点库位 → 编号 → 按周转率分配 → 校验找货时间

---

# 7. 需要收集的数据

- 库位数、SKU 数
- 各 SKU 出库频率
- 当前找货时间

---

# 8. 决策逻辑

高频 + 大件 → 黄金层近出口

低频 + 小件 → 高处远端

批次严格 → 库位绑定批次

---

# 9. 常见错误

1. 编号只做一半
2. 高频货放最高层
3. 库位与货号不绑定
