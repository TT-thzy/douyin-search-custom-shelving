# WDS-026 货架安全检查标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-026 货架安全检查标准（Rack Safety Inspection Standard）

用于建立货架定期检查制度，预防倒塌事故。

核心目标：损伤早发现、隐患早处理。

---

# 2. 应用场景

- 在用货架日常管理
- 叉车碰撞后检查
- 安全整改

---

# 3. 决策问题

1. 检查频率怎么定？
2. 重点查哪些部位？
3. 发现损伤怎么处理？

---

# 4. 评估核心指标

## 4.1 检查频率

| 类型 | 频率 |
| ---- | ---- |
| 日常目视 | 每周 |
| 专项检查 | 每月 |
| 专业检测 | 每年 |
| 事故后 | 立即 |

## 4.2 重点部位

立柱、横梁、连接件、安全销、底脚、防撞设施。

---
# 5. 判断参考

- 立柱变形 → 评估更换
- 横梁弯曲 → 更换
- 安全销缺失 → 补齐
- 垂直度偏差 >3mm → 调整

---
# 6. 评估流程

建立台账 → 按频率检查 → 记录损伤 → 隔离评估 → 整改复查

---
# 7. 需要收集的数据

- 货架台账（位置、类型、承重）
- 检查记录
- 损伤照片

---
# 8. 决策逻辑

轻微损伤 → 标记观察

中度 → 限载或加固

严重 → 隔离更换

---
# 9. 常见错误

1. 装完不检查
2. 撞弯敲直继续用
3. 检查走过场
