# WDS-021 流利式货架评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-021 流利式货架评估标准（Flow Rack Assessment Standard）

用于判断仓库是否适合流利式货架。

核心目标：纸箱小件实现先进先出和高效拣选。

---

# 2. 应用场景

- 纸箱/周转箱拣选
- 有保质期要求仓库
- 高频品拣货

---

# 3. 决策问题

1. 货物是否纸箱/周转箱、单箱 ≤30kg？
2. 是否有先进先出要求？
3. 拣货频率是否高？

---

# 4. 评估核心指标

## 4.1 货物形态

箱式、能靠重力滑动。

## 4.2 单箱重量

一般 ≤30kg。

## 4.3 先进先出

滑道结构天然 FIFO。

---

# 5. 判断参考

- 托盘级 → 重力式货架
- 单箱超重 → 普通货架
- 高频拣选 + FIFO → 流利式

---

# 6. 评估流程

确认箱重 → 选滑道规格 → 按频率分配滑道 → 拣货口设计

---
# 7. 需要收集的数据

- 箱重、箱型
- 出库频率
- 保质期要求

---
# 8. 决策逻辑

箱式 + FIFO + 高频 → 流利式

托盘 → 重力式

低频 → 普通货架

---
# 9. 常见错误

1. 重箱放流利式，滑道压坏
2. 无 FIFO 需求也选
3. 滑道坡度设计不当
