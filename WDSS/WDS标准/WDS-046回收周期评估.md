# WDS-046 回收周期评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-046 回收周期评估标准（Payback Period Assessment Standard）

用于评估仓储改造和设备投入的投资回收周期。

核心目标：投入前算清回报，避免冲动投资。

---

# 2. 应用场景

- 仓储改造立项
- 自动化设备投资
- 外租 vs 自建决策

---

# 3. 决策问题

1. 年收益如何测算？
2. 回收周期多少？
3. 是否值得投入？

---

# 4. 评估核心指标

## 4.1 年收益

省租金 + 省人工 + 提效率折价。

## 4.2 回收周期

总投入 ÷ 年收益。

## 4.3 判断参考

| 回收周期 | 建议 |
| -------- | ---- |
| <2 年 | 优先投入 |
| 2～4 年 | 常规可投 |
| >4 年 | 谨慎评估 |

---
# 5. 判断参考

- 改造回收 < 外租年租金 × 3 → 值得
- 自动化回收 >5 年 → 暂缓
- 只算投入不算收益 → 补测算

---
# 6. 评估流程

算总投入 → 算年收益 → 算回收期 → 决策

---
# 7. 需要收集的数据

- 总投入
- 年省租金/人工
- 效率提升折算

---
# 8. 决策逻辑

回收短 → 投

回收长 → 分期或降规格

收益不清 → 先算清

---
# 9. 常见错误

1. 只看投入不看收益
2. 收益拍脑袋
3. 回收超长还硬投
