# WDS-008 仓库布局评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-008 仓库布局评估标准（Warehouse Layout Assessment Standard）

用于判断仓库功能分区、货架排列和动线设计的合理性。

核心目标：布局与作业流程匹配，减少无效移动。

---

# 2. 应用场景

- 新建仓库规划
- 老仓库改造
- 布局混乱诊断

---

# 3. 决策问题

1. 功能分区是否完整（收货/存储/拣选/发货）？
2. 货架排列与通道是否匹配？
3. 动线是否单向顺畅？

---

# 4. 评估核心指标

## 4.1 功能区完整性

收货区、存储区、拣选区、发货区、退货区是否齐备。

## 4.2 货架排列

- 排列方向与通道一致
- 背靠背双排减少通道
- 柱距与货架组距匹配

## 4.3 动线

收货 → 存储 → 拣选 → 发货 单向不交叉。

---

# 5. 判断参考

- 功能区缺失 → 优先补分区
- 动线交叉 → 布局需重排
- 货架与柱网不匹配 → 调整排列方向

---

# 6. 评估流程

画平面图 → 标功能区和动线 → 查交叉点 → 优化排列

---

# 7. 需要收集的数据

- 仓库平面尺寸、柱距
- 功能需求、设备清单
- 货物存储特征

---

# 8. 决策逻辑

动线交叉 → 布局重排

功能缺失 → 补分区

货架排布不合理 → 按柱网调整

---

# 9. 常见错误

1. 只看货架不看动线
2. 收货发货同口冲突
3. 货架排列与采光、通道不匹配
