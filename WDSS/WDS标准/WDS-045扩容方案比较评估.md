# WDS-045 扩容方案比较评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-045 扩容方案比较评估标准（Expansion Option Comparison Standard）

用于在多套扩容方案之间做比较决策。

核心目标：按匹配度而非价格选方案。

---

# 2. 应用场景

- 仓库扩容决策
- 货架方案比选
- 扩容 vs 外租 vs 搬迁

---

# 3. 决策问题

1. 各方案解决什么问题？
2. 匹配度如何？
3. 投入产出如何？

---

# 4. 评估核心指标

## 4.1 方案清单

内部立体化 / 外租 / 搬迁 / 组合。

## 4.2 匹配度

方案与货物特征、作业方式的匹配。

## 4.3 成本比较

三年总成本（投入 + 运营 + 机会成本）。

---
# 5. 判断参考

- 层高够 → 内部立体化优先
- 外租年租金高 → 改造回收快
- 方案只比价格 → 先比匹配度

---
# 6. 评估流程

列方案 → 测匹配 → 算三年成本 → 决策

---
# 7. 需要收集的数据

- 货物特征、层高
- 外租租金
- 改造投入估算

---
# 8. 决策逻辑

匹配度优先 → 再比性价比

回收 <3 年 → 改造值得

层高不足 → 外租/搬迁

---
# 9. 常见错误

1. 只比单价
2. 忽略匹配度
3. 不算长期总成本
