# WDS-006 通道评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-006 通道评估标准（Warehouse Aisle Assessment Standard）

用于判断仓库通道宽度和布局是否合理，在空间利用与作业效率之间取得平衡。

核心目标：通道既满足设备通行和安全要求，又不浪费存储空间。

---

# 2. 应用场景

- 仓库布局优化
- 货架方案设计
- 通道过宽/过窄判断
- 叉车设备选型

---

# 3. 决策问题

1. 当前通道宽度是否按设备核算？
2. 通道分级（主/支/拣货/消防）是否合理？
3. 通道收窄能释放多少存储面积？

---

# 4. 评估核心指标

## 4.1 设备通道

按作业设备转弯半径核算：

| 设备 | 主通道参考宽度 |
| ---- | -------------- |
| 平衡重叉车 | 3.5～4.0 米 |
| 前移式叉车 | 2.6～3.0 米 |
| 电动地牛 | 1.8～2.2 米 |
| 人工拣货 | 1.2 米 |

## 4.2 消防通道

- 按消防规范保留疏散通道宽度
- 通道不得被货物占用

## 4.3 通道分级

主通道、支通道、拣货通道分级设置，避免统一宽度浪费。

---

# 5. 判断参考

- 通道全部同宽 → 存在浪费，建议分级
- 通道比设备需求宽 30% 以上 → 可收窄释放空间
- 消防通道被占用 → 立即整改

---

# 6. 评估流程

确认设备清单 → 查转弯半径 → 核算各通道最小宽度 → 分级设计 → 验证消防要求

---

# 7. 需要收集的数据

- 作业设备类型和转弯半径
- 通道长度、宽度
- 消防通道要求
- 货物出库频率

---

# 8. 决策逻辑

设备需求 < 通道宽度 → 收窄释放空间

消防要求 > 通道宽度 → 必须满足消防

拣货频繁 → 拣货通道保证人工通行

---

# 9. 常见错误

1. 通道按"感觉"留，不按设备核算
2. 消防通道被货物占用
3. 主支通道不分级，统一宽度
