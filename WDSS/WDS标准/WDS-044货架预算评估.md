# WDS-044 货架预算评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-044 货架预算评估标准（Rack Budget Assessment Standard）

用于评估货架项目预算构成和合理性。

核心目标：预算不漏项、口径可比、花得明白。

---

# 2. 应用场景

- 货架采购立项
- 报价对比
- 预算审批

---

# 3. 决策问题

1. 预算包含哪些项？
2. 报价口径是否统一？
3. 有无隐性费用？

---

# 4. 评估核心指标

## 4.1 预算构成

货架货价 + 安装 + 运输 + 辅件 + 消防/地坪配合。

## 4.2 口径统一

同承重、同规格、同层数对比。

## 4.3 参考区间

| 类型 | 参考（占货价） |
| ---- | -------------- |
| 轻型 | 8～15% 安装费 |
| 重型 | 12～20% 安装费 |
| 阁楼类 | 15～25% 安装费 |

---
# 5. 判断参考

- 只报总价 → 要求拆项
- 安装费异常低 → 问清范围
- 漏消防地坪 → 补预算

---
# 6. 评估流程

定方案 → 列预算项 → 统一口径 → 对比报价

---
# 7. 需要收集的数据

- 货架规格清单
- 安装运输费
- 消防/地坪条件

---
# 8. 决策逻辑

规格不同 → 先同口径再比价

漏项 → 补列

超预算 → 调规格或分期

---
# 9. 常见错误

1. 只比总价
2. 漏算辅件和消防
3. 为省钱减规格
