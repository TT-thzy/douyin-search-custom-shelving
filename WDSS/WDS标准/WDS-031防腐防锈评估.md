# WDS-031 防腐防锈评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-031 防腐防锈评估标准（Corrosion Assessment Standard）

用于评估货架锈蚀风险和防腐配置。

核心目标：高湿环境货架寿命达标。

---

# 2. 应用场景

- 高湿/沿海仓库
- 冷库货架选型
- 锈蚀货架处理

---

# 3. 决策问题

1. 环境湿度/腐蚀性如何？
2. 防腐等级是否匹配？
3. 锈蚀处理是否及时？

---

# 4. 评估核心指标

## 4.1 环境分级

常温干燥 / 高湿 / 高湿+腐蚀介质。

## 4.2 防腐等级

普通喷塑 / 镀锌 / 高防腐涂层。

## 4.3 锈蚀分级

| 等级 | 表现 | 处理 |
| ---- | ---- | ---- |
| 轻度 | 浮锈 | 打磨补漆 |
| 中度 | 漆面脱落 | 除锈重涂 |
| 重度 | 截面减薄 | 更换构件 |

---
# 5. 判断参考

- 高湿/冷库 → 镀锌或高防腐
- 出现穿孔 → 立即更换
- 湿度失控 → 先控环境

---
# 6. 评估流程

测环境 → 定防腐等级 → 检查锈蚀 → 分级处理

---
# 7. 需要收集的数据

- 环境温湿度
- 货架表面状态
- 锈蚀深度

---
# 8. 决策逻辑

高湿环境 → 高防腐材质

轻度锈 → 处理观察

重度锈 → 更换

---
# 9. 常见错误

1. 高湿仓用普通喷涂
2. 锈蚀刷漆掩盖
3. 只治货架不治环境
