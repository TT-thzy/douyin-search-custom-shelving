# WDS-022 重力式货架评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-022 重力式货架评估标准（Gravity Rack Assessment Standard）

用于判断仓库是否适合托盘级重力式货架。

核心目标：托盘先进先出 + 高密度。

---

# 2. 应用场景

- 托盘大批量 FIFO
- 冷库（减少通道）
- 食品饮料仓库

---

# 3. 决策问题

1. 托盘规格是否统一？
2. 是否有先进先出硬要求？
3. 仓库深度是否够放滑道？

---

# 4. 评估核心指标

## 4.1 托盘规格

统一规格，轨道适配。

## 4.2 先进先出

重力滑道天然 FIFO。

## 4.3 深度空间

滑道需较长深度（一般 6 托以上）。

---

# 5. 判断参考

- SKU 多 → 横梁式
- 托盘不统一 → 不适合
- 需 FIFO + 高密度 → 重力式

---

# 6. 评估流程

确认托盘规格 → FIFO 需求 → 深度核算 → 选型

---
# 7. 需要收集的数据

- 托盘尺寸重量
- SKU 数量
- 仓库深度

---
# 8. 决策逻辑

托盘统一 + FIFO → 重力式

SKU 多 → 横梁式

箱级 → 流利式

---
# 9. 常见错误

1. 托盘规格不统一硬上
2. 深度不足硬设计
3. 与流利式混淆
