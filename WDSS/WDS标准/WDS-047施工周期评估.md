# WDS-047 施工周期评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-047 施工周期评估标准（Construction Period Assessment Standard）

用于评估仓储改造和货架安装的施工周期。

核心目标：工期可控、停产影响最小。

---

# 2. 应用场景

- 货架安装排期
- 阁楼平台施工
- 不停产改造

---

# 3. 决策问题

1. 工期由哪些环节决定？
2. 关键路径在哪？
3. 能否压缩工期？

---

# 4. 评估核心指标

## 4.1 周期构成

设计评审 + 生产 + 安装 + 消防验收。

## 4.2 参考周期

| 项目 | 参考 |
| ---- | ---- |
| 货架安装 | 1～3 周 |
| 阁楼平台 | 3～5 周 |
| 仓库整体改造 | 4～8 周 |

## 4.3 关键路径

生产周期和消防验收通常是瓶颈。

---
# 5. 判断参考

- 只算安装天数 → 漏生产
- 大促/旺季前赶工 → 提前排期
- 停产损失大 → 分区滚动

---
# 6. 评估流程

拆环节 → 排关键路径 → 定总周期 → 排停产计划

---
# 7. 需要收集的数据

- 项目范围
- 材料生产周期
- 消防验收要求

---
# 8. 决策逻辑

工期紧 → 并行 + 标准件

不能停 → 分区滚动

验收复杂 → 提前对接

---
# 9. 常见错误

1. 只算安装天数
2. 验收预留不足
3. 不停产不规划
