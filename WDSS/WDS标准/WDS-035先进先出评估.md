# WDS-035 先进先出评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-035 先进先出评估标准（FIFO Assessment Standard）

用于评估仓库先进先出能力及实现方式。

核心目标：保质期货物先入先出，临期损失最小化。

---

# 2. 应用场景

- 食品、医药、日化仓库
- 效期管理
- 货架选型

---

# 3. 决策问题

1. 是否有保质期要求？
2. 当前 FIFO 如何实现？
3. 货架结构是否支持？

---

# 4. 评估核心指标

## 4.1 批次标识

每批入库日期/批号可查。

## 4.2 货位规则

同批同库位、方向统一。

## 4.3 结构支持

| 方式 | FIFO 能力 |
| ---- | --------- |
| 流利式/重力式 | 天然 FIFO |
| 普通货架+管理 | 靠制度 |
| 驶入式 | 后进先出，不适合 |

---
# 5. 判断参考

- 有保质期 + 流利式 → 首选
- 驶入式存保质期货物 → 排除
- 靠人记效期 → 制度补强

---
# 6. 评估流程

确认保质期要求 → 定批次规则 → 选货架结构 → 落地检查

---
# 7. 需要收集的数据

- 保质期要求
- 批次管理现状
- 货架结构

---
# 8. 决策逻辑

批次严 + 箱级 → 流利式

批次严 + 托盘 → 重力式

批次松 → 普通货架 + 制度

---
# 9. 常见错误

1. 保质期货用驶入式
2. 新旧批次混放
3. 无批次标识
