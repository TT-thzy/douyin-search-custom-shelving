# WDS-037 温湿度评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-037 温湿度评估标准（Temperature & Humidity Assessment Standard）

用于评估仓库温湿度控制水平。

核心目标：货物存储环境达标、可监测、可追溯。

---

# 2. 应用场景

- 食品、医药、电子仓库
- 防潮防锈
- GSP 合规

---

# 3. 决策问题

1. 温湿度目标值是多少？
2. 当前是否达标？
3. 是否有连续监测？

---

# 4. 评估核心指标

## 4.1 目标范围

| 场景 | 参考 |
| ---- | ---- |
| 一般仓储 | RH 40～70% |
| 医药 | 10～30℃、RH 35～75% |
| 金属件 | RH <50% |

## 4.2 监测

连续记录 + 超限报警。

## 4.3 控制手段

通风、除湿、空调、防潮层。

---
# 5. 判断参考

- 无监测 → 先加记录仪
- 超标时段明确 → 定位原因
- 返潮严重 → 离地 + 防潮层

---
# 6. 评估流程

监测一周 → 分析超标 → 定位原因 → 分档投入

---
# 7. 需要收集的数据

- 温湿度记录
- 货物存储要求
- 仓库结构

---
# 8. 决策逻辑

轻微超标 → 通风调整

持续超标 → 除湿/空调

地面返潮 → 防潮处理

---
# 9. 常见错误

1. 靠感觉不记录
2. 只买设备不分析原因
3. 货物贴地存放
