# WDS-007 存储密度评估标准

版本：v0.1

状态：Active

---

# 1. 标准定义

WDS-007 存储密度评估标准（Warehouse Storage Density Assessment Standard）

用于衡量单位面积/体积的存储能力，判断仓库空间是否被高效利用。

核心目标：在满足作业效率的前提下最大化存储密度。

---

# 2. 应用场景

- 仓库扩容评估
- 货架方案比较
- 存储模式优化

---

# 3. 决策问题

1. 当前存储密度处于什么水平？
2. 不同方案密度差异多少？
3. 提升密度是否牺牲作业效率？

---

# 4. 评估核心指标

## 4.1 面积密度

库位数 ÷ 仓库面积（托位/㎡ 或 箱位/㎡）

## 4.2 体积密度

货物体积 ÷ 仓库容积（%）

## 4.3 密度参考

| 存储方式 | 面积密度参考（托位/㎡） |
| -------- | -----------------------: |
| 地面堆垛 | 0.8～1.2 |
| 横梁式货架 | 1.5～2.5 |
| 驶入式/穿梭车 | 2.5～4.0 |

---

# 5. 判断参考

- 密度过低 → 先查通道和高度浪费
- 密度过高 → 检查存取率是否下降
- 密度与效率需平衡，不能只追密度

---

# 6. 评估流程

统计库位和面积 → 计算密度 → 与同类仓库对比 → 找差距原因

---

# 7. 需要收集的数据

- 库位数、仓库面积
- 存储方式、通道比例
- 货物体积、周转率

---

# 8. 决策逻辑

密度低 + 面积充足 → 优化布局优先

密度低 + 面积不足 → 升级存储方式

密度高 + 存取率低 → 牺牲过多效率，需回调

---

# 9. 常见错误

1. 只算地面密度忽略高度
2. 为密度选驶入式，忽略 SKU 结构
3. 密度和效率失衡
