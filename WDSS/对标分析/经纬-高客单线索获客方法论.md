## 二、获客方法论核心（六条）

1. **内容四型配比**：认知型（立人设）→ 信任型（晒服务颗粒度）→ 通知型（卖课）→ 成交型（逼单）。主页前 2 屏 = 人设 + 信任。
2. **2 个屏幕内建立信任**：观众刷到主页前几条内容，就要知道"你是谁、做什么、凭什么信你"。
3. **信任型内容的本质**：客户想看的不是"多少年经验/多少案例"，而是"服务流程颗粒度有多细"——把团队怎么干活拍出来（采访同事、述职现场、客户评价、工作文档）。
4. **痛点型视频 = 销售话术视频化**：把成交对话里客户问的问题直接变成视频选题。
5. **选题来源 = 客户高频问题**："发现一只蟑螂，说明家里已经有一窝了"——统计私信/评论区高频问题，优先回答。
6. **4.0 方法论核心**：先给客户一个"选你不选别人的理由"，再去做流量；不蹭热点、不做泛流量、只做精准客资。

## 三、脚本框架（可参考）

| 环节 | 做法 |
| ---- | ---- |
| 开头 | 答客户问（客户原话/私信截图）或金句反差（"我很羡慕那些特别会讲空话的人"） |
| 中段 | 先讲"你/同行哪里错了"→ 再晒自己强（点名客户、晒业务规模）→ 快速总结 3 个小点再展开 |
| 结尾 | 晒案例收尾 + 留钩子（送资料/引导私域） |
| 语气 | 有态度、敢批评、专业自信（适合乙方操盘手，WDSS 不采用） |

## 四、对 WDSS 可用清单（收编进知识库）

| 方法 | 在 WDSS 的落点 |
| ---- | -------------- |
| 认知型 + 信任型内容 | 新建 6 条认知信任型搜索资产 + 后续"合集零：认识规划顾问"选题线 |
| 2 个屏幕内建立信任 | 主页置顶/首个合集放"我如何做规划"类内容 |
| 信任型 = 晒服务流程颗粒度 | 把 WDS 评估流程（测层高/算承重/出方案）拍成视频 = 信任内容 |
| 痛点型 = 销售话术视频化 | 100 个搜索资产就是现成选题库，客户搜什么就拍什么 |
| 选题来自评论区/私信高频问题 | 评论回复库 v0.2 增加"评论区高频问题收集表"，反哺新资产 |
| 先给"选你不选别人的理由" | 差异化内容（同行给产品，WDSS 给决策） |
| 咨询式私域承接 | 私信承接 SOP（首问 3 件套：面积/层高/货物） |

## 五、对 WDSS 禁用清单（红线）

| 内容 | 禁用原因 |
| ---- | -------- |
| 拽/高傲/骂同行的人设 | 违反"中立专业顾问"定位 |
| 晒收入、晒"我们多强" | 乙方自夸逻辑，违反"不推销" |
| 通知型/成交型内容（卖课、逼单、课程预告） | WDSS 无课程产品，商业转化优先级最低 |
| 卖"获客方法论"本身 | 行业不同：WDSS 卖仓储决策知识 |
| 强势筛选话术（"客户不配"类） | 对中小企业采购决策者赶客 |
