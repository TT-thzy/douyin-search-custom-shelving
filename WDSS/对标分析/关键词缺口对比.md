# 关键词缺口对比（金铁牛 vs WDSS 搜索资产）

版本：v0.1

状态：Active

说明：将金铁牛两个账号的高频标签词（主页作品实测归纳）与 WDSS 100 个搜索资产做对比，输出三张表：重叠词（红海，需差异化）、缺口词（金铁牛占位强、WDSS 未覆盖）、差异化词（WDSS 独有阵地）。用于指导下一步选题与标签词库建设。

---

## 一、重叠词（金铁牛在讲，WDSS 已有资产 → 红海，靠决策价值差异化）

| 金铁牛标签词 | WDSS 对应资产 |
| ------------ | ------------- |
| 阁楼货架 | 匹配型-阁楼货架适合什么仓库 / 预算型-阁楼货架多少钱 / 比较型-阁楼货架和自动化立体库区别 |
| 阁楼平台 / 钢结构平台 / 钢平台 | 匹配型-阁楼平台适合什么企业 / 预算型-阁楼平台多少钱 / 阁楼平台承重怎么计算 / 对比决策-阁楼平台和阁楼货架有什么区别 |
| 重型货架 | 比较型-重型货架怎么选择 / 比较型-中型货架和重型货架区别 |
| 仓库扩容 / 厂房扩容 | 比较型-仓库扩容有哪些方案 / 问题型-仓库太小怎么办 / 问题型-仓库空间不足有哪些解决方案 |
| 仓库改造 / 老仓库 | 老仓库改造怎么规划 / 预算型-仓库改造多少钱 / 问题型-仓库层高不够怎么办 |
| 冷库货架 | 冷库怎么规划 / 比较型-冷库货架和常温货架区别 |
| 悬臂货架 | 匹配型-悬臂货架适合什么场景 / 比较型-悬臂货架和重型货架区别 |
| 驶入式 / 贯通式（通廊式） | 匹配型-驶入式货架适合什么场景 |
| 自动化立库 | 自动化立体库值得上吗 / 比较型-阁楼货架和自动化立体库区别 |
| 电商仓库 / 云仓 | 电商仓怎么规划 / 跨境仓怎么规划 |
| 托盘货架 | 托盘尺寸标准 / 比较型-如何选择仓储货架类型 |

> 策略：重叠词不拼数量（拼不过 736 集合集），拼"决策价值"——金铁牛给参数，WDSS 给"怎么选、要不要选、多少钱、有什么风险"。

## 二、缺口词（金铁牛占位强、WDSS 目前未覆盖 → 评估是否补建）

| 金铁牛高频词 | 说明 | WDSS 建议 |
| ------------ | ---- | --------- |
| 钢结构隔层 / 工字钢隔层 / 厂房隔层 | 金铁牛第一占位词群，WDSS 未使用这些词（WDSS 讲"阁楼平台"） | 建议在阁楼平台类内容中补充这些搜索词作为标签/标题词 |
| 钢结构安装 / 钢结构工程 / 钢混结构 / 楼承板 | 施工/结构类词 | 可在"阁楼平台施工/钢结构二层"内容中作为标签覆盖 |
| 钢结构二层 / 可拆卸式钢结构二层 | 产品形态词 | 并入阁楼平台资产的关键词与标签 |
| 混凝土钢平台 | 细分产品词 | 评估是否补建"混凝土钢平台 vs 钢平台"比较资产 |
| 布匹货架 / 布料货架 | 行业细分词 | 并入纺织厂仓库怎么规划的关键词与标签 |
| 货架出口外贸 | 金铁牛外贸业务词，WDSS 不涉及 | 不建 |
| 货架源头工厂 / 货架厂家 / 货架供应商 | 厂家身份词 | 顾问身份不占，不建 |

## 三、差异化词（金铁牛完全没做、WDSS 独有阵地 → 重点深耕）

| 类别 | 关键词 | 对应资产（已有/新建） |
| ---- | ------ | -------------------- |
| 决策类 | 货架承重怎么算 / 验收标准 / 能用多少年 / 买货架踩坑 | 技术辅助类、风险型已有 |
| 风险类 | 货架倒塌预防 / 消防要求 / 地面承重判断 / 叉车撞货架防护 | 风险型已有 |
| 规划方法类 | 通道设计 / 分区规划 / 空间利用率计算 / 布局优化 | 规划改造类已有 |
| 管理类 | 5S / 库位管理 / 目视化 / 盘点 / 防潮防锈 | 通用管理类已有 |
| 顾问信任类 | 仓储规划顾问是做什么的 / 为什么先规划再买货架 / 怎么判断顾问靠不靠谱 / 顾问和厂家有什么区别 | 认知信任型（本次新建 6 条） |

> 结论：WDSS 的差异化不在产品词（金铁牛已占满），而在"决策词 + 管理词 + 顾问信任词"。内容生产应优先保证差异词汇集，重叠词只作为标签补充，不主力投入。
