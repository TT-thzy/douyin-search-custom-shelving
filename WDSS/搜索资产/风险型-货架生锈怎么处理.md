# 用户问题分析

## 表面问题

货架生锈了怎么办？

## 深层原因

仓库防潮不到位、喷塑层破损、环境酸碱度高，导致钢材锈蚀。

## 用户真正需求

区分"表面浮锈可处理"和"结构锈蚀需更换"，并建立防锈措施。

# 决策分析

## 按锈蚀程度分级处理

| 锈蚀程度 | 表现 | 处理方式 |
| -------- | ---- | -------- |
| 轻度浮锈 | 表面起皮、局部锈点 | 打磨除锈 + 补漆 |
| 中度锈蚀 | 锈层明显、漆面大面积脱落 | 除锈 + 底漆 + 面漆恢复 |
| 重度锈蚀 | 钢材减薄、出现凹坑/穿孔 | 更换构件，不得继续使用 |

## 防锈措施

1. 控制仓库湿度，做好通风或除湿
2. 避免货物贴墙堆放阻碍通风
3. 及时修补碰撞造成的漆面破损
4. 高湿环境选择镀锌或更高防腐等级货架

---

# 推荐决策流程

第一步：检查锈蚀部位和深度，重点看立柱、横梁连接处和底脚。

第二步：轻度锈蚀自行除锈补漆，中度请专业处理。

第三步：出现截面减薄、穿孔的构件立即更换。

第四步：排查潮湿源，从根本上防锈。

---

# 不建议直接做的事情

✘ 锈蚀严重的货架刷层漆继续用。

✘ 只处理表面，不解决仓库潮湿问题。

✘ 用酸性清洗剂清洗货架，加剧腐蚀。

# FAQ

## FAQ-001

问题：货架生锈了还能用多久？

回答：轻度浮锈不影响使用，及时处理后可以长期使用；锈蚀导致钢材截面减薄时承载能力下降，必须评估或更换，不能只看表面。

## FAQ-002

问题：仓库潮湿，选什么货架不容易生锈？

回答：可以选择镀锌货架或更高防腐等级的表面处理，同时做好仓库除湿。钢材本身都会锈蚀，环境控制比材质选择更重要。
