# 决策分析

## 核心区别

| 对比项 | 中型货架 | 重型货架 |
| ------ | -------- | -------- |
| 单层承重 | 约 150～350kg | 500～2000kg（按规格） |
| 存储单元 | 纸箱、散件 | 托盘、重件 |
| 作业方式 | 人工存取 | 叉车存取 |
| 通道要求 | 窄，1 米左右 | 宽，3 米以上 |
| 结构 | 插接式 | 横梁 + 立柱螺栓连接 |
| 参考造价 | 中 | 高 |

## 选择逻辑

1. 单层荷载超过 350kg → 直接考虑重型
2. 需要叉车存取 → 重型货架（横梁式）
3. 人工上下货、重量轻 → 中型货架
4. 有托盘 → 优先按托盘位计算重型货架

---

# 推荐决策流程

第一步：确认是否托盘化、是否用叉车。

第二步：核算单层最大荷载和托盘尺寸。

第三步：确认仓库高度和地坪承载。

第四步：再按统一参数对比报价。

---

# 不建议直接做的事情

✘ 中型货架放重托盘，结构强度不足。

✘ 没有叉车却买重型货架，上下货困难。

✘ 忽略地坪承载，重型货架压裂地面。

# FAQ

## FAQ-001

问题：中型货架能放托盘吗？

回答：一般不建议。中型货架为人工存取设计，托盘进出需要叉车，会损坏货架且荷载不匹配，托盘存储应选重型（横梁式）货架。

## FAQ-002

问题：重型货架多少钱一组？

回答：按规格差异较大，一般横梁式重型货架每组（3 托位）约 1500～4000 元，含立柱、横梁，不含安装。

# 评论区设计

评论：我们一天进出几十托，用叉车，选哪种？

回复：叉车托盘作业应选重型横梁货架。如果 SKU 多、需要独立存取，横梁式最稳；如果 SKU 少、周转慢，可以评估驶入式。
