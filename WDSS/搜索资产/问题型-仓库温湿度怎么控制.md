# 用户问题分析

## 表面问题

仓库湿度大，货物受潮、纸箱变软、金属生锈。

## 深层原因

仓库通风不良、地面返潮、昼夜温差大、货物包装吸湿。

## 用户真正需求

以合理的投入把温湿度控制在货物要求范围内。

# 决策分析

## 控制手段

| 手段 | 适用 | 投入 |
| ---- | ---- | ---- |
| 通风 | 湿度不高、温差小的仓库 | 低 |
| 除湿机 | 梅雨季、高湿地区 | 中 |
| 地面防潮层/托盘离地 | 地面返潮严重 | 低～中 |
| 空调/恒温系统 | 有温度要求的货物 | 高 |
| 温湿度监控仪 | 需要记录和报警 | 低 |

## 参考标准

- 一般仓储：相对湿度 40～70%
- 食品/药品：按品类要求（如药品一般 ≤60%）
- 金属件仓库：优先控制在 50% 以下，防止锈蚀
- 电子元件：防静电、防潮双重考虑

# 推荐决策流程

第一步：用温湿度记录仪监测一周，找到超标时段。

第二步：分析原因是通风、返潮还是温差。

第三步：从低成本手段开始（通风、离地、分区）。

第四步：仍不达标再上除湿或恒温设备。

---

# 不建议直接做的事情

✘ 货物直接落地堆放，地面返潮直接入侵包装。

✘ 只买除湿机不管通风，能耗高效果差。

✘ 忽略湿度记录，靠"感觉"判断。

# FAQ

## FAQ-001

问题：仓库湿度多少合适？

回答：一般仓储建议 40～70%，具体看货物。金属件、纸品、食品、药品各有要求，先查货物的储存规范再定目标。

## FAQ-002

问题：仓库除湿用除湿机还是靠通风？

回答：通风适合湿度不极端的情况，成本低；梅雨季或高湿地区必须配除湿机。多数仓库是通风加局部除湿组合使用。

# 评论区设计

评论：南方梅雨季仓库太潮，货架都生锈了怎么办？

回复：先给货物加托盘离地存放，配合除湿机把湿度压到 60% 以下，货架锈蚀部分及时除锈补漆。长期可以考虑地面做防潮处理。
