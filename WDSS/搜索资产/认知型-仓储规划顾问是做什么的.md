# 用户问题分析

## 表面问题

"规划顾问"是做什么的，跟货架厂家/装修公司有什么区别。

## 深层原因

用户准备买货架或改造仓库，但分不清该找谁：怕找厂家被推销，怕自己不懂被坑。

## 用户最终目标

找到一个能"站在自己这边"、帮自己做对决策的人。

---

# 决策分析

## 问题产生原因

货架行业信息不透明：厂家卖货、装修公司只做施工，缺一个"先判断该不该做、怎么做划算"的角色。

## 可选择方案

方案1：直接找货架厂家（省钱，但容易买错/过度配置）
方案2：自己研究再买（免费，但专业门槛高、风险自担）
方案3：找仓储规划顾问（多一笔咨询费，但先判断再买，降低返工和错配风险）

## 方案比较

| 方案 | 优点 | 缺点 | 适用场景 |
| ---- | ---- | ---- | -------- |
| 厂家直购 | 价格直接、落地快 | 以卖货为导向，易过度配置 | 需求明确、自己懂行 |
| 自己研究 | 免费 | 承重/消防/布局门槛高，出错成本大 | 简单仓库 |
| 规划顾问 | 中立、按需给方案 | 需支付咨询费 | 扩容/改造/选型不确定 |

## 推荐方案

推荐：需求不确定、要扩容/改造时，先找顾问做方向判断，再拿着方向去比价。

## 不推荐方案

不推荐：什么参数都不清楚就找厂家下单。

# FAQ问题库

## FAQ-001

问题：规划顾问和货架厂家有什么区别？
回答：厂家以卖货为导向，顾问以你的需求为导向，先判断该不该买、买什么，再进入采购。

## FAQ-002

问题：找规划顾问要钱吗？
回答：方向性建议可以免费给；出详细方案按工作量收费，先出东西再谈钱。
