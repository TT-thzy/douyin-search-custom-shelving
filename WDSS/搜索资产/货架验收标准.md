# 用户问题分析

**表面问题**：货架装完了，看着挺整齐的，但不知道合不合格，怎么检查？

**深层原因**：
1. 大多数企业没有专业的货架验收知识，看不懂安装图纸上的技术参数
2. 施工方做完就走了，现场没有交接验收环节，或者验收只是"走形式看看"
3. 只关注表面（油漆、外观），忽略了关键的结构安全指标（垂直度、螺栓扭矩、地脚固定等）
4. 不知道货架的"合格标准"是什么，没有对照检查的依据

**用户真正需求**：要一份实用的、能拿着到现场逐项对照检查的验收清单。深层需求是：确保货架安装质量合格、使用安全有保障、避免因安装缺陷导致的安全事故。对于货架这种承载重物、涉及人身安全的设施，验收不是"走流程"，而是安全管理的底线。

# WDS分析

货架验收与WDS标准的关系非常密切——验收的本质就是确认安装结果是否满足设计标准要求：

- **WDS-001 仓高评估**：验收时需实际测量货架安装后的总高度，确认不超过仓库可用净高，并符合设计方案中确定的高度参数。同时检查最高层横梁上方的安全距离是否充足（与消防喷淋头、照明设备、屋顶结构的间距）。
- **WDS-002 承重评估**：货架验收的核心依据来源于WDS-002的承重计算报告。验收时需要核对货架铭牌上标注的额定荷载是否与设计要求一致，立柱规格和横梁截面尺寸是否与承重报告匹配。如果安装期间发生了立柱规格替换，必须要求施工方提供新的承重核算。
- **WDS-003 消防评估**：验收时需要确认货架安装后消防通道的实际宽度与设计一致（通常不小于2米），消防栓和灭火器未被货架遮挡，喷淋头下方有足够的净空间隙（通常不小于0.5米）。如果有消防验收的强制要求，货架安装不应影响消防安全合规性。
- **WDS-004 地坪评估**：验收时应对安装区域的地坪进行复查，确认安装后地坪未出现新的裂缝或沉降。特别是重型货架区域，如果在验收时已经发现地坪出现细微裂纹，需要记录备案并评估其发展趋势。
- **WDS-005 货架选型评估**：验收阶段需要确认实际安装的货架型号、规格、配件与WDS-005选型方案一致，没有被"偷梁换柱"的情况。同时检查安全附件（防撞护栏、立柱护角、背拉杆等）是否按照选型方案完整安装。

# 决策分析

## 一、货架验收检查项目清单

### 1. 外观与表面处理

| 检查项目 | 验收标准 | 检查方法 |
|---------|---------|---------|
| 构件表面涂层 | 无漏喷、无气泡、无剥落、无严重划伤 | 目视检查，重点检查焊接点和边角 |
| 焊接质量 | 焊缝饱满均匀，无裂纹、无气孔、无咬边 | 目视+放大镜检查关键受力焊缝 |
| 构件变形 | 立柱、横梁无肉眼可见弯曲、扭曲 | 目视+靠尺检查 |
| 标识铭牌 | 荷载铭牌张贴完整清晰，位置醒目 | 逐排检查，拍照存档 |

### 2. 安装精度

| 检查项目 | 验收标准 | 检查方法 |
|---------|---------|---------|
| 立柱垂直度 | 偏差≤H/1000且整体≤10mm（H为立柱总高） | 经纬仪或激光垂直仪测量 |
| 同排立柱直线度 | 偏差≤5mm/10m | 拉通线后测量最大偏差 |
| 横梁水平度 | 偏差≤L/500（L为横梁长度） | 激光水平仪逐层检测 |
| 横梁与立柱挂接 | 安全销/保险销全部插入到位，无遗漏 | 逐节点目视+手动检查 |
| 货架间距 | 与设计图纸偏差≤±10mm | 卷尺测量关键间距 |

### 3. 紧固件检查

| 检查项目 | 验收标准 | 检查方法 |
|---------|---------|---------|
| 地脚螺栓紧固 | 全部螺栓紧固到位，无松动 | 扭矩扳手抽检（抽检比例≥20%） |
| 螺栓规格 | 与设计图纸一致，无以小代大 | 卡尺测量螺栓直径 |
| 垫片配置 | 弹簧垫圈/平垫圈齐全 | 目视逐点检查 |
| 化学锚栓/膨胀螺栓 | 锚固深度符合要求，无拔出痕迹 | 抽检关键承重位置的锚固情况 |

### 4. 安全附件

| 检查项目 | 验收标准 | 检查方法 |
|---------|---------|---------|
| 防撞护栏 | 安装位置正确、高度合适、固定牢固 | 目视+推力检查 |
| 立柱护角 | 通道侧立柱全部安装护角 | 逐排清点数量 |
| 背拉杆/水平拉杆 | 按图纸要求安装，螺栓紧固 | 目视+扳手检查 |
| 防坠落网/挡板 | 托盘位后端安装防推落装置 | 目视+推力测试 |

### 5. 荷载测试（如有要求）

| 检查项目 | 验收标准 | 检查方法 |
|---------|---------|---------|
| 满载测试 | 按额定荷载的100%装载，持续24小时 | 逐层满载，检查变形量 |
| 偏载测试 | 按额定荷载的75%单侧装载 | 仅对悬臂货架等偏心结构执行 |
| 残余变形 | 卸载后结构变形恢复，无永久变形 | 加载前后测量关键点数据对比 |

## 二、验收流程建议

```
安装完成 → 施工方自检 → 提交自检报告
    ↓
甲方外观初检（目视检查漆面、焊接、变形）
    ↓
精度检测（垂直度、水平度、直线度测量）
    ↓
紧固件抽检（地脚螺栓、连接螺栓扭矩检查）
    ↓
安全附件检查（护栏、护角、背拉杆）
    ↓
荷载测试（如合同约定）
    ↓
出具验收报告 → 双方签字确认
    ↓
资料归档（验收报告、荷载铭牌照片、精度测量数据）
```

## 三、常见安装缺陷及处理

| 常见缺陷 | 风险等级 | 处理要求 |
|---------|---------|---------|
| 立柱垂直度超标（＞H/1000） | 高 | 必须返工校正，不能让步接收 |
| 横梁安全销漏装 | 高 | 逐节点排查补齐，验收前必须100%安装 |
| 地脚螺栓未紧固或数量不足 | 高 | 必须补装补齐并重新紧固 |
| 涂层局部脱落或划伤 | 中 | 现场补漆处理（使用相同颜色和规格的修补漆） |
| 横梁轻微弯曲（挠度＜L/300） | 中 | 记录在案，下次定期检查时重点关注 |
| 标识铭牌缺失 | 中 | 要求施工方补齐所有荷载标识铭牌 |
| 表面轻微划痕（未伤及底材） | 低 | 记录在案，不影响验收通过 |
| 立柱护角漏装 | 低 | 补齐即可，不影响主体结构安全 |

# 不建议做的事

- ✘ 不检查就直接签字验收——一旦签字确认，后续发现安装质量问题，责任界定会很困难
- ✘ 只看外观不测精度——垂直度和水平度是结构安全的关键，肉眼看不出来偏差，必须用仪器测
- ✘ 只检查一排货架就当全部合格——不同排、不同列都可能存在差异，建议按抽样比例覆盖所有区域
- ✘ 荷载测试用"差不多重的货"而不是标准荷载——如果合同约定了要做荷载测试，必须按额定荷载执行，不能"感觉差不多"
- ✘ 验收资料不做归档——验收报告、荷载铭牌照片、精度测量数据、保修文件等是后续使用中最重要的参考依据，丢了以后很难追溯
- ✘ 发现立柱规格被替换但不追究——立柱是货架最核心的承重构件，规格降低意味着承重能力的降级，不是"差不多"的问题

# FAQ

**FAQ-001**
- 问题：货架验收有没有国家标准或行业标准可以参考？
- 回答：国内的货架行业标准主要参考以下文件：GB/T 51410-2020《货架术语》、WB/T 1042-2012《货架术语及定义》、JB/T 11270-2012《仓储货架技术条件》。但需要说明的是，这些标准主要规定货架的设计和制造要求，对于现场安装验收的细节，更实用的做法是依据安装合同中的技术协议和施工图纸来检查。如果合同没有明确验收标准，建议以上述标准中的安装精度指标作为最低验收要求。

**FAQ-002**
- 问题：货架装好了但荷载铭牌还没贴上，能先验收其他项目吗？
- 回答：不建议先验收再说。荷载铭牌不是"装饰品"，它是告知使用方每个货位最大荷载的安全信息标识。没有荷载铭牌，操作人员不知道能放多重的货，这是重大安全隐患。正确的做法是：要求施工方在正式验收前完成荷载铭牌的张贴，并确认铭牌上的荷载数据与设计方案一致。如果施工方以"铭牌还没做好"为由推脱，可以要求其先提供临时荷载标识（手写贴纸也可以），后续再更换为正式铭牌，但验收前必须确认荷载信息已明确标示。

**FAQ-003**
- 问题：货架使用半年后做安全检查，发现部分地脚螺栓松动了，是安装质量问题吗？
- 回答：不一定。部分原因可能是安装时扭矩不够，但更多时候是因为叉车在日常运行中碰撞到立柱底部或地坪存在微小振动导致螺栓自然松动。这就说明了为什么货架应该建立定期检查和紧固制度——通常建议每半年对全仓库的地脚螺栓进行一次扭矩复查和紧固。验收时确认螺栓紧固到位是第一步，使用后的定期维护是第二步，两者缺一不可。

# 评论区设计

**评论1**：
- 评论：请教一下，我们仓库的货架装完3个月了，当时验收没太仔细。现在发现有一排货架的横梁挂接处有点晃动，这种情况要紧吗？
- 回答：横梁挂接处有晃动需要立刻处理。先检查两个问题：一是安全销（保险销）是否已经插入到位——很多时候晃动就是因为安全销漏装或被震动弹出来了；二是检查挂接爪和立柱的孔位配合是否松动——如果是挂接爪本身变形或制造公差偏大造成的间隙，需要联系施工方评估是否需要更换横梁。在问题处理完成之前，该排货架应暂停使用或降低荷载。安全无小事，不要"凑合用"。

**评论2**：
- 评论：我们仓库面积比较大，货架有几百排，验收时不可能每一排都检查，怎么抽样才科学？
- 回答：建议按照"重点区域全检+一般区域抽检"的原则。重点区域包括：高度超过5米的高位货架区、重型货物存放区、叉车进出频繁的通道转角区域、以及施工过程中你印象中施工质量不太好的区域——这些区域建议100%逐排检查。一般区域可以按10%-20%的比例抽检，但抽检时要覆盖不同排、不同列、不同安装批次。如果抽检中发现超过20%的抽检点存在同类问题，就需要扩大抽检比例甚至全检。
