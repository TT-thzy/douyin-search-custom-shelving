# 用户问题分析

## 表面问题

仓库乱，不知道怎么管。

## 深层原因

一套能落地、能坚持的仓库现场管理方法。

# 决策分析

## 5S 实施步骤

| 步骤 | 内容 | 仓库落地点 |
| ---- | ---- | ---------- |
| 整理 | 区分要与不要 | 清理呆滞料、废品 |
| 整顿 | 定位定量定标识 | 库位编号、区域划线 |
| 清扫 | 清洁现场 | 通道无杂物、货架无灰尘 |
| 清洁 | 标准化保持 | 检查表、责任区 |
| 素养 | 养成习惯 | 班前检查、定期评比 |

## 落地要点

1. 先清呆滞料，腾出空间再划线
2. 库位编号 + 区域标识是整顿的核心
3. 建立周检查表和责任人
4. 目视化（划线、标签、看板）让问题一眼可见

---

# 推荐决策流程

第一步：用一周时间完成整理（清理无用物）。

第二步：按功能分区并编号。

第三步：划通道线、贴标识、上货架。

第四步：建立检查机制，持续保持。

---

# 不建议直接做的事情

✘ 只做表面大扫除，不建立定位标识。

✘ 一次突击完成后无人检查，很快反弹。

✘ 为了 5S 把有用物料当废品清掉。

# FAQ

## FAQ-001

问题：仓库5S从哪里开始？

回答：从"整理"开始，先清掉不用、待报废、呆滞的物料，腾出空间。整理不到位，后面的定位和标识都会白做。

## FAQ-002

问题：5S和目视化是一回事吗？

回答：目视化是 5S 中"整顿"和"清洁"的主要手段。通过划线、标签、看板让状态一目了然，两者配合使用。

# 评论区设计

评论：我们仓库太小，做5S有用吗？

回复：越小的仓库越需要 5S。清理呆滞料、压缩无效空间、货架加高，小仓库的空间利用率提升往往更明显。
