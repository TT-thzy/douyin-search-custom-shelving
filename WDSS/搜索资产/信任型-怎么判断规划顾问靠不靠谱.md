# 决策分析

## 问题产生原因

规划服务没有标准，方案质量凭感觉，客户缺乏判断抓手。

## 可选择方案

方案1：看方案是否算全四项基础（层高/承重/消防/地坪）
方案2：看是否给"不推荐"结论（敢说不买的才是顾问）
方案3：看是否绑定厂家（不绑厂家的更中立）

## 方案比较

| 判断点 | 靠谱表现 | 不靠谱表现 |
| ------ | -------- | ---------- |
| 基础四项 | 逐项算给你看 | 只报价格 |
| 是否敢说不 | 会告诉你"这个方案不合适" | 什么都答应 |
| 是否绑厂家 | 可拿方案去比价 | 强制指定厂家 |
| 交付物 | 现状分析+对比+图纸要点+预算 | 一张报价单 |

## 推荐方案

推荐：用"四项都算 + 敢说不推荐 + 不绑厂家 + 有明确交付物"四条筛选。

## 不推荐方案

不推荐：只看价格选人，或选"什么都行"的方案。

# FAQ问题库

## FAQ-001

问题：顾问出的方案一定能落地吗？
回答：方案交付包含现状分析和图纸要点，你可以拿给任何厂家落地比价；落地质量以你的验收为准。

## FAQ-002

问题：怎么防止顾问和厂家串通？
回答：看方案是否绑定厂家。不绑厂家的方案，你拿去谁家都能做，串通就没意义。
