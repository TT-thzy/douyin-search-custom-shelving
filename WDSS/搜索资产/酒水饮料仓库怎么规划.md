# 用户问题分析

## 表面问题

酒水饮料仓库怎么放？

## 深层原因

饮料整托重量大（通常 800kg～1.5 吨/托）、SKU 相对少、批量大、周转快，且有先进先出要求。

## 用户真正需求

托盘化高密度存储 + 快速周转 + 防倾倒安全。

# 决策分析

## 存储方案选择

| 方案 | 适用 | 说明 |
| ---- | ---- | ---- |
| 横梁式货架 | 多品牌、需随机存取 | 通用性最强 |
| 驶入式货架 | 单一品种大批量 | 密度高，后进先出 |
| 重力式货架 | 有先进先出要求 | 密度 + FIFO 兼得 |
| 地面堆垛 | 周转极快 | 空间利用率低 |

## 关键要点

1. 整托存储，托盘尺寸和堆高统一
2. 有保质期要求的产品优先重力式或规范管理
3. 重托盘货架要核算地坪承载
4. 通道宽度按叉车转弯半径设计

---

# 推荐决策流程

第一步：统计品牌/SKU 数量和单托重量。

第二步：确认是否有先进先出硬性要求。

第三步：按品种数量选横梁式或重力式。

第四步：核算地坪和叉车条件。

---

# 不建议直接做的事情

✘ 小品牌多 SKU 却用驶入式，存取受限。

✘ 重托盘放普通轻型货架，结构超载。

✘ 忽略地坪承载，压裂地面。

# FAQ

## FAQ-001

问题：饮料仓库用什么货架好？

回答：品牌多、SKU 多选横梁式货架；单一品种大批量、可接受后进先出选驶入式；有保质期要求选重力式。先看品种数量和 FIFO 需求。

## FAQ-002

问题：饮料托盘一般多重？

回答：整托饮料通常在 800kg～1.5 吨之间，货架横梁层载和地坪承载都要按最大托盘重量核算。

# 评论区设计

评论：我们代理20多个饮料品牌，用哪种货架？

回复：20多个品牌 SKU 较多，推荐横梁式货架保证独立存取。如果部分大单品周转快、有 FIFO 要求，可以单设重力式区域。
