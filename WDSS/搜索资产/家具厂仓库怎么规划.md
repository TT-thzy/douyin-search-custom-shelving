# 用户问题分析


## 表面问题


家具体积大、形状不规则，仓库怎么放？


---

## 深层原因


可能原因：

- 成品家具占用空间大，同等面积能存放的SKU少
- 不同材质和成品需要不同的存储条件
- 板材、木材等原材料也需要大量存储空间
- 定制家具按订单生产，成品停留时间短但包装和暂存需要空间
- 家具怕磕碰，对存储方式有特殊要求


---

## 用户真正需求


不是简单分类存放。

而是：

针对大体积、多品类、多材料的家具行业特点，建立高效的空间利用方案。

# 决策分析


## 家具仓库存储物品分类


| 类别 | 物品举例 | 存储特点 |
| ---- | -------- | -------- |
| 原材料-木材 | 实木板、人造板、木方 | 体积大，需要防潮，码放要注意平直 |
| 原材料-五金 | 螺丝、铰链、滑轨 | 品种多，小件，分类存放 |
| 原材料-皮料布料 | 真皮、布艺面料 | 卷材存储，需要防潮防尘 |
| 半成品 | 已裁板、已封边板 | 按批次存放，周转快 |
| 成品 | 椅子、桌子、柜子等 | 体积大，怕磕碰，分品类存放 |


---

## 不同品类家具存储方案


品类一：

实木家具

成型后重量大，不可堆叠，需要独立存放空间。

建议：地面平放或大型横梁货架，底部加保护垫。


品类二：

板式家具

平板包装，可堆叠，适合高位货架存储。

建议：横梁货架或高位货架，每托盘放同批次同型号。


品类三：

软体家具

沙发、床垫等体积大但相对较轻。

建议：地面分区存放或阁楼货架，注意防尘。


品类四：

五金配件

品种多、数量大、单个小。

建议：层板货架或零件柜，按规格分类存放。


品类五：

板材

密度板、刨花板、多层板等大幅面材料。

建议：专用板材架或L型存放架，保证板材不变形。


---

## 家具仓库货架选型


| 货架类型 | 适用场景 | 说明 |
| -------- | -------- | ---- |
| 重型横梁货架 | 板式家具、箱装成品 | 承重好，适合托盘化存储 |
| 层板货架 | 五金配件 | 分层分类存放小件 |
| 悬臂货架 | 板材、长料 | 存放木方、板材 |
| 阁楼货架 | 小件成品、配件 | 多层空间，提高利用率 |
| 贯通式货架 | 大批量同型号产品 | 高密度存储 |

## 成品家具存储注意事项


注意一：

防止变形

实木板式家具存放时要平放或垂直靠放，不可长期侧立或斜放。

底部必须垫平，避免受力不均导致变形。


注意二：

防止磕碰

成品家具之间需要保持间距或用软质隔层分开。

通道宽度要足够叉车或搬运设备通过，避免刮蹭。


注意三：

防潮防霉

木材和布艺制品对湿度敏感，仓库需要保持通风干燥。

建议地面做防潮处理，货物离地存放。


注意四：

包装保护

未包装的成品需要在搬运和存放过程中做好表面保护。

批量产品建议标准化包装，便于堆叠和运输。


---

## 家具仓库功能分区


分区一：

原材料区

存放木材、板材、五金配件等生产原料。

靠近生产车间入口，便于领料。


分区二：

半成品暂存区

存放加工中的半成品，周转快。

靠近生产线，动态管理。


分区三：

成品存储区

存放已完成的待出库产品。

按品类和批次分区，留够通道和操作空间。


分区四：

配件包装区

五金配件分拣、包装的区域。

配置操作台和包装设备。

# 不建议做的事


✘ 成品家具直接堆叠，下层压变形。

✘ 木材和五金配件混放在同一区域。

✘ 板材长期倾斜靠放，导致板材弯曲变形。

✘ 仓库不做防潮，木制家具受潮发霉。

✘ 忽略通道宽度，搬运大件成品时刮蹭损坏。

# FAQ


## FAQ-001


问题：

家具仓库用哪种货架最合适？


回答：

家具仓通常需要多种货架组合。板材用悬臂货架，板式成品用重型横梁货架，五金配件用层板货架，大件成品地面分区存放。没有"一种货架解决所有问题"的方案。


---

## FAQ-002


问题：

成品家具可以叠放吗？


回答：

板式家具如果是标准包装（纸箱平装），可以在托盘上按规定高度叠放。实木成品和已组装的家具不建议叠放，应该独立存放在地面或货架上，避免压坏。


---

## FAQ-003


问题：

木材仓库如何防止板材变形？


回答：

板材存放要做到三点：一是水平存放，底部多点支撑保证平整；二是避免直接接触地面，用垫块隔离潮气；三是仓库保持通风，避免湿度剧烈变化导致板材吸湿膨胀。

# 评论区设计


评论：

我们做实木餐桌椅，成品太重太大，货架能放吗？


回答：

实木餐桌椅重量大的可以存放在重型横梁货架上，但要注意层高必须大于成品高度。如果单件过重，也可以地面分区存放配合醒目的库位标识，做好防磕碰保护。


---

评论：

板材架和普通悬臂货架有什么区别？


回答：

板材专用架通常悬臂间距更密，避免板材中间悬空导致弯曲。悬臂长度和承重也根据板材标准尺寸设计。如果用普通悬臂货架存放板材，需要确认悬臂间距是否合适。
