# 用户问题分析

## 表面问题

货物经常出现过期或积压，怎么做到先进先出？

## 深层原因

库位管理靠人工记忆、上架随意、没有批次标识，导致先入库的货被压在后面。

## 用户真正需求

一套从入库、上架到出库都能强制先进先出的管理方法。

# 决策分析

## 管理手段

1. 批次标识：每批入库打上日期/批次号
2. 库位绑定：同批次同库位，禁止混放
3. 出库规则：系统或单据按批次先后排序
4. 库位调整：新批次放货架后侧/下方，旧批次靠前

## 货架结构选择

| 方式 | 适用 | 说明 |
| ---- | ---- | ---- |
| 流利式货架 | 纸箱、周转箱 | 重力滑道天然先进先出 |
| 重力式货架 | 托盘 | 靠坡度实现先进先出 |
| 普通货架 + 管理 | 一般货物 | 靠批次管理和库位规则实现 |
| 驶入式货架 | — | 后进先出，不适合保质期货物 |

---

# 推荐决策流程

第一步：盘点现有货物，清理过期和呆滞品。

第二步：建立批次标识和库位绑定规则。

第三步：规范上架方向（先进先出的货物统一方向）。

第四步：高频、多批次品类评估流利式货架。

---

# 不建议直接做的事情

✘ 有保质期的货用驶入式货架（后进先出）。

✘ 靠工人记性判断先后，不做批次标识。

✘ 新旧批次混放同一库位。

# FAQ

## FAQ-001

问题：先进先出必须用特殊货架吗？

回答：不一定。数量少、批次清晰时靠库位管理就能做到；品种多、批次杂、周转快时，流利式或重力式货架更可靠。

## FAQ-002

问题：流利式货架适合什么货物？

回答：适合纸箱、周转箱等能靠重力滑动的货物，单件重量不宜过大。托盘级货物通常用重力式货架。

# 评论区设计

评论：我们是做食品的，货架怎么选才能先进先出？

回复：纸箱类推荐流利式货架，靠重力滑道实现先进先出；托盘类可考虑重力式。具体还要结合仓库高度和货物重量。
