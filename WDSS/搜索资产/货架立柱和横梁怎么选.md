# 决策分析

## 选型逻辑

| 构件 | 决定因素 | 常见规格参考 |
| ---- | -------- | ------------ |
| 立柱 | 层数、层载、总高 | 轻型 30/40 型、中型 60/80 型、重型 90/100 型及以上 |
| 横梁 | 跨度、单层载重 | 抱焊梁/矩形管，按截面和壁厚分级 |
| 层板 | 货物形态 | 木板、钢层板、格栅板 |

## 判断要点

1. 先算单层最大荷载和横梁跨度
2. 立柱规格要满足总高度 + 层载组合
3. 问供应商要"承载对照表"并核对钢材壁厚
4. 同规格比价，不同规格比质量，不能只比总价

---

# 推荐决策流程

第一步：确定单层荷载和横梁跨度。

第二步：按荷载查立柱横梁规格对照表。

第三步：核对壁厚、材质和表面处理。

第四步：把规格写进合同，验收按规格核对。

---

# 不建议直接做的事情

✘ 只问"几层多少钱"，不问立柱横梁规格。

✘ 让供应商用薄壁横梁凑合，超载变形。

✘ 验收只数数量，不核对规格和壁厚。

# FAQ

## FAQ-001

问题：货架立柱型号怎么看？

回答：型号数字一般代表立柱截面尺寸（如 90×60×2.0 表示宽90mm、深60mm、壁厚2.0mm）。型号越大、壁厚越厚，承载越高。

## FAQ-002

问题：怎么防止供应商用规格不足的货架？

回答：要求报价单写明立柱横梁的截面和壁厚，提供承载对照表，合同里列明规格，验收时抽检复核。规格写不清的报价建议谨慎。

# 评论区设计

评论：供应商说立柱是90型的，够不够用？

回复：90型立柱的承载还取决于壁厚、高度和层载组合。让供应商提供承载对照表，按你的层高和单层荷载核对，别只看型号数字。
