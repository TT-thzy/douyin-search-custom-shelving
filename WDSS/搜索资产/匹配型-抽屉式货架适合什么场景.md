# 用户问题分析

## 表面问题

抽屉式货架是干什么用的？

## 深层原因

模具、钢板等重物平放占地大、搬动危险，需要抽出式存取结构。

## 用户真正需求

安全、省力地存取重而扁平、不宜叠放的货物。

# 决策分析

## 适合场景

| 货物 | 说明 |
| ---- | ---- |
| 模具 | 冲压模、注塑模，抽拉存取免吊装 |
| 钢板/板材 | 平放存储，避免堆叠变形 |
| 刀具/量具 | 精密件分类存放 |
| 大型盘类件 | 刹车盘、齿轮等扁平重件 |

## 不适合场景

- 小件、多品种、高频拣选（选普通货架或阁楼）
- 大体积异形件（超出抽屉尺寸）

---

# 推荐决策流程

第一步：统计货物尺寸、重量和数量。

第二步：确认抽拉式能否替代吊装作业。

第三步：按最大单件重量设计抽屉承载。

第四步：对比抽屉式与地台板堆放的占地和安全。

---

# 不建议直接做的事情

✘ 模具直接堆叠存放，取用时容易砸伤。

✘ 抽屉承重按平均重量设计，超重变形。

✘ 小件货物用抽屉式，单位面积利用率低。

# FAQ

## FAQ-001

问题：抽屉式货架能放多重的模具？

回答：单抽屉承载可从几百公斤到数吨，按最大模具重量定制。抽屉配滚轮和滑道，可抽出 80% 以上便于吊装。

## FAQ-002

问题：抽屉式货架和模具货架一样吗？

回答：抽屉式是模具货架的常见结构形式。模具货架还有层板式、悬臂式等，按模具大小和重量选型。
