# 用户问题分析

## 表面问题

纺织厂仓库应该怎么规划？

## 深层原因

纺织货物形态特殊：布卷长而重、纱线怕压怕潮、坯布怕污染，普通货架方案不完全适用。

## 用户真正需求

按货物形态分区存储，同时解决防潮、防尘和承重问题。

# 决策分析

## 分区域规划

| 区域 | 货物 | 存储建议 |
| ---- | ---- | -------- |
| 原料仓 | 纱线、化纤包 | 托盘 + 横梁式货架，防潮离地 |
| 半成品 | 坯布卷 | 布卷横放托盘，重型货架 |
| 成品仓 | 色布、面料 | 卷装/匹装分类，防尘包装 |
| 辅料仓 | 纸管、包材 | 轻型货架 |

## 关键要点

1. 布卷长件用托盘横放，避免立放变形
2. 纱线怕压，层高和层载要控制
3. 仓库防潮、防尘、防虫是硬要求
4. 按批次管理，配合先进先出

---

# 推荐决策流程

第一步：盘点纱线、布卷、成品的形态和单件重量。

第二步：确认仓库层高和地坪承载。

第三步：分区域选型（原料/半成品/成品）。

第四步：加入防潮防尘措施后整体规划。

---

# 不建议直接做的事情

✘ 布卷竖放堆叠，时间长变形压坏。

✘ 纱线直接落地，受潮发霉。

✘ 所有货物用同一种货架，不考虑形态差异。

# FAQ

## FAQ-001

问题：布卷可以立着放货架吗？

回答：一般不建议。布卷立放受重力影响容易变形，通常横放托盘存储，配合重型货架和叉车作业。

## FAQ-002

问题：纺织仓库要注意什么环境问题？

回答：重点是防潮、防尘、防虫和防火。纺织原料易燃且怕潮，仓库要做好湿度控制和消防分区。

# 评论区设计

评论：我们是织布厂，布卷每个200多斤，用什么货架？

回复：200斤的布卷建议托盘横放，用重型横梁式货架加叉车作业。层高够的话按4层设计，注意单层承重按最大布卷核算。
