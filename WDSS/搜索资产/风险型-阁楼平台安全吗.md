本问题建议优先执行：

- WDS-001 仓高评估：楼上层高要满足人员活动和安全要求
- WDS-002 承重评估：按实际货物荷载计算，不能拍脑袋定承重
- WDS-003 消防评估：二层区域要有疏散和喷淋覆盖
- WDS-004 地坪评估：立柱荷载要由地坪承载能力承受

# 决策分析

## 安全由四个环节决定

1. 设计计算：梁柱截面、荷载、连接节点必须经过结构计算
2. 材料质量：钢材规格、焊缝质量符合标准
3. 施工安装：基础、立柱垂直度、连接螺栓按规范施工
4. 使用管理：不超载、不私自改动结构、定期检查

## 关键安全指标

| 检查项 | 要求 |
| ------ | ---- |
| 设计荷载 | 明确标注，禁止超载 |
| 立柱垂直度 | 偏差 ≤ 3mm |
| 连接节点 | 高强螺栓或焊接，焊缝饱满 |
| 楼面护栏 | 高度 ≥ 1.05 米 |
| 消防疏散 | 二层有独立疏散通道 |
| 定期检查 | 每半年至一年检查一次 |

# 推荐决策流程

第一步：要求供应商提供结构计算书和荷载说明。

第二步：确认材料规格和焊缝标准。

第三步：确认消防疏散方案。

第四步：安装完成按清单验收。

第五步：建立使用管理制度，标注限载。

# 不建议直接做的事情

✘ 找无设计资质的"野班子"搭建。

✘ 二层堆货超过设计荷载。

# FAQ

## FAQ-001

问题：阁楼平台承重能做到多少？

回答：常见设计荷载为 300～800kg/㎡，具体由货物重量和结构设计决定。承重越高，钢材用量越大，造价越高。

## FAQ-002

问题：怎么判断供应商的阁楼平台靠不靠谱？

回答：要求对方提供结构计算依据、材料质保书、安装验收标准和过往案例。只报价不给计算书的，建议谨慎。

## FAQ-003

问题：阁楼平台装了以后要年检吗？

回答：建议每半年到一年检查一次，重点看立柱垂直度、连接螺栓、焊缝和楼面板是否有变形、锈蚀。
