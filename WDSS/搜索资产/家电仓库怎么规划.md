# 用户问题分析

## 表面问题

家电仓库怎么放才不乱？

## 深层原因

家电体积大、重量重、怕磕碰，品类和型号多，地面堆放容易压坏、难找货。

## 用户真正需求

大件货物的托盘化存储 + 按型号的库位管理。

# 决策分析

## 分区域规划

| 区域 | 货物 | 存储建议 |
| ---- | ---- | -------- |
| 整机仓 | 冰箱、洗衣机等大件 | 托盘 + 重型横梁货架，叉车作业 |
| 小家电仓 | 微波炉、吸尘器等 | 中型货架或阁楼货架，人工拣选 |
| 配件仓 | 遥控器、说明书 | 轻型货架 |
| 退换货区 | 返修机 | 独立隔离区域 |

## 关键要点

1. 大件必须托盘化，避免直接堆叠压坏
2. 按型号分区，库位绑定型号
3. 高价值商品考虑防尘包装和监控
4. 出入库通道宽度满足叉车转弯

---

# 推荐决策流程

第一步：区分大件和小件，分开规划。

第二步：大件核算托盘载重和叉车通道。

第三步：小件按 SKU 数量选阁楼或中型货架。

第四步：建立型号库位管理。

---

# 不建议直接做的事情

✘ 大件家电直接叠放，压坏外壳。

✘ 大件小件混放，找货困难。

✘ 忽略退换货区域，占用正常库位。

# FAQ

## FAQ-001

问题：冰箱洗衣机用什么货架？

回答：整机用托盘加横梁式重型货架，叉车存取。注意单托盘的重量和尺寸，横梁层载按最大机型核算。

## FAQ-002

问题：小家电仓库用阁楼货架合适吗？

回答：合适。小家电 SKU 多、单件轻、人工拣选，阁楼货架能增加存储面积，比平面中型货架空间利用率更高。

# 评论区设计

评论：我们做小家电的，SKU有200多个，怎么规划？

回复：小家电 SKU 多、单件轻，推荐阁楼货架或中型货架按型号分区，配合库位编号。层高够的话阁楼货架能大幅增加面积。
