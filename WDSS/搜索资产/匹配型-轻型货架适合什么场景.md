# 决策分析

## 适合场景

| 场景 | 说明 |
| ---- | ---- |
| 轻小件存储 | 纸箱、小包装、备件，单层 ≤150kg |
| 电商拣货仓 | 人工拣货、品种多、批量小 |
| 办公/工具库 | 文件、样品、工具存放 |
| 门店仓库 | 汽配、五金等中小型门店备货 |

## 不适合场景

- 托盘 + 叉车作业（应选重型横梁式）
- 单层荷载超过 150kg 的重货
- 需要高密度、高层存储的仓库

---

# 推荐决策流程

第一步：确认货物单件重量和每层数量。

第二步：确认作业方式（人工 / 叉车）。

第三步：轻型够用就不选重型，避免浪费。

---

# 不建议直接做的事情

✘ 轻型货架放重货，横梁弯曲。

✘ 用轻型货架配合叉车作业。

# FAQ

## FAQ-001

问题：轻型货架能放多重的货？

回答：单层一般 50～150kg。放轻小件、纸箱没问题，重货建议直接选重型货架。

## FAQ-002

问题：轻型货架和角钢货架是一回事吗？

回答：角钢货架是轻型货架的一种常见形式，靠蝴蝶孔插接，安装方便、价格低，适合轻小件场景。

# 评论区设计

评论：我们的货最重20斤一箱，适合轻型货架吗？

回复：适合。20斤/箱的货物轻型货架完全够用，注意每层堆放的箱数别让单层总重超过150kg。
