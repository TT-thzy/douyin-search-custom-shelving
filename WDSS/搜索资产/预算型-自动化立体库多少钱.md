# 决策分析

## 投资量级参考

| 规模 | 参考投资 | 说明 |
| ---- | -------: | ---- |
| 小型（500 库位以内） | 150～300 万元 | 以货架、堆垛机、输送线为主 |
| 中型（500～2000 库位） | 300～800 万元 | 含 WMS、控制系统 |
| 大型（2000 库位以上） | 800 万元以上 | 含分拣、输送、软件整体方案 |

> 注意：投资包含货架、堆垛机、输送设备、WMS 软件、安装调试和土建配合，不能只看设备报价。

## 决策要点

1. 日出入库量是否值得自动化（一般建议日处理 1000 托以上再考虑）
2. 仓库层高是否达到 8 米以上
3. 货物是否托盘化、标准化
4. 是否接受 6～12 个月的实施周期
5. 未来 5 年业务是否稳定增长

---

# 推荐决策流程

第一步：测算当前出入库量和未来增长。

第二步：对比自动化与普通货架 + 人工的五年总成本。

第三步：确认仓库高度、地坪和消防条件。

第四步：用投资回收周期做立项判断。

# FAQ

## FAQ-001

问题：自动化立体库多少钱一个库位？

回答：按库位折算通常在 3000～8000 元/库位，规模越大单库位成本越低。但库位单价不能单独决策，要结合出入库效率和人工成本算总账。

## FAQ-002

问题：小企业能上自动化立体库吗？

回答：取决于出入库量和货物标准化程度。如果日出入库量小、货物规格杂乱，自动化投入回收期会很长，普通货架加管理系统往往更划算。

## FAQ-003

问题：自动化立体库和阁楼货架怎么选？

回答：两者不是一类方案。自动化立体库解决"高效率吞吐"，投资高；阁楼货架解决"增加存储面积"，投资低。先明确要解决效率问题还是面积问题。
