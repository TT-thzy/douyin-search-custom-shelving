# 决策分析

## 安装费构成

1. 人工费：按货架吨位或工时计算
2. 吊装设备费：高位货架需要登高设备
3. 辅材费：垫片、膨胀螺栓、防撞件等
4. 差旅食宿：异地项目常见

## 参考标准

| 货架类型 | 安装费参考（占货架货价比例） | 说明 |
| -------- | ----------------------------: | ---- |
| 轻型货架 | 8～15% | 人工安装，无需设备 |
| 中型货架 | 10～18% | 需要登高梯 |
| 重型/横梁货架 | 12～20% | 需要叉车配合吊装 |
| 阁楼货架/平台 | 15～25% | 涉及楼面板和高空作业 |

> 安装费包含在总价内或单列均可，关键是要在合同中写清安装范围和验收标准。

# 推荐决策流程

第一步：确认安装是否由厂家负责。

第二步：问清安装费包含哪些内容（人工、辅材、设备、食宿）。

第三步：确认安装工期和验收标准。

第四步：对比报价时统一口径，再比总价。

# 不建议直接做的事情

✘ 只问"安装费多少钱"，不问包含什么。

# FAQ

## FAQ-001

问题：货架安装费一般占货价多少？

回答：轻型货架约 8～15%，重型货架约 12～20%，阁楼类 15～25%。超过这个区间需要问清原因，可能是吊装难度大或异地差旅。

## FAQ-002

问题：安装费可以自己找人装吗？

回答：可以，但风险自担。货架安装涉及垂直度、水平度、安全销等专业要求，安装不合格可能导致验收不过或使用隐患。建议由货架厂家或有资质的安装团队负责。

# 评论区设计

评论：我们的货架报价里安装费占了20%，正常吗？

回复：要看货架类型和现场条件。如果是重型货架、需要吊装，20%属于正常范围；如果是普通轻型货架，建议问清费用构成。
