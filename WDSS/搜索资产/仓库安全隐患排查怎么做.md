# 决策分析

## 排查清单（五大类）

| 类别 | 排查内容 |
| ---- | -------- |
| 消防 | 灭火器、喷淋、疏散通道、易燃物存放 |
| 货架 | 立柱变形、横梁弯曲、超载、防撞设施 |
| 电气 | 私拉电线、插座过载、充电区域 |
| 作业 | 叉车管理、登高作业、人车分流 |
| 环境 | 地面油污、堆垛倾斜、通道堵塞 |

## 排查流程

1. 建立检查表，按区域逐项检查
2. 发现问题拍照记录，定整改人和期限
3. 重大隐患立即隔离相关区域
4. 复查闭环，纳入台账

---

# 推荐决策流程

第一步：按消防、货架、电气、作业、环境五类建表。

第二步：每月全面排查一次，日常周检。

第三步：隐患分级（立即整改/限期整改/长期关注）。

第四步：整改后复查并记录。

---

# 不建议直接做的事情

✘ 检查走过场，只填表不整改。

✘ 发现货架变形、超载先"凑合用"。

✘ 消防通道被货物占用还习以为常。

# FAQ

## FAQ-001

问题：仓库隐患排查多久做一次？

回答：建议日常周检、每月全面排查。消防设施和疏散通道每周看一次，货架和电气重点区域每月专项检查。

## FAQ-002

问题：排查出的隐患怎么管理？

回答：分级管理：立即整改（如通道堵塞）、限期整改（如灭火器过期）、长期关注（如货架轻微损伤）。每项都定责任人、期限和复查。

# 评论区设计

评论：我们仓库货架被叉车撞了几次，怎么查隐患？

回复：碰撞部位要重点检查立柱垂直度和横梁变形，受损区域先隔离。同时加装防撞护栏和立柱护套，把碰撞风险从源头降下来。
