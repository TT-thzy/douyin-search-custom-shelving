# 用户问题分析

## 表面问题

买货架是不是直接找厂家报个价就行？

## 深层原因

怕多花钱：怕买多、买错、装完利用率低；怕被厂家引导买贵配置。

## 用户最终目标

用最少的钱买到"正好够用"的存储方案。

---

# 决策分析

## 问题产生原因

货架是"按需定制"的东西，不先规划就采购 = 拿自己的仓库条件去套别人的方案。

## 可选择方案

方案1：先规划后采购（推荐）
方案2：直接采购
方案3：先采购后改造（最贵）

## 方案比较

| 方案 | 优点 | 缺点 | 适用场景 |
| ---- | ---- | ---- | -------- |
| 先规划后采购 | 配置精准、不浪费 | 多一步规划投入 | 扩容/改造/选型不确定 |
| 直接采购 | 快 | 易错配、返工 | 需求非常明确 |
| 先采购后改造 | 无 | 双重成本 | 不推荐 |

## 推荐方案

推荐：先规划。规划能回答"要不要买、买多少、买哪种"，返工成本远高于规划费。

## 不推荐方案

不推荐：不看层高承重直接下单。

# FAQ问题库

## FAQ-001

问题：规划要钱吗？是不是套路？
回答：方向性建议免费；详细方案按工作量明码标价，先出东西再谈钱。

## FAQ-002

问题：不规划直接买，真会浪费吗？
回答：层高6米只堆2米、通道留太宽、货架选错类型，都是常见的浪费，返工成本往往高于规划费。
