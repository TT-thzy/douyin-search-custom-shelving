# 用户问题分析

## 表面问题

冷库货架和常温货架有区别吗？

## 深层原因

低温、高湿、结霜环境对钢材和安装有特殊要求，用普通货架容易出问题。

## 用户真正需求

确认冷库货架的材质、防腐、安装要点，避免二次改造。

# 决策分析

## 核心区别

| 对比项 | 常温货架 | 冷库货架 |
| ------ | -------- | -------- |
| 表面处理 | 普通喷塑 | 高防腐（镀锌/加强喷涂） |
| 钢材选择 | 常规 Q235 | 注意低温冲击性能 |
| 地坪 | 常规 | 防冻防裂处理 |
| 安装 | 常规 | 注意结霜、滑倒、高空低温作业 |
| 维修 | 随时 | 停机检修成本高，前期要选好 |

## 冷库货架选择要点

1. 高湿环境优先镀锌或高防腐处理
2. 速冻库（-18℃ 以下）确认钢材低温性能
3. 货架设计预留结霜空间，避免堆货过满
4. 照明和通道按低温作业考虑

---

# 推荐决策流程

第一步：确认冷库温度区间（冷藏 0~8℃ / 冷冻 -18℃ 及以下）。

第二步：明确货物形态（托盘 / 纸箱 / 散货）。

第三步：选择高防腐货架并确认低温性能。

第四步：把停机安装风险计入工期计划。

---

# 不建议直接做的事情

✘ 直接把常温货架装进冷库，防腐不够生锈。

✘ 忽略冷库地面防冻，地面开裂影响货架稳定。

✘ 冷冻库用普通钢材不评估低温脆断风险。

# FAQ

## FAQ-001

问题：冷库货架为什么要贵一些？

回答：因为需要更高等级的防腐处理和低温性能材料，加上冷库内安装效率低、环境特殊，整体造价会高于同规格常温货架。

## FAQ-002

问题：常温货架能用多久？

回答：常温货架一般 10 年以上，冷库环境下因高湿结霜，普通喷涂货架可能 3～5 年就明显锈蚀，所以冷库要选镀锌或高防腐处理。

# 评论区设计

评论：-18度的冷冻库用普通喷塑货架行吗？

回复：不建议。-18℃ 高湿环境普通喷塑容易脱落生锈，建议选镀锌或高防腐货架，并确认钢材低温性能。
