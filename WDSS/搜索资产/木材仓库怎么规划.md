# 用户问题分析

## 表面问题

木材仓库怎么放？

## 深层原因

木材长（4 米以上常见）、重、怕潮怕变形，板材叠放压弯，长料立放危险。

## 用户真正需求

长料和板材的安全存放 + 防潮防火管理。

# 决策分析

## 分区域规划

| 区域 | 货物 | 存储建议 |
| ---- | ---- | -------- |
| 原木/长料区 | 木方、圆木 | 架空码放，通风防潮 |
| 板材区 | 人造板、实木板 | 平放托盘，层板货架或地台板 |
| 成品区 | 半成品件 | 横梁货架，按规格分区 |
| 干燥/防火区 | 待干燥材 | 独立分区，严格防火 |

## 关键要点

1. 木材必须架空、通风，离地防潮
2. 长料横放固定，防止滑落伤人
3. 木材仓库防火是重中之重，消防分区和通道要专门设计
4. 板材平放减少变形，垛高按含水率控制

# 推荐决策流程

第一步：区分长料、板材、成品的形态。

第二步：确认单件重量和仓库层高。

第三步：长料区做固定架，板材区做平放托盘。

第四步：消防和防潮同步设计。

# 不建议直接做的事情

✘ 长料竖放靠墙，倾倒伤人风险高。

✘ 板材叠放过高，底部变形。

✘ 木材仓库消防设施不足，火灾蔓延快。

# FAQ

## FAQ-001

问题：4米长的木方怎么存放？

回答：用长料架或托盘横放固定，架空通风。不要竖放靠墙，也不要叠放过高，存取时注意防滑落。

## FAQ-002

问题：木材仓库防潮怎么处理？

回答：木材要架空离地、保持通风，湿度控制在木材平衡含水率附近，板材区可做地面防潮层。潮湿地区要配除湿。

# 评论区设计

评论：我们做板材贸易，仓库500平，怎么放不容易变形？

回复：板材要平放托盘、控制垛高，底部架空防潮。建议按规格分区，重板在下、大板在下，避免长期受压变形。
