# 用户问题分析

## 表面问题

仓库有老鼠、虫子，货物被咬坏污染。

## 深层原因

货物散放离地、卫生死角多、门窗缝隙大、没有检查机制。

## 用户真正需求

建立物理隔离为主的防鼠防虫体系，减少药物依赖。

# 决策分析

## 防治手段

| 手段 | 说明 |
| ---- | ---- |
| 离地存放 | 托盘/货架，货物不落地不靠墙 |
| 封闭隔离 | 门窗密封、挡鼠板、防虫网 |
| 环境清洁 | 及时清废料，不留食物源 |
| 定期检查 | 布设粘鼠板、诱虫灯并记录 |
| 专业消杀 | 定期请消杀公司处理 |

## 重点区域

1. 门缝、墙角、管线穿墙处
2. 货物堆垛底部（留出检查空间）
3. 卸货区（易带入虫源）
4. 垃圾和废料暂存区

---

# 推荐决策流程

第一步：排查鼠虫进入通道（门、窗、孔洞）。

第二步：货物全部离地存放，留检查间隙。

第三步：布设监测点并记录密度。

第四步：定期专业消杀 + 环境治理。

---

# 不建议直接做的事情

✘ 只靠撒药，不堵源头，反复复发。

✘ 货物贴地贴墙堆放，检查不到虫害。

✘ 鼠虫密度高时不敢声张，污染扩大。

# FAQ

## FAQ-001

问题：仓库防鼠最关键的措施是什么？

回答：封堵进入通道。老鼠能钻过 6mm 的缝隙，门缝、孔洞、墙角都要封堵，配合挡鼠板和离地存放。

## FAQ-002

问题：食品仓库能用药灭鼠吗？

回答：食品仓库尽量用物理方法（粘鼠板、捕鼠笼、挡鼠板）和低毒饵站，饵站要有专人管理并记录，避免污染食品。
