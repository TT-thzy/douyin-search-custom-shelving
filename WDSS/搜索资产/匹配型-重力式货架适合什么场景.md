# 决策分析

## 适合场景

| 场景 | 说明 |
| ---- | ---- |
| 大批量、少品种 | 同种托盘多，适合一条轨道多托盘 |
| 先进先出要求 | 靠重力滑道天然实现 FIFO |
| 高密度存储 | 通道少、密度高于横梁式 |
| 冷库 | 密度高、通道少，可减少冷量流失 |

## 不适合场景

- SKU 多、需要随机存取 → 选横梁式
- 托盘规格不统一 → 重力轨道适应性差
- 货物不宜倾斜滑动（易碎、滚动）→ 不适合

---

# 推荐决策流程

第一步：确认 SKU 数量和托盘规格是否统一。

第二步：确认是否有先进先出硬性要求。

第三步：确认仓库深度是否足够放滑道。

第四步：对比重力式与横梁式/流利式的密度和造价。

---

# 不建议直接做的事情

✘ SKU 多还选重力式，存取率受限制。

✘ 托盘规格不统一就上重力轨道。

✘ 忽略重力式单侧出入库的作业规则。

# FAQ

## FAQ-001

问题：重力式货架和流利式货架有什么区别？

回答：重力式是托盘级存储（叉车存取），流利式是箱级拣选（人工取货）。按存储单元选，托盘用重力式，纸箱用流利式。

## FAQ-002

问题：重力式货架能实现先进先出吗？

回答：可以。货物从一端放入，靠重力滑到另一端取出，天然满足先进先出，适合有保质期要求的场景。

# 评论区设计

评论：我们是饮料仓库，托盘多品种少，适合重力式吗？

回复：很适合。饮料托盘规格统一、批量大、有先进先出需求，重力式比横梁式密度更高，还能减少冷库或常温仓的通道空间。
