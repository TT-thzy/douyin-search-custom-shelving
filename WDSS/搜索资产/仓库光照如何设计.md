# 用户问题分析


## 表面问题


仓库灯光不够亮，货架下面暗。


---

## 深层原因


可能原因：

- 货架高度较高，顶部灯具被货架遮挡
- 原有照明设计未考虑货架布局
- 灯具老化，光衰严重
- 灯具位置与货架通道不对应
- 只关注了照度大小，忽略了光线均匀度


---

## 用户真正需求


不是更亮的灯。

而是：

在货架环境中实现均匀、无死角的照明，保障作业安全和拣选准确率。

| 出入库区 | 200-300 | 验货和装卸 |
| 办公区 | 300-500 | 日常办公 |

## 货架布局对照明的影响


影响一：

货架遮挡光线

高货架会阻挡顶部灯具的光线，导致货架下层和内部光线不足。

解决：在通道上方沿通道方向布置线性灯具。


影响二：

通道宽度

通道越窄，光线越容易被两侧货架遮挡。

解决：窄通道需要更高密度的灯具布置。


影响三：

货架高度

货架越高，底部光线衰减越严重。

解决：高货架可考虑分层补光，在中层加装灯具。

## 照明布局方案


方案一：

通道顶部线性布置

沿货架通道正上方安装LED线条灯，灯具与通道方向一致。

适合：常规货架仓库。

优点：光线直接照入通道，利用率高。


方案二：

均匀网格布置

在整个仓库顶部按均匀间距布置灯具。

适合：开放区域，没有高大货架遮挡。

优点：整体照度均匀。


方案三：

分层补光

在高层货架的中下层增加补充照明。

适合：高度超过8米的货架区域。

优点：解决底部光线不足的问题。


方案四：

感应式照明

安装人体感应或移动感应开关，有人或叉车经过时自动亮起。

适合：低频出入库区域。

优点：节能效果显著。


---

## 照明与货架配合要点


| 货架类型 | 照明要点 |
| -------- | -------- |
| 横梁货架 | 通道上方线性布置，注意货架高度对底部照度的影响 |
| 阁楼货架 | 上下层分别设计照明，下层尤其需要补充灯光 |
| 驶入式货架 | 内部通道狭窄且深，需在通道内布置灯具 |
| 悬臂货架 | 长料不遮挡光线，常规布置即可 |
| 穿梭车货架 | 通道内需布置灯具，保证操作安全 |

# 推荐设计流程


第一步：

确定货架布局。

先有货架规划方案，再设计照明。

↓

第二步：

划分照明区域。

根据功能区域确定各区域的照度要求。

↓

第三步：

选择灯具类型。

根据仓高、环境和节能要求选择灯具。

↓

第四步：

计算灯具数量和间距。

保证照度达标且光线均匀。

↓

第五步：

安装调试。

安装后进行照度实测，调整不达标区域。

# 不建议做的事


✘ 先装灯后规划货架，灯具被货架遮挡。

✘ 只看瓦数不看光效，瓦数大不一定亮。

✘ 忽略光衰，灯具用了好几年不换照度明显下降。

✘ 只在仓库中间装灯，靠墙区域一片暗。

✘ 所有区域统一照度，不区分作业区和存储区。

# FAQ


## FAQ-001


问题：

仓库照明用多少瓦的灯合适？


回答：

瓦数不是选择灯具的唯一标准，需要看光效（每瓦流明数）。100W的LED工矿灯（光效120lm/W）比150W的金卤灯（光效70lm/W）更亮。建议根据目标照度、安装高度和灯具间距来选型。


---

## FAQ-002


问题：

阁楼货架下层很暗怎么解决？


回答：

阁楼货架下层空间高度受限，建议在楼板下方安装LED线条灯或面板灯，灯具应与通道走向一致，保证通道和拣选面都有足够照度。


---

## FAQ-003


问题：

仓库灯24小时开着电费太高，怎么节能？


回答：

建议采用分区控制，不同区域按作业时段开灯。低频区域安装感应开关，人来灯亮人走灯暗。同时更换高光效LED灯具，在保证照度的前提下降低能耗。

# 评论区设计


评论：

我们仓库15米高，货架12米，灯装在顶上下面基本没光怎么办？


回答：

15米仓高12米货架的情况，建议在货架中层（约6-8米高度）增加补充照明，同时在通道正上方安装聚光角度较小的工矿灯，减少光线散射。


---

评论：

LED灯比荧光灯能省多少电？


回答：

同样照度下，LED灯具通常比荧光灯节能50%-60%。虽然LED灯具采购单价略高，但按2-3年电费和维修成本计算，综合成本通常低于荧光灯。
