# 决策分析

## 荷载计算逻辑

楼面均布荷载 = 货物重量 ÷ 存放面积 + 人员 + 设备 + 安全余量

| 场景 | 建议设计荷载 | 说明 |
| ---- | ------------ | ---- |
| 轻小件、人工拣货 | 300～400kg/㎡ | 常见电商、电子件 |
| 一般纸箱货物 | 500kg/㎡ | 多数仓库的默认档 |
| 叉车上楼/重货 | 800kg/㎡ 以上 | 结构加强，造价显著增加 |

## 计算步骤

1. 统计楼上最大货物总量
2. 除以实际存放面积得均布荷载
3. 加上人员、设备和安全系数（一般 1.2～1.5）
4. 按立柱间距验算梁柱截面

# 推荐决策流程

第一步：明确楼上用途（存储/作业/叉车）。

第二步：核算最大存放重量和面积。

第三步：确定设计荷载并留安全余量。

第四步：要求供应商提供荷载计算依据。

# FAQ

## FAQ-001

问题：阁楼平台每平米承重500公斤够用吗？

回答：对多数纸箱、电子件仓库够用。具体要算你楼上实际最大存放重量除以面积，再留安全余量，不能拍脑袋。

## FAQ-002

问题：叉车能上阁楼平台吗？

回答：可以，但需要按叉车重量、轮压和作业方式做专项设计，平台荷载通常要做到 800kg/㎡ 以上，造价会明显增加。

# 评论区设计

评论：我们楼上只放小件，500公斤每平够吗？

回复：先算楼上最大存放重量除以面积。轻小件一般 300～400kg/㎡ 就够，500kg/㎡ 通常有富余，不必盲目加高承重。
