# 决策分析

## 问题产生原因

行业收费不透明：有免费引流、有打包收费、有按面积收费，用户分不清。

## 可选择方案

方案1：方向免费 + 详案按工作量收费（推荐，明码标价）
方案2：打包按面积收费（简单但可能过度）
方案3：完全免费（警惕绑定推销）

## 方案比较

| 模式 | 优点 | 缺点 | 适用场景 |
| ---- | ---- | ---- | -------- |
| 方向免费+详案收费 | 透明、先建立信任 | 详案需付费 | 需要决策支持 |
| 按面积打包 | 报价简单 | 可能过度配置 | 标准仓库 |
| 完全免费 | 无成本 | 质量/立场存疑 | 初步了解 |

## 推荐方案

推荐：方向性建议免费，详细方案明码标价、先出东西再谈钱。

## 不推荐方案

不推荐：为"免费"接受绑定采购。
