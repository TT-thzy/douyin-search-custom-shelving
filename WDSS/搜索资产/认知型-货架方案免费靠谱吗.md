# 决策分析

## 问题产生原因

行业普遍"免费出方案"吸引客户，方案质量参差，部分以方案换订单。

## 可选择方案

方案1：免费方向建议 + 付费详细方案（推荐，顾问模式）
方案2：厂家免费出方案（快，但方案自带推销属性）
方案3：纯免费方案（谨慎，羊毛出在羊身上）

## 方案比较

| 方案 | 优点 | 缺点 | 适用场景 |
| ---- | ---- | ---- | -------- |
| 免费方向+付费详案 | 中立、质量可控 | 详细方案需付费 | 需要决策支持 |
| 厂家免费方案 | 免费、落地快 | 与采购绑定，可能过度配置 | 需求明确 |
| 纯免费方案 | 免费 | 质量无保障 | 简单了解 |

## 推荐方案

推荐：把"免费"定义清楚——方向建议免费，详细方案明码标价，先出东西再谈钱。

## 不推荐方案

不推荐：因为免费就接受"必须从对方采购"的绑定。

# FAQ问题库

## FAQ-001

问题：你们免费方案和付费方案差在哪？
回答：免费给方向和判断标准；付费出完整方案（现状分析、对比、图纸要点、预算范围），按工作量收费。

问题：免费方案会不会强制我在指定厂家买？
回答：不会。方案交付后你拿去哪家比价都行，顾问不绑厂家。
