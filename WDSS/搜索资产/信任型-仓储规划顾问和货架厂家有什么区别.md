# 决策分析

## 问题产生原因

行业角色混在一起：厂家自称"免费规划"，顾问被误认为"中间商"。

## 可选择方案

方案1：厂家（产品 + 免费方案，但方案自带推销）
方案2：顾问（决策 + 中立方案，再对接工厂落地）
方案3：厂家 + 独立验收（先顾问后厂家，最稳）

## 方案比较

| 维度 | 厂家 | 顾问 |
| ---- | ---- | ---- |
| 立场 | 卖自家产品 | 你的需求 |
| 方案 | 免费但自带推销 | 中立、可比价 |
| 强项 | 生产、安装、价格 | 选型、规划、避坑 |
| 风险 | 过度配置 | 需支付咨询费 |

## 推荐方案

推荐：先顾问做方向判断，再拿方案找厂家比价落地。

## 不推荐方案

不推荐：参数没确认就在厂家下单。

# FAQ问题库

## FAQ-001

问题：顾问是不是就是中间商？
回答：不是。顾问出决策方案，不靠差价赚钱，交付物是方案本身，你可以拿方案去任何厂家落地。

## FAQ-002

问题：找了顾问还要找厂家吗？
回答：要。顾问管决策，厂家管生产安装；先决策后落地，各司其职。
