本问题建议优先执行：

- WDS-001 仓高评估：阁楼货架必须有足够有效层高（一般不低于 4.5 米）

- WDS-003 消防评估：二层空间消防要求影响方案

# 决策分析

## 价格构成

阁楼货架价格主要由四部分决定：

1. 楼面面积和承重等级（核心变量）
2. 货架立柱、横梁的材料规格
3. 楼面板材质（木板 / 钢格板 / 冷轧钢板）
4. 安装、运输和消防配合费用

## 参考价格区间

| 承重等级 | 参考造价（元/㎡） | 适用场景 |
| -------- | ---------------: | -------- |
| 300kg/㎡ | 350～500 | 轻小件、人工拣货 |
| 500kg/㎡ | 500～700 | 一般电子件、纸箱存储 |
| 800kg/㎡ | 700～1000 | 较重货物、叉车辅助上货 |

> 注意：以上为方案参考区间，实际价格需结合仓库柱距、层高、消防条件确定，不同地区施工费差异较大。

# 推荐决策流程

不要直接询价。

建议顺序：

第一步：确认仓库层高和可用面积。

第二步：确认货物类型和单层承重要求。

第三步：确认是否需要叉车上楼。

第四步：完成 WDS-001/002/003 评估。

第五步：再让供应商按明确参数报价。

# 不建议直接做的事情

✘ 不做消防确认就定方案。

✘ 忽略安装和物流费用只比货价。

# FAQ

## FAQ-001

问题：阁楼货架多少钱一平方？

回答：一般 350～1000 元/㎡，主要取决于承重等级和楼面板材质。直接报"每平方多少钱"没有意义，因为承重标准不同，价格可能差一倍。

## FAQ-002

问题：阁楼货架和阁楼平台哪个便宜？

回答：同面积下阁楼货架通常更便宜，因为它是货架承重结构加楼面板；阁楼平台是独立钢平台，承重和造价更高。具体选哪个看是否需要叉车上楼和重货存储。

## FAQ-003

问题：100 平方的阁楼货架大概多少钱？

回答：按 500kg/㎡ 承重估算约 5～7 万元，但需要确认仓库高度、柱距和消防条件后才能给出准确范围。
