# 用户问题分析

## 表面问题

担心仓库货架倒塌造成人员伤亡和财产损失。

## 深层原因

- 听说过或见过货架倒塌事故
- 仓库货架已经使用多年，不确定是否安全
- 没有定期检查制度
- 不知道货架安全标准是什么
- 采购时只关注价格忽略了安全配置

## 用户真正需求

建立可执行的货架安全管理体系，不是简单问"安不安全"。

# 决策分析

## 货架倒塌常见原因

| 原因 | 说明 | 占比估测 |
|------|------|---------|
| 超载使用 | 实际存放重量超过设计荷载 | 最常见 |
| 碰撞损伤 | 叉车撞击导致立柱变形 | 常见 |
| 安装不当 | 螺栓松动、连接件缺失 | 较常见 |
| 设计缺陷 | 初期方案承重计算不足 | 较少 |
| 地面问题 | 地坪沉降导致货架倾斜 | 较少 |
| 腐蚀老化 | 长期使用未维护 | 较少 |

## 预防措施

**采购阶段：**
- 明确荷载需求，不为了省钱降低承重规格
- 确认供应商提供结构计算和设计图纸
- 选用符合标准的产品

**安装阶段：**
- 立柱安装牢固，连接件齐全
- 安装完成后做荷载测试

**使用阶段：**
- 建立定期检查制度（每月至少一次外观检查）
- 严格控制单层荷载
- 叉车通道安装防撞护栏
- 发现立柱变形立即更换
- 货架上有荷载标识牌

## 推荐流程

安全自查 → 专业检测 → 确定问题 → 加固或更换 → 建立检查制度

# 不建议做的事

✘ 为降低成本取消安全附件
✘ 超期使用已经变形的货架
✘ 自行焊接修复损坏的立柱
✘ 只在事故后才检查货架

# FAQ

## FAQ-001

问题：货架一般多久检查一次？

回答：建议每月做一次外观检查（立柱变形、螺栓松动、连接件状态），每年做一次全面安全检查。

## FAQ-002

问题：立柱撞弯了还能用吗？

回答：不建议继续使用。变形的立柱承载能力已下降，存在安全风险，应及时更换。

## FAQ-003

问题：旧仓库货架怎么判断是否还能用？

回答：需检查立柱垂直度、横梁变形情况、连接件状态、焊接点、地脚螺栓等。建议由专业人员检测评估。

# 评论区设计

评论：我们仓库货架用了快十年了，怎么判断安不安全？

回复：十年是一个需要重点评估的时间点。建议检查立柱垂直度、横梁变形、连接件松动、地脚螺栓状态，最好请专业人员现场检测。
