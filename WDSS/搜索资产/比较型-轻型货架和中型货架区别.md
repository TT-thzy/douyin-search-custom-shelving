# 决策分析

## 核心区别

| 对比项 | 轻型货架 | 中型货架 |
| ------ | -------- | -------- |
| 单层承重 | 约 50～150kg | 约 150～350kg |
| 立柱形式 | 蝴蝶孔插接 | 插接或螺栓连接，截面更大 |
| 层板 | 薄板/木板 | 厚板/加强板 |
| 适用货物 | 小件、纸箱、轻包材 | 中件、整箱、较重纸箱 |
| 参考价格 | 较低 | 中 |

## 选择逻辑

1. 先称单件货物重量，再加安全系数
2. 确定每层放几件，算出单层总重
3. 单层总重 ≤ 150kg 选轻型，150～350kg 选中型
4. 超过 350kg 考虑重型货架

---

# 推荐决策流程

第一步：统计货物单件重量和单层存放数量。

第二步：计算单层最大荷载。

第三步：按荷载选型，宁留余量不超载。

第四步：对比报价时统一层数和承重口径。

---

# 不建议直接做的事情

✘ 只看货架价格，不看承重等级。

✘ 轻型货架当中型用，超载变形。

✘ 为了省几百元放弃安全余量。

# FAQ

## FAQ-001

问题：轻型货架单层能放多重？

回答：一般 50～150kg，具体看规格。放重货会弯曲变形，选型前先算单层总重。

## FAQ-002

问题：中型货架和轻型货架价格差多少？

回答：同规格面积下中型货架通常贵 20～40%，多花的部分主要是立柱和层板的钢材用量。

# 评论区设计

评论：我们放的都是十几斤的小件，轻型够用吗？

回复：够用，但要注意每层放多少件。如果一层堆几十件，加起来可能超 150kg，建议先算单层总重再定。
