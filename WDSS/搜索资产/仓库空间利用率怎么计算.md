# 决策分析

## 常用指标

| 指标 | 公式 | 意义 |
| ---- | ---- | ---- |
| 面积利用率 | 实际使用面积 ÷ 总面积 | 通道、死角是否过多 |
| 空间利用率 | 货物体积 ÷ 仓库容积 | 高度是否被浪费 |
| 库位利用率 | 已用库位 ÷ 总库位 | 货架配置是否合理 |
| 存储密度 | 货物量 ÷ 仓库面积 | 综合存储水平 |

## 常见浪费点

1. 通道过宽（叉车通道可以压缩）
2. 货物只堆一层，高度浪费
3. 死角区没有利用
4. 呆滞料占用黄金库位

---

# 推荐决策流程

第一步：量出实际使用面积和货物总体积。

第二步：算出面积利用率和空间利用率。

第三步：对照行业经验值判断差距。

第四步：针对最大的浪费点做优化。

---

# 不建议直接做的事情

✘ 只看"仓库满了"就决定租新仓。

✘ 忽略高度利用率，只算地面面积。

✘ 为压缩通道牺牲作业安全。

# FAQ

## FAQ-001

问题：仓库空间利用率多少算正常？

回答：地面面积利用率一般 60～75%，高度利用率看层高。层高 5 米以上只用地面堆放，空间利用率通常不足 40%，提升空间很大。

## FAQ-002

问题：仓库利用率低怎么提升？

回答：先清呆滞料，再压缩无效通道，最后利用高度（货架、阁楼）。多数仓库先做管理优化就能提升 20% 以上。

回复：6米层高只堆地面，空间利用率通常不到一半。建议先做 WDS-001 仓高评估，用货架或阁楼把垂直空间用起来。
