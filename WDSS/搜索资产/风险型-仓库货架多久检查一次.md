# 决策分析

## 检查频率建议

| 检查类型 | 频率 | 检查内容 |
| -------- | ---- | -------- |
| 日常目视检查 | 每周 | 立柱变形、横梁弯曲、超载迹象 |
| 月度检查 | 每月 | 安全销、连接螺栓、防撞护栏 |
| 专业检测 | 每年 | 垂直度、焊缝、结构完整性 |
| 事故后检查 | 叉车碰撞后立即 | 受损区域整体评估 |

## 重点检查部位

1. 立柱：有无碰撞凹痕、变形、倾斜
2. 横梁：有无弯曲、安全销脱落
3. 底脚：螺栓是否松动、地面有无沉降
4. 防撞设施：护栏、立柱护套是否完好

# 推荐决策流程

第一步：建立货架台账（位置、类型、承重、安装时间）。

第二步：固定检查责任人，按频率执行。

第三步：发现损伤立即隔离该区域，评估后再决定维修或更换。

第四步：每年请专业人员做一次结构检测。

# FAQ

## FAQ-001

问题：货架检查必须找专业机构吗？

回答：日常目视检查和月度检查可以自己人做，每年一次的结构专业检测建议请有经验的供应商或第三方进行，重点查垂直度和焊缝。

## FAQ-002

问题：发现立柱被撞弯了怎么办？

回答：先清空该区域货物，请专业人员评估。立柱轻微碰撞可以补装护套观察，明显变形必须更换立柱，不能简单敲直继续用。

# 评论区设计

评论：叉车撞了货架，检查没问题还能用吗？

回复：碰撞后即使外观没明显变形，也建议评估立柱垂直度和连接节点。轻微碰撞可以补装护套观察，损伤明显要换立柱。
