# 用户问题分析

## 表面问题

托盘买多大尺寸？

## 深层原因

托盘尺寸决定货架货位宽度、叉车属具和装载率，选错会连锁浪费。

## 用户真正需求

选定行业通用的托盘标准，避免非标造成长期麻烦。

# 决策分析

## 常见托盘标准

| 标准 | 尺寸（mm） | 应用 |
| ---- | ---------- | ---- |
| 国标（GB/T 2934） | 1200×1000 | 国内通用，推荐首选 |
| 欧标（EUR） | 1200×800 | 出口欧洲 |
| 美标 | 1219×1016（48×40 英寸） | 对美贸易 |
| 非标定制 | 按货物 | 特殊情况 |

## 选型要点

1. 国内供应链优先 1200×1000
2. 货位宽度 = 托盘宽度 + 叉车作业间隙（一般 +100～150mm）
3. 托盘载重与货架横梁层载匹配
4. 叉车货叉尺寸与托盘插口匹配

---

# 推荐决策流程

第一步：确认货物尺寸和装载方式。

第二步：默认选 1200×1000 标准托盘。

第三步：按托盘定货架货位和叉车属具。

第四步：出口场景再按目的市场标准调整。

---

# 不建议直接做的事情

✘ 自定非标托盘，货架和叉车全部定制。

✘ 货位尺寸按托盘标称做死，不留间隙。

✘ 忽略托盘载重，货架和托盘承载不匹配。

# FAQ

## FAQ-001

问题：国内仓库默认用多大托盘？

回答：国内最常用的是 1200×1000mm 标准托盘，货架、叉车、运输设备都按这个规格配套，通用性最好。

## FAQ-002

问题：托盘尺寸会影响货架价格吗？

回答：会。货位宽度、横梁长度都按托盘尺寸设计，非标托盘会导致货架定制，造价和周期都会增加。

# 评论区设计

评论：我们是出口企业，用1200×1000还是1200×800？

回复：主要看目的市场。欧洲用 1200×800 欧标托盘，其他市场多按 1200×1000 或 48×40 英寸。建议先确认客户要求再定。
