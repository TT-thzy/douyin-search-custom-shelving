# 用户问题分析

## 表面问题

想知道货架拆装要花多少钱。

## 深层原因

仓库搬迁时货架数量大，拆装运输成本可能超过预期，用户需要提前预算。

## 用户真正需求

# 决策分析

## 拆装费用构成

1. 拆除人工费
2. 运输费（按车次或吨位）
3. 重新安装人工费
4. 损耗件更换（螺栓、底脚、防撞件）
5. 旧件整理、包装费

## 参考标准

| 项目 | 参考费用 |
| ---- | -------- |
| 轻型货架拆装 | 15～30 元/组 |
| 重型货架拆装 | 50～120 元/组 |
| 阁楼平台拆装 | 按面积 80～200 元/㎡ |
| 运输 | 按车次 800～1500 元/车 |

> 实际费用受货架高度、数量、楼层和拆装难度影响；异地搬迁还要加食宿。

---

# 推荐决策流程

第一步：盘点货架数量、类型和状态。

第二步：评估旧货架在新仓库的适用性（高度、柱距、承重）。

第三步：对比"拆装搬迁总费用"和"新购货架总费用"。

第四步：让专业团队现场评估后报价。

# 不建议直接做的事情

✘ 搬迁前不检查货架锈蚀、变形，直接复用有隐患。

✘ 只算拆装费，忽略运输和损耗件。

✘ 新仓库高度和旧货架不匹配还强行搬迁。

# FAQ

## FAQ-001

问题：旧货架拆了再装，还能用多久？

回答：取决于货架现状。拆装一次对结构件会有一定损耗，如果锈蚀、变形明显，建议淘汰；状态好的货架重装后正常使用 5～10 年问题不大。

## FAQ-002

问题：拆装费比新货架还贵，怎么办？

回答：当拆装、运输、损耗件加起来的费用接近新购的 60% 以上时，建议直接采购新货架，还能按新仓库重新设计布局。

# 评论区设计

评论：我们的货架用了8年，搬迁值得拆吗？

回复：8年的货架建议先检查锈蚀和变形情况。如果状态良好可以拆装复用，如果明显老化，搬迁费加新购比拆装更划算的情况很常见。
