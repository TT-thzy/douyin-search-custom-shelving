# 用户问题分析


## 表面问题


电子元器件怕静电、怕潮，仓库怎么规划？


---

## 深层原因


可能原因：

- 电子元器件对静电（ESD）极其敏感，普通仓库环境不能满足要求
- 湿敏元件（MSD）对湿度有严格要求，超出范围可能影响焊接质量
- 物料品种极多（一颗料一个规格），管理精度要求高
- 部分物料有保质期和批次追溯要求
- 洁净度有要求，普通仓库灰尘会影响产品质量


---

## 用户真正需求


不是简单配货架。

而是：

建立满足ESD防护、温湿度控制和精细化管理要求的专业化电子仓储体系。

# 决策分析


## 电子元器件存储的关键要求


| 要求 | 说明 | 控制标准 |
| ---- | ---- | -------- |
| 防静电（ESD） | 防止静电放电损伤元件 | 表面电阻10^6-10^9Ω |
| 温湿度控制 | 防止湿敏元件受潮 | 温度22±5℃，湿度30%-60%RH |
| 洁净度 | 减少粉尘对元件的影响 | 10万级以上 |
| 防氧化 | 防止引脚氧化影响焊接 | 真空包装/干燥柜 |
| 批次追溯 | 物料全生命周期追溯 | 系统记录批次信息 |


---

## 防静电（ESD）防护措施


措施一：

防静电地板

仓库地面铺设防静电PVC或环氧地坪。

表面电阻控制在10^6-10^9Ω之间，接地系统完善。


措施二：

防静电货架

货架表面做防静电处理，或使用防静电材料制作的货架。

货架需通过接地线连接到接地系统。


措施三：

防静电操作台

在拣货、质检等工作区域使用防静电台垫。

操作人员佩戴防静电手环。


措施四：

防静电包装

存储和转运过程中使用防静电袋、防静电周转箱。

禁止使用普通塑料袋和非防静电泡沫。


措施五：

人员接地

入口处设置防静电鞋测试仪和静电释放桩。

进入仓库人员必须穿防静电鞋和防静电服。


---

## 湿敏元件（MSD）管理


MSD等级：

不同元件对湿度敏感程度不同，按IPC标准分为MSL 1-6级。

等级越高对湿度越敏感，存储时间越短。

存储方式：

- 未开封：原厂真空包装，在有效期内存放于温湿度受控环境
- 已开封：放入干燥柜（湿度<10%RH）或重新真空包装
- 过期：需要按规范进行烘烤处理后再使用

管理要点：

- 记录每个MSD元件的开封时间和暴露时间
- 超过暴露时限的元件必须烘烤后才能上线
- 干燥柜定期更换干燥剂


---

## 电子厂仓库货架选型


| 货架类型 | 适用场景 | ESD要求 |
| -------- | -------- | ------- |
| 层板货架 | 小件元器件、IC芯片 | 防静电层板，接地 |
| 抽屉式货架 | 精密芯片、样品 | 防静电抽屉 |
| 阁楼货架 | 多品种小批量 | 全区域防静电处理 |
| 重型横梁货架 | PCB板、成品 | 防静电托盘 |
| 恒温恒湿柜 | 湿敏元件 | 自带温湿度控制 |

## 电子厂仓库功能分区


分区一：

原料仓（电子仓）

存放电阻、电容、IC、连接器等电子元器件。

要求：防静电地板+温湿度控制+洁净环境。

建议：按物料类型和尺寸分区，使用防静电层板货架。


分区二：

PCB/结构件仓

存放PCB线路板、外壳结构件、包装材料等。

要求：PCB板需要防氧化防潮，结构件防磕碰。

建议：横梁货架+悬臂货架组合。


分区三：

化学品仓

存放锡膏、助焊剂、清洗剂等化工辅料。

要求：防火防爆、通风良好、远离热源。

建议：独立防火区域，防爆柜或专用货架。


分区四：

成品仓

存放已完成的电子产品。

要求：防静电+防潮+防尘。

建议：重型货架托盘化存储，按型号和批次分区。


分区五：

来料检验区

对入库物料进行质量检验的区域。

要求：与存储区分开，配置检验设备和防静电工作台。

# 推荐规划流程


第一步：

确定存储物料清单。

按类别、尺寸、ESD敏感等级和湿度敏感度分类。

↓

第二步：

建立ESD防护体系。

从地板、货架、工具到人员，建立完整的防静电链条。

↓

第三步：

配置温湿度控制系统。

安装空调和除湿设备，关键区域配置监控报警。

↓

第四步：

完成WDS评估。

确认仓高、承重和消防条件。

↓

第五步：

配置货架和设备。

选择防静电货架和配套存储设备。


---

# 不建议做的事


✘ 普通货架直接用于电子元件存储，不做防静电处理。

✘ 湿敏元件打开原包装后不放入干燥柜，暴露在普通空气中。

✘ 电子仓和化学品仓混在一起。

✘ 仓库温湿度不监控不记录，出了问题找不到原因。

✘ 忽略人员防静电培训，员工穿普通鞋进入ESD区域。

# FAQ


## FAQ-001


问题：

普通货架能改成防静电货架吗？


回答：

可以通过以下方式改造：一是在层板上铺设防静电胶皮并接地；二是在货架整体连接接地线；三是更换为防静电周转箱。但粉末喷涂的货架表面本身电阻较高，防静电效果不如专业防静电货架。


---

## FAQ-002


问题：

电子仓的温湿度控制在什么范围？


回答：

一般电子元器件仓库建议温度22±5℃，湿度30%-60%RH。湿敏元件存储建议湿度控制在30%以下。具体范围应根据存储元件的规格要求设定，建议配置温湿度自动监控和报警系统。


---

## FAQ-003


问题：

SMT物料的防潮柜怎么选？


回答：

防潮柜（干燥柜）选型要点：一是控湿能力，能稳定控制在5%-10%RH以下；二是容量，要根据开封物料量选择合适容积；三是密封性，开门后恢复湿度的时间要短；四是能耗和噪音。建议选择带湿度显示和报警功能的型号。

# 评论区设计


评论：

我们电子厂仓库200平，SMT物料有2000多种，怎么规划空间？


回答：

2000多种SMT物料建议采用防静电层板货架配合电子标签拣选系统，按物料类别分区。高频使用的物料放在靠近SMT车间的区域，配合系统实现先进先出和批次管理。


---

评论：

仓库防静电接地怎么做？


回答：

防静电接地需要：一是地面防静电层通过铜箔网连接到接地汇流排；二是货架通过接地线与汇流排连接；三是操作台和工作设备接地；四是所有接地最终汇入建筑的防雷接地系统。建议由专业人员施工。
