# 用户问题分析

**表面问题**：生产线经常断料停线，或者堆了太多物料占地方，仓库和生产之间好像永远对不上。

**深层原因**：
1. 生产计划和仓库物料计划脱节——生产计划改了，仓库不知道；仓库缺料了，生产不知道
2. 没有区分"中心仓库"和"线边库"的职能差异——把中心仓库的管理模式直接搬到生产线旁，导致物料管理混乱
3. 物料配送没有固定节奏（没有标准配送周期和配送路线），依赖生产线临时喊人送料
4. 库存信息不透明——生产排产的人看不到仓库实际库存，仓库的人不知道生产接下来要用什么

**用户真正需求**：深层需要一个"物料供给的保障机制"，让生产线专注制造，仓库专注供料。具体包括：建立标准化的物料配送节拍（定时定量配送或按需叫料）、明确中心仓库和线边库各自的责任边界、让生产计划和物料计划实现信息互通。最终目标是消除因为物料问题导致的生产线停工。

# WDS分析

仓库配合生产计划的规划离不开仓库基础设施的合理配置：

- **WDS-001 仓高评估**：对于配合生产线的仓库（线边库或车间级仓库），通常不需要很高的货架（2-4米即可，因为要保证快速存取）。但如果中心仓库同时服务多条产线，则需要利用仓高搭建多层货架或高位货架来满足存储容量需求。
- **WDS-002 承重评估**：线边库的地面承重需求通常低于中心仓库，因为线边只存放少量待上线物料，而非大量库存。但如果是重型制造（如铸造、大型机械装配），线边存放的毛坯件或半成品也可能很重，需要单独核算。
- **WDS-003 消防评估**：线边库通常位于生产车间内部，其消防要求与生产车间一致。需要注意的是，线边物料不能堵塞生产设备的消防通道和安全出口，这是很多工厂容易忽视的问题。
- **WDS-004 地坪评估**：生产车间的地坪通常会承受较频繁的叉车和拖车来回碾压。线边库区域的地坪如果已经存在磨损或裂纹，重型货架的安装需要更加谨慎，建议进行局部地坪检测。
- **WDS-005 货架选型评估**：线边库的货架选型与中心仓库差异很大。线边库优先选择方便快速存取的货架（如轻型搁板货架、带周转箱的流利式货架、悬挂式料架等），而不是追求高密度存储的重型货架。

# 决策分析

## 一、中心仓库与线边库的职能划分

这是仓库配合生产计划最核心的概念：

| 对比维度 | 中心仓库 | 线边库 |
|---------|---------|--------|
| 核心职能 | 大批量接收、存储、保管 | 为生产线提供"马上要用"的物料缓存 |
| 存储时间 | 天-月级别 | 小时-班次级别 |
| 库存策略 | 以"不缺料"为目标，经济批量为补充 | 以"够当前及下一班次用"为目标，最小化线边存量 |
| 货架类型 | 重型货架、高位货架、窄巷道货架 | 轻型流利式货架、周转箱货架、可移动料架 |
| 补货方式 | 供应商送货入库 | 中心仓库按配送计划向线边库补货 |
| 管理重点 | 库存准确率、存储效率 | 配送及时性、物料齐套性 |

## 二、物料配送的三种模式

| 配送模式 | 描述 | 适用场景 | 优点 | 缺点 |
|---------|------|---------|------|------|
| 定时定量配送 | 按固定时间间隔（如每2小时），将固定数量的物料送到线边 | 生产节拍稳定、物料消耗速度可预测 | 计划性强、便于管理 | 不够灵活，生产波动时容易过量或缺料 |
| 按需叫料（看板/Kanban） | 线边物料消耗到一定量时，触发补货信号（看板卡/电子信号） | 多品种小批量生产、物料消耗速度不一 | 精准、减少线边库存堆积 | 需要成熟的看板管理体系和人员执行纪律 |
| 齐套配送（Kitting） | 按生产工单将所需物料一次性配套配送到线边 | 装配型生产、物料种类多、单工单用量明确 | 减少线边物料混乱、提高装配效率 | 仓库端的工作量增加，需要提前做齐套分拣 |

**建议**：大多数制造企业采用"看板拉动+定时巡检"的混合模式——80%的常规物料用看板拉动，20%的非常规物料（如指定批次的特殊物料）用工单驱动的齐套配送。

## 三、物料流动路线设计

一个典型的制造工厂物料流动路线：

```
供应商送货 → 中心仓库收货区 → 来料质检
    ↓
中心仓库存储区（整存）
    ↓
（配送准备区：分拣、拆包、齐套）
    ↓
线边库（缓存，等待上线）
    ↓
生产工位（上线消耗）
    ↓
半成品缓存区/成品入库
```

关键设计要点：
1. 物料的物理流动方向应该与生产流程方向一致，避免回流和交叉
2. 配送路径应设计为闭环，配送车辆（人工或AGV）出去送货，顺路带回空容器和返工品
3. 线边库的位置应在生产工位的步行距离30米以内，且不阻碍生产通道

## 四、信息协同机制

| 信息流 | 源头 | 接收方 | 传递方式 | 重要性 |
|--------|------|--------|---------|--------|
| 生产排产计划 | 生产计划部 | 仓库 | 每日推送未来3天排产 | 极高 |
| 物料齐套报告 | 仓库 | 生产计划部 | 按工单反馈缺料清单 | 极高 |
| 线边库存预警 | 线边库 | 仓库 | 看板信号/扫描触发 | 高 |
| 生产异常预警 | 生产部 | 仓库 | 即时通知（插单、急单、取消） | 高 |
| 供应商到货计划 | 采购/仓库 | 生产计划部 | ASN（预到货通知） | 中 |

## 五、衡量仓库-生产协同效果的KPI

要判断仓库配合生产计划的效果好不好，不能只看"感觉"，需要量化指标：

| KPI指标 | 定义 | 行业参考值 | 数据来源 |
|---------|------|----------|---------|
| 配送及时率 | 在约定时间内送达线边库的配送次数÷总配送次数 | ≥95%为合格，≥98%为优秀 | 配送记录（手工或系统） |
| 生产断料次数 | 因物料未及时到位导致生产线停工的次数 | 0次为目标，每月≤1次可接受（离散制造） | 生产停工记录 |
| 线边库存周转率 | 线边库日均消耗量÷线边平均库存量 | 越高越好，参照"班次周转"（每班次周转1次以上） | 线边盘点数据 |
| 齐套率 | 按生产工单物料清单全部配齐的工单数÷总工单数 | ≥90% | 工单发料记录 |
| 配送差错率 | 送错数量/规格的配送次数÷总配送次数 | ≤0.5% | 线边接收确认记录 |
| 紧急要料次数 | 因配送不足或遗漏导致产线临时呼叫送料的次数 | 越少越好，≤5次/天（大型工厂） | 仓库配送工单 |

## 六、常见协同问题及解决方案

| 问题 | 典型表现 | 解决方案 |
|------|---------|---------|
| 排产变动通知滞后 | 生产换线了，仓库还按原计划送料 | 建立排产变更即时通知机制（微信群/钉钉/系统推送），变更超过30%时触发配送计划重新计算 |
| 线边库存"黑洞效应" | 物料送到线边后就跟丢了，不知道用了多少、剩了多少 | 推行线边库"定容定量+目视化管理"，每个容器标明满箱数量和补货触发点 |
| 紧急插单打乱配送节奏 | 生产临时插单，仓库原来的配送计划全被打乱 | 在配送计划中预留"插单缓冲槽"（通常是配送能力的15-20%），插单不超过缓冲容量则不影响常规配送 |
| 退货/返工品物料倒流 | 生产线退回的物料不经过仓库登记，堆在线边形成账外库存 | 制定明确的物料退回流程：线边退库→仓库质检→合格入库/不合格隔离 |

# 不建议做的事

- ✘ 把线边库当成"小仓库"来管理——线边库的唯一目的是为生产线提供即时的物料缓存，如果发现线边库的物料能存放超过2个班次，说明配送过于超前，占用了生产现场的宝贵空间
- ✘ 生产计划改了但不通知仓库——很多停线事件不是因为缺料，而是因为生产悄悄换了排产顺序，仓库按原计划配送了错误的物料
- ✘ 中心仓库以"满仓"为考核目标——配合生产计划的仓库，核心KPI是"配送及时率"和"断料次数"，不是"库存利用率"。压满库存不等于保障了生产
- ✘ 物料配送没有标准路线和标准时间——靠感觉和喊话送料的方式在小批量时可以凑合，一旦产量上规模，立刻就会成为瓶颈
- ✘ 在线边库追求高密度存储——线边库如果堆得太满，物料难以快速找到，配送效率反而下降。线边库应该"一眼看清、伸手可及"

# FAQ

**FAQ-001**
- 问题：我们是多品种小批量的生产模式，产品经常换线，物料配送怎么适应这种快速切换？
- 回答：多品种小批量模式下，传统的定时定量配送很难奏效，建议采用"按工单齐套配送"的方式。具体做法：仓库在接到生产计划后，提前将每个工单所需的全部物料（包括专用件和标准件）按BOM清单进行齐套分拣，放入专用的工单料车或料箱，然后一次性配送到工位。换线时，旧的工单料车拉走，新的工单料车就位，换线时间可以大幅缩短。这个模式下，仓库的前端分拣工作量会增加，需要配备专门的齐套分拣区域。

**FAQ-002**
- 问题：线边库的物料经常丢失或者混料，怎么管理能变好？
- 回答：线边物料混乱的根源通常不是人的问题，而是"没有给物料一个固定的家"。三个改进方向：一是给线边每个物料位置都做明确的标识（物料编码+名称+最大存量的标签），让任何人一眼就能看出物料该放在哪、最多放多少；二是采用定容定量容器（如每个盒子只放固定数量的物料，20个/盒或50个/盒），这样不用点数就能判断够不够用；三是明确线边库存的上限标识（如用红黄绿三色标识线），超过上限就停止配送。这些是"防呆"思路，减少对人的依赖。

**FAQ-003**
- 问题：仓库和车间在同一个建筑里，和不在同一个建筑里，物料配送的方案有什么区别？
- 回答：区别很大。如果在同一建筑内，可以采用高频次、小批量的配送模式（如每小时配送一次），配送距离短，灵活性强，甚至可以不需要专门的配送人员，由产线班长自行从中心仓库取料。如果仓库和车间不在同一建筑（甚至在不同厂区），则需要采用低频次、大批量的配送模式（如每班次配送1-2次），并需要专用的运输工具（电瓶车、叉车、AGV），对配送计划的要求更高——因为一旦出现漏送或错送，修正的成本（时间成本和运输成本）会高很多。

# 评论区设计

**评论1**：
- 评论：我们工厂目前的配送方式和你说的一样，就是'生产线打电话叫料'。生产线经常抱怨送得慢，仓库说一上午接了20个电话根本跑不过来。这个矛盾怎么解？
- 回答：电话叫料的本质问题是"配送节奏被动的跟着需求跑"，没有主动权。改的方向是把"被动响应"变成"主动配送"。第一步：统计一下过去一周的电话叫料数据——哪个时段叫料最密集、哪些物料被叫得最频繁。第二步：找到被叫频率最高的前10种物料，改成定时主动配送（比如每小时补充一次，不需要等电话）。做完这两步，电话叫料量通常会减少60%以上。剩下的低频物料可以保留电话叫料，因为数量少不影响效率。

**评论2**：
- 评论：我们公司的生产计划和仓库归两个部门管，生产计划归计划部，仓库归物流部，每次协调都很费劲。管理上有什么好办法？
- 回答：跨部门协调问题的根在于信息不对称和KPI不同。生产计划部的KPI是按时完成生产任务，物流部的KPI是库存准确率和周转率——两者的天然张力是正常的。建议建立一个"每日物料对接会"机制，每天早上各15分钟：生产计划部通报未来三天的排产计划和优先级变化，仓库通报物料齐套情况和缺料预警。不用大领导主持，两个部门的主管和调度参加即可。这个制度不是要重新划分职责，而是让信息在最短路径上流动。
