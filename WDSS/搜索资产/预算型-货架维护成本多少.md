# 决策分析


## 维护成本构成


| 成本项目 | 说明 | 频率 |
| -------- | ---- | ---- |
| 日常检查 | 外观检查和简单紧固 | 每月 |
| 年度检测 | 专业安全检测评估 | 每年 |
| 配件更换 | 横梁、立柱、安全销等 | 按需 |
| 防腐处理 | 除锈刷漆或更换腐蚀件 | 1-3年 |
| 结构加固 | 立柱加固、横梁加强 | 按需 |


---

## 日常维护内容


维护项一：

月度外观检查

检查立柱垂直度、横梁变形、安全销状态、地脚螺栓紧固。

工作量：少量人工，无需额外费用。


维护项二：

季度紧固检查

对所有连接件重新紧固，补充缺失的安全销。

工作量：少量人工和配件。


维护项三：

年度专业检测

请专业人员检测货架整体安全状态，出具检测报告。

工作量：需要专项费用。


维护项四：

碰撞后应急检查

叉车撞击后立即检查受损件，评估是否需要更换。

工作量：按事故频次计算。


---

## 配件更换参考


| 配件类型 | 更换触发条件 | 更换难度 |
| -------- | ------------ | -------- |
| 安全销 | 缺失或变形 | 低 |
| 横梁 | 下弯超过设计限度 | 中 |
| 立柱 | 变形、倾斜超过标准 | 高 |
| 地脚螺栓 | 松动、锈蚀、断裂 | 中 |
| 层板 | 凹陷变形 | 低 |
| 护栏 | 变形损坏 | 低 |


---

## 维修 vs 更换判断


| 条件 | 建议维修 | 建议更换 |
| ---- | -------- | -------- |
| 使用年限 | 5年内 | 超过设计使用年限 |
| 损坏范围 | 个别配件 | 大面积变形 |
| 腐蚀程度 | 表面锈蚀 | 深度锈蚀影响结构 |
| 立柱状态 | 单根变形 | 多根变形或倾斜 |
| 安全评估 | 通过检测 | 未通过检测 |

# 不建议做的事


✘ 损坏后不检查继续使用。

✘ 用非原厂配件替换关键结构件。

✘ 自行焊接修复损坏的立柱。

✘ 为了降低维护成本取消年度检测。

✘ 只比较配件单价而忽略安全和人工成本。

# FAQ


## FAQ-001


问题：

货架一般多久需要大修一次？


回答：

货架没有固定的大修周期。正常使用情况下，每年做一次全面检测，根据检测结果确定维修内容。使用5年以上的货架建议增加检测频次，重点关注腐蚀和疲劳损伤。


---

## FAQ-002


问题：

货架配件贵吗？自己能换吗？


回答：

安全销、层板等简单配件可以自行更换。横梁、立柱等结构件建议由原供应商提供并安装，避免因尺寸偏差或安装不当造成安全隐患。配件价格因规格和承重等级不同，应与供应商确认具体报价。


---

## FAQ-003


问题：

维修费用比买新的还贵怎么办？


回答：

需要综合评估。如果货架已使用多年且大面积损坏，更换整排货架可能比零散维修更经济。同时要评估维修后的安全余量是否满足未来若干年的使用需求。

# 评论区设计


评论：

我们货架用了8年了，最近横梁老是变形，是不是到换的时候了？


回复：

8年是需要重点评估的节点。横梁频繁变形可能意味着材料疲劳或承载力已不满足当前需求。建议先做一次全面安全检测，确认是局部更换还是整体更换更合理。


---

评论：

年度检测一定要找专业机构做吗？自己检查行不行？


回答：

日常月度检查可以由仓库人员自行完成，但年度全面检测建议由专业人员执行。专业检测能发现外观不易察觉的问题，如立柱垂直度偏差、焊接点微裂纹等。
