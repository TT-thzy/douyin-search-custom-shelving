# 决策分析

## 水平度参考标准

| 货架类型 | 允许高差参考 | 处理方式 |
| -------- | ------------ | -------- |
| 轻型货架 | ≤ 10mm | 底脚垫片调整 |
| 中型货架 | ≤ 5mm | 垫片 + 局部找平 |
| 重型货架 | ≤ 3mm | 地面整体找平或垫板处理 |

> 立柱垂直度偏差一般要求 ≤ 3mm，地面越不平，找平成本越高。

## 处理方案

1. 局部垫片：适合小范围轻微不平
2. 局部自流平：适合局部坑洼
3. 整体地坪找平：适合大面积不平或叉车作业区
4. 结构补强：地坪有裂缝、沉降时需先评估再处理

---

# 推荐决策流程

第一步：测量地面高差和裂缝情况。

第二步：确认地坪类型（混凝土 / 砖地 / 旧地面）。

第三步：让货架厂家现场评估并提出找平方案。

第四步：把地坪处理费用计入总预算。

# 不建议直接做的事情

✘ 地面不平强行安装，靠"垫木头"凑合。

✘ 忽视地坪裂缝和沉降，直接上重型货架。

✘ 只问货架价格，不问地坪处理费用。

# FAQ

## FAQ-001

问题：地面有裂缝能装重型货架吗？

回答：需要先评估裂缝类型和地坪承载能力。结构性裂缝必须处理后再装；普通表面裂纹一般不影响，但要现场确认。

## FAQ-002

问题：地坪找平大概多少钱？

回答：局部自流平一般 20～50 元/㎡，整体找平视材料和厚度不同。具体以现场测量为准，这笔费用容易在预算时漏掉。

# 评论区设计

评论：水泥地有点斜坡，装重型货架有问题吗？

回复：有坡度要看高差和坡向。重型货架对水平度要求高，建议先测量整体高差，再决定是局部垫片还是整体找平。
