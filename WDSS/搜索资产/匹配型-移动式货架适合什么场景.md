# 决策分析

## 适合场景

| 场景 | 说明 |
| ---- | ---- |
| 档案/资料密集存储 | 存取频率低，密度优先 |
| 备件库、工具库 | 品种多、批量小、频次低 |
| 图书、样品库 | 需要最大化库容 |
| 低温/受限空间 | 减少通道，压缩占地面积 |

## 不适合场景

- 高频拣货仓库（每次存取都要移开整排，效率低）
- 需要叉车作业的托盘仓库
- 地面不平、承重不足的旧仓库

---

# 推荐决策流程

第一步：统计存取频率（一天几次）。

第二步：低频率 + 高密度需求 → 移动式。

第三步：确认地面平整度和承重。

第四步：对比移动式与普通货架的库容提升幅度和造价。

---

# 不建议直接做的事情

✘ 高频拣货仓用移动式，工人每天"开柜移架"。

✘ 地面不平就装轨道，容易卡顿。

✘ 只算库容，不算电控和轨道维护成本。

# FAQ

## FAQ-001

问题：移动式货架能提升多少存储量？

回答：靠压缩通道，库容一般可提升 30～80%，具体取决于货架排数和作业频率。频率越低，收益越明显。

## FAQ-002

问题：移动式货架存取会不会很麻烦？

回答：存取时需要先移动相邻货架留出通道，适合低频存取。高频拣选场景不建议，效率和密集度不可兼得。

# 评论区设计

评论：我们是汽配备件库，每天出库几十次，能用移动式吗？

回复：几十次/天的存取频率偏高了，移动式每次都要移架，效率会受影响。建议评估普通货架加库位管理，或高频区固定、低频区移动的混合方案。
