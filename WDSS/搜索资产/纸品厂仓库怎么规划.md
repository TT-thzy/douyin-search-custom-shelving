# 用户问题分析

## 表面问题

纸品仓库怎么放？

## 深层原因

原纸卷筒重达数百公斤到数吨，成品纸箱体积大，纸品怕潮怕压，普通存储方案风险高。

## 用户真正需求

重件托盘化存储 + 严格的防潮管理。

# 决策分析

## 分区域规划

| 区域 | 货物 | 存储建议 |
| ---- | ---- | -------- |
| 原纸仓 | 卷筒纸 | 托盘横放，重型横梁货架 |
| 纸板仓 | 瓦楞纸板 | 托盘 + 重型货架，避免堆叠压伤 |
| 成品仓 | 纸箱 | 纸箱垛 + 横梁货架 |
| 辅料仓 | 油墨、胶水 | 单独存放，注意危化品隔离 |

## 关键要点

1. 卷筒纸必须横放托盘，防止滚动和变形
2. 纸品离地存放，底部加托盘防潮
3. 消防分区和通道要重点设计
4. 先进先出管理，避免原纸积压受潮

---

# 推荐决策流程

第一步：统计原纸卷筒的重量和尺寸。

第二步：确认仓库层高和地坪承载。

第三步：按区域选型并做消防专项设计。

第四步：建立防潮和先进先出制度。

---

# 不建议直接做的事情

✘ 卷筒纸竖放，滚动倒伏伤人或变形。

✘ 纸品直接落地，受潮降级。

✘ 忽略消防分区，纸品仓库火灾风险高。

# FAQ

## FAQ-001

问题：卷筒纸怎么上货架？

回答：卷筒纸横放在托盘上，用叉车存取。托盘承重和货架横梁层载按最重卷筒核算，禁止竖放。

## FAQ-002

问题：纸品仓库消防有什么要求？

回答：纸品属可燃物，仓库要按消防规范设置喷淋、分区和通道，货架布局要预留消防净空，建议方案阶段就做消防评估。

# 评论区设计

评论：我们一卷原纸1吨左右，货架怎么选？

回复：1吨/卷需要重型横梁式货架，单层承载按1.5吨以上设计，托盘用加厚规格。同时确认地坪承载和消防条件。
