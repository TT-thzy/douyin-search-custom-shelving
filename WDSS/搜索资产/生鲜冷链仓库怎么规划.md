# 用户问题分析

## 表面问题

生鲜仓怎么建、怎么放？

## 深层原因

生鲜保质期短、周转快、温区多，规划不当会导致损耗高、作业拥堵。

## 用户真正需求

按温区和周转速度分区，实现快速出入库和低损耗。

# 决策分析

## 分温区规划

| 温区 | 温度参考 | 存储建议 |
| ---- | -------- | -------- |
| 常温区 | 常温 | 干货、包材 |
| 冷藏区 | 0～8℃ | 蔬果、乳品，周转箱 + 货架 |
| 冷冻区 | -18℃ 以下 | 冻品托盘，重型货架 |
| 分拣暂存区 | 按品类 | 流利式货架，快速拣选 |

## 关键要点

1. 按"入库 → 暂存 → 分拣 → 发货"动线设计，减少冷区暴露
2. 高频品类放在靠近分拣口的位置
3. 冷库内货架选高防腐材质（见冷库货架资产）
4. 先进先出管理，避免积压损耗

---

# 推荐决策流程

第一步：确定温区数量和各温区货物占比。

第二步：设计动线，冷区尽量集中、少开门。

第三步：按温区分别选货架（常温/冷藏/冷冻）。

第四步：建立批次和效期管理。

---

# 不建议直接做的事情

✘ 把所有生鲜塞进一个温区，品质互相影响。

✘ 动线不合理，货物在冷区外长时间暴露。

✘ 冷冻库用普通喷塑货架，几年锈蚀返工。

# FAQ

## FAQ-001

问题：生鲜仓库一定要分区吗？

回答：要。蔬果、乳品、冻品对温度要求不同，混放会导致品质下降和损耗。至少区分冷藏和冷冻两个温区。

## FAQ-002

问题：生鲜仓用什么货架？

回答：常温/冷藏区用横梁货架或流利式货架，冷冻区用镀锌或高防腐重型货架。按存储单元（箱/托盘）选型。

# 评论区设计

评论：我们做生鲜电商，冷库加常温一共800平，怎么分区？

回复：按货物占比和周转速度分区，高频品类放分拣口附近，冷冻/冷藏分开。建议先画动线再定货架，避免冷区暴露。
