# 用户问题分析

## 表面问题

日化仓库怎么放才高效？

## 深层原因

日化 SKU 多、渠道多、批次效期管理严格，液体货物还涉及泄漏和渗漏风险。

## 用户真正需求

高密度存储 + 批次效期管理 + 液体安全存放。

# 决策分析

## 分区域规划

| 区域 | 货物 | 存储建议 |
| ---- | ---- | -------- |
| 箱装区 | 整箱日化品 | 横梁货架或阁楼货架 |
| 液体区 | 洗护、消毒液 | 防漏托盘，与干品隔离 |
| 拣选区 | 电商/零担发货 | 流利式货架 + 拣货通道 |
| 效期管理区 | 临期品 | 独立区域，先进先出 |

## 关键要点

1. SKU 多 → 库位编号 + 分区是前提
2. 液体区用防漏托盘和隔离栏
3. 批次效期管理，临期品单独处理
4. 纸箱轻件可考虑阁楼货架增加面积

---

# 推荐决策流程

第一步：统计 SKU 数量、货物形态（箱/瓶/袋）。

第二步：液体与干品分区，单独设计防漏。

第三步：按周转率安排货位。

第四步：建立批次效期管理规则。

---

# 不建议直接做的事情

✘ 液体和干品混放，泄漏污染整批货。

✘ 靠人工记效期，临期品积压。

✘ 高 SKU 仓库不用库位编号，找货靠记忆。

# FAQ

## FAQ-001

问题：日化仓库用阁楼货架合适吗？

回答：合适。日化以纸箱和瓶装为主、单件轻、SKU 多，阁楼货架能显著增加存储面积，配合人工拣选效率高。

## FAQ-002

问题：液体日化品存放要注意什么？

回答：液体区要配防漏托盘、与干品隔离，并控制堆高防止倾倒。含酒精等易燃成分的产品还要符合消防要求。

# 评论区设计
