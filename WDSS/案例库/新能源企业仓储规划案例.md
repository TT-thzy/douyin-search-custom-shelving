CASE-022

新能源

# 一、客户背景

## 企业情况

储能电池生产企业，产能三年规划翻两倍，仓库需分阶段匹配。

## 仓储现状

仓库类型：☑ 原材料仓 / ☑ 成品仓 / ☑ 不良品仓

面积：4000 平方米

高度：层高 8 米

存储方式：电芯料箱 + 托盘堆放

---

# 二、客户问题

## 表面问题

产能翻倍后仓库不够，且电芯存储安全要求高。

## 深层问题

- 规划只覆盖眼前，扩产就要再改造
- 电芯存储温控、消防要求高
- 原材料、成品、不良品分区不足

## 客户目标

按 3 年产能分阶段规划，一次结构到位。

---

# 三、采购决策过程

## 方案调研

1. 一期做满，后期再扩
2. 预留接口分两期建设
3. 直接按 3 年规模一次建成

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 一期做满 | 投入低 | 二次改造浪费 |
| 预留分两期 | 投入平滑 | 需前期规划 |
| 一次建成 | 一步到位 | 前期资金占用 |

## 最终决策因素

☑ 资金节奏 / ☑ 扩展能力

客户选择"结构一次到位、设备分两期"。

---

# 四、仓储分析过程

## 现场评估

- 电芯料箱单托 500～800kg
- 电芯存储需温湿度监控和专用消防
- 8 米层高可做 5 层高位货架

## WDS 关联

- WDS-001：8 米层高 5 层布局
- WDS-002：料箱荷载核算
- WDS-003：电芯仓库消防专项
- WDS-005：料箱托盘横梁式

---

# 五、解决方案

☑ 高位横梁货架 / ☑ 温控消防配套

设计：一期安装 60% 库位，预留二期接口；电芯区温控 + 专用消防；不良品独立隔离。

核心参数：

| 参数 | 数值 |
|------|------|
| 货架层数 | 5 层 |
| 一期库位 | 约 5200 个 |
| 二期预留 | 约 3400 个 |
| 一期投资 | 约 210 万元 |

---

# 六、成本与收益分析

一期投入约 210 万元；对比一次建成节省初期资金约 150 万元；产能翻倍时二期仅需设备投入。

---

# 七、实施过程

一期设计含二期接口 → 安装 → 温控消防验收 → 投产，周期约 55 天。

难点：电芯消防方案审批；解决：提前与消防单位对接专用灭火系统。

---

# 八、项目结果

- 一期满足当前产能，二期预留就绪
- 电芯温控、消防合规
- 不良品独立隔离

# 十、经验总结

解决的问题：扩产与仓库投入节奏错配。

适用企业：产能高增长的新能源、制造企业。

不适用企业：业务稳定的中小企业。
