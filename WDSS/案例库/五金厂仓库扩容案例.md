# 一、客户背景

## 企业情况

企业主营业务：五金紧固件、门窗五金配件制造

产品类型：螺丝、螺母、垫片、锁具、门窗配件、卫浴五金等

生产模式：多品种、中小批量

库存特点：
- SKU 数量约 3000 个
- 单件重量较小（多数在 0.1～5kg 之间）
- 人工拣货为主
- 库存周转中等

## 仓储现状

仓库类型：
☑ 成品仓

当前面积：800 平方米

当前高度：层高 6.5 米（梁下净高约 6 米）

当前存储方式：
- 地面堆放为主
- 部分使用轻型货架（2 米高）
- 通道混乱，没有统一规划
- 找货靠人工记忆

# 二、客户问题

## 表面问题

仓库放不下货，产品堆到通道上，新到的货没有地方放。

## 深层问题

进一步分析后发现问题不是面积不足，而是空间利用率过低：

- 仓库高度 6.5 米，但现有货架仅 2 米高，大量垂直空间闲置
- 货物分类混乱，同类产品分散在仓库不同位置
- 通道宽度不统一，部分区域通道过宽浪费面积
- 库存增长约 30%，原有存储方式无法支撑
- 没有库位管理，找货依赖老员工

## 客户目标

- 在不搬仓的前提下，增加约 50% 的有效存储能力
- 实现货物分区分类管理
- 提升拣货效率
- 控制改造成本在合理范围内

# 三、采购决策过程

## 发现问题

客户在年末盘点时发现：
- 订单增长 25%，但仓库吞吐能力已到瓶颈
- 旺季需要临时租用外部仓库，年租金约 8 万元
- 员工每天找货浪费大量时间

## 方案调研

客户考虑过三个方案：

1. **搬迁仓库** — 租用更大面积的仓库
2. **扩建现有仓库** — 在厂区空地新建仓库
3. **改造现有仓库** — 通过货架系统提升存储能力

## 方案比较

| 方案 | 优势 | 不足 | 适用情况 |
| ---- | ---- | ---- | -------- |
| 搬迁仓库 | 面积增加明显 | 搬迁成本高、运营中断、新址距离远 | 现有仓库完全无法改造时 |
| 扩建仓库 | 不影响现有运营 | 审批周期长、建设成本高、一次性投入大 | 厂区有空地且长期需求明确 |
| 改造现有仓库 | 投资少、无搬迁、见效快 | 提升幅度受仓库条件限制 | 仓库高度、地面条件满足时 |

## 最终决策因素

客户最终关注：

☑ 价格 — 控制改造成本

☑ 使用面积 — 实际增加多少存储能力

☑ 安全 — 结构安全、消防合规

☑ 施工周期 — 不能长时间停产

□ 后期维护

☑ 扩展能力 — 未来还能继续调整

客户最终选择了"改造现有仓库"方案，核心原因是 6.5 米的层高完全具备立体化利用条件，投资远低于搬仓和扩建。

# 四、仓储分析过程

## 现场评估

评估内容：

- **仓库高度**：层高 6.5 米，梁下净高 6 米。→ 满足阁楼货架建设条件（参见 WDS-001）
- **地面情况**：混凝土地面，平整度良好，无明显裂缝。→ 满足承重要求（参见 WDS-004）
- **柱距**：8 米 × 8 米柱网，空间规整 → 布局灵活
- **消防条件**：已有消防栓和喷淋系统。→ 需调整喷淋位置以适应阁楼结构（参见 WDS-003）
- **货物情况**：小件、多 SKU、单件重量 ≤5kg → 适合人工拣选的阁楼货架（参见 WDS-005）
- **作业流程**：以人工搬运为主，无大型叉车 → 阁楼货架是合适方案

## WDS 关联

对应标准：

- WDS-001 仓高评估：层高 6.5 米，可设计两层阁楼，每层净高约 2.8 米
- WDS-002 承重评估：楼面荷载设计 300kg/㎡，满足五金件存储需求
- WDS-003 消防评估：调整喷淋系统，确保每层均有消防覆盖
- WDS-004 地坪评估：原地坪满足新建立柱的承载要求
- WDS-005 货架选型评估：小件多SKU → 阁楼货架 + 轻型货架组合

# 五、解决方案

## 方案类型

选择：

☑ 阁楼货架

□ 阁楼平台

□ 重型货架

□ 横梁货架

□ 驶入式货架

□ 其他仓储方案

## 设计思路

采用 **两层阁楼货架 + 一层地面货架** 的三层存储体系：

- **一层（地面层）**：保留原有轻型货架，存放高频出库产品和较重产品
- **二层（阁楼一层）**：新建阁楼货架，存放中频产品，分为若干分区
- **三层（阁楼二层）**：存放低频产品和备货库存

核心逻辑：将 6.5 米的闲置垂直空间转化为有效存储面积，在不增加仓库面积的情况下，将可用存储面积从约 800㎡ 提升至约 1400㎡（考虑通道、楼梯等占用）。

## 核心参数

| 参数 | 数值 |
|------|------|
| 仓库面积 | 800 ㎡ |
| 层高 | 6.5 米 |
| 阁楼楼层数 | 2 层 |
| 单层净高 | 约 2.8 米 |
| 楼面荷载 | 300 kg/㎡ |
| 楼梯 | 2 处（主通道两端） |
| 货架类型 | 轻型货架 + 阁楼货架组合 |
| 库位数 | 约 5000 个（改造前约 2000 个） |
| 设备要求 | 手动液压搬运车、小推车 |

# 六、成本与收益分析

## 项目投入

预算范围：15～20 万元

包括：
- 阁楼货架钢结构（立柱、主梁、楼面板）：约 10～13 万元
- 楼梯、护栏、安全设施：约 2～3 万元
- 消防改造：约 1～2 万元
- 安装施工：约 2～3 万元

## 收益分析

改善前：
- 实际可用存储面积约 500 ㎡（扣除无效通道和浪费空间）
- 库位约 2000 个
- 旺季需外租仓库，年租金约 8 万元
- 找货平均耗时 15 分钟/次

改善后：
- 实际可用存储面积约 1400 ㎡
- 库位约 5000 个
- 无需外租仓库
- 找货时间降至约 3 分钟/次（分区+库位管理）

## ROI 分析

投入：一次性约 18 万元
年收益：节省外租仓库 8 万元 + 人工效率提升约 2 万元 ≈ 10 万元/年
回收周期：约 2 年

## 实施难点

问题一：施工期间不能完全停产。

解决方式：分区域施工，先施工仓库东侧，西侧继续使用；东侧完成后转移货物，再施工西侧。整体周期约 25 天。

问题二：原有喷淋系统需要改造。

解决方式：与消防施工单位配合，在阁楼每层增加喷淋支管，确保覆盖。

## 可制作 FAQ

问题一：五金厂仓库适合做什么类型的货架？

回答：需要看产品特点。如果是小件、多SKU的五金件（螺丝、配件等），人工拣货为主，阁楼货架通常比较合适。如果是重型五金材料，应考虑重型货架。

问题二：仓库改造大概需要多少钱？

回答：取决于仓库面积、高度、承载需求和设计方案。以 800㎡ 仓库为例，增加阁楼货架的投资一般在 15～20 万左右，具体需要现场测量后确定。

问题三：改造需要多长时间？

回答：一般 20～30 天，具体看规模和施工条件。可以分区域施工，不需要完全停产。

# 十、经验总结

## 本案例解决的问题

一个库存增长、仓库不够用的五金制造企业，通过阁楼货架改造，在不搬仓、不扩建的前提下增加了约 75% 的存储面积，同时实现了分区分类管理，拣货效率明显提升。

核心经验：**很多企业仓库不够用，不是面积问题，而是空间利用率问题。** 对有足够层高的仓库（≥5 米），立体重直利用往往是成本最低的解决方案。

## 适用企业

- 五金制造、零部件加工企业
- SKU 数量多（1000+）、单件重量较小的仓库
- 仓库层高 ≥5 米，地面条件良好
- 以人工拣货为主的作业模式
- 短期内无搬迁计划

## 不适用企业

- 货物单件重量 >50kg、需要叉车作业的企业 → 考虑重型货架或钢平台
- 仓库层高 <4.5 米 → 阁楼方案收益有限
- 大量整托进出、高频周转 → 考虑横梁式货架
- 即将搬迁的仓库 → 投资回收周期不足
