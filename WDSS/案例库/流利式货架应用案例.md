# 基础信息

CASE-046

## 行业类型

日化

---

# 一、客户背景

## 企业情况

日化经销商，纸箱小件、SKU 约 800 个，有保质期要求。

## 仓储现状

仓库类型：☑ 成品仓

面积：900 平方米

高度：层高 4.5 米

存储方式：普通货架，人工找货

---

# 二、客户问题

## 表面问题

拣货慢、临期品积压。

## 深层问题

- 先进先出做不到，临期浪费
- 找货路径长
- 批次混放

## 客户目标

先进先出 + 拣货效率提升 40%。

---

# 三、采购决策过程

## 方案调研

1. 普通货架 + 人工管理
2. 流利式货架
3. 阁楼货架

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 普通货架 | 便宜 | FIFO 靠人 |
| 流利式 | 天然 FIFO | 单层造价略高 |
| 阁楼 | 面积大 | 不解决 FIFO |

## 最终决策因素

☑ 效期 / ☑ 拣选效率

客户选择流利式货架。

---

# 四、仓储分析过程

## 现场评估

- 纸箱单箱 5～15kg，适合重力滑道
- 高频品 40% 用流利式
- 通道与拣货口衔接

## WDS 关联

- WDS-005：流利式匹配纸箱 FIFO

---

# 五、解决方案

☑ 流利式货架

设计：高频品流利式滑道，先进先出；低频品普通货架；拣货口统一。

核心参数：

| 参数 | 数值 |
|------|------|
| 流利式滑道 | 120 条 |
| 每道库位 | 6～8 箱 |
| 拣货效率 | 提升约 45% |
| 投资 | 约 35 万元 |

---

# 六、成本与收益分析

投入约 35 万元；临期报废减少约 70%；拣货效率提升约 45%。

ROI：年收益约 13 万元，回收约 2.7 年。

---

# 七、实施过程

高频品筛选 → 安装 → 批次规则培训 → 试运行，周期约 15 天。

难点：批次规则执行；解决：入库统一放后端，取货从前端，制度化。

---

# 八、项目结果

- 先进先出制度落地
- 临期报废减少约 70%
- 拣货效率提升约 45%

# 十、经验总结

解决的问题：先进先出与拣选效率。

适用企业：纸箱小件、有保质期要求的日化、食品企业。

不适用企业：重货、托盘、异形件仓库。
