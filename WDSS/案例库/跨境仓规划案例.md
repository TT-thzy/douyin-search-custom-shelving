# 一、客户背景

## 企业情况

跨境电商卖家，经营家居小件，覆盖欧美市场。

## 仓储现状

仓库类型：☑ 电商仓

面积：2000 平方米

高度：层高 5 米

存储方式：轻型货架 + 地面堆放

---

# 二、客户问题

## 表面问题

多平台多站点备货，SKU 暴涨，仓库混乱。

## 深层问题

- 按平台/站点分区不清，发货串单
- 库容不足，爆款断货与积压并存
- 打包发货区动线混乱

## 客户目标

按平台站点分区 + 爆款独立区，效率提升 30%。

---

# 三、采购决策过程

## 方案调研

1. 只加货架
2. 分区 + 动线重规划
3. 外租第二仓

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 只加货架 | 便宜 | 分区问题依旧 |
| 分区重规划 | 治本 | 需停业几天 |
| 外租二仓 | 快 | 管理成本翻倍 |

## 最终决策因素

☑ 管理效率 / ☑ 投入

客户选择分区 + 动线重规划。

---

# 四、仓储分析过程

## 现场评估

- 按平台（Amazon/eBay/独立站）分大区
- 爆款独立区就近发货
- 打包区与拣货区动线衔接

## WDS 关联

- WDS-001：5 米层高阁楼扩容评估
- WDS-005：轻型/阁楼货架选型

---

# 五、解决方案

☑ 阁楼货架 / ☑ 分区管理

设计：按平台三大区，各区内按站点分区；爆款区独立；阁楼存低频库存。

核心参数：

| 参数 | 数值 |
|------|------|
| 阁楼楼面 | 约 450 ㎡ |
| 库位数量 | 约 8500 个 |
| 打包台 | 8 个 |
| 投资 | 约 60 万元 |

---

# 六、成本与收益分析

投入约 60 万元；发货串单率下降约 90%；外租仓计划取消。

ROI：年收益约 20 万元，回收约 3 年。

---

# 七、实施过程

分区方案 → 货架安装 → 爆款迁移 → 动线测试，周期约 25 天。

难点：大促期间切换；解决：选淡季施工，分批迁移。

---

# 八、项目结果

- 平台站点分区清晰，串单率下降
- 爆款区发货提速
- 库容提升约 60%
