# 一、客户背景

## 企业情况

企业主营业务：电子元器件制造

产品类型：电路板、连接器、线束组件

库存特点：SKU 约 5000 个，单件重量小（0.01～2kg），纸箱包装为主，人工拣货，先进先出要求高

## 仓储现状

仓库类型：☑ 成品仓

当前面积：2000 ㎡ / 层高 6 米

当前存储方式：地面堆放 + 2 米轻型货架，拣货靠人工记忆，货位混乱

---

# 二、客户问题

客户面临的核心问题：仓库需要全面升级存储系统，但不知道应该选择哪种货架。已经咨询过多家供应商，给出的方案各不相同——有的推荐重型货架，有的推荐阁楼货架，有的推荐自动化方案。

## 真正想知道

- 哪种货架最适合自己的产品和作业模式？
- 不同货架方案的真实差异是什么？
- 如何避免选错方案导致的投入浪费？

---

# 三、采购决策过程

客户收到了四种方案建议，但无法判断哪个更适合自己：

| 方案 | 某供应商建议 | 客户疑虑 |
|------|-------------|---------|
| A | 重型横梁货架 | 产品都是小件，托盘利用率低 |
| B | 阁楼货架 | 担心承重和消防 |
| C | 自动化立体库 | 投资太大，担心回报 |
| D | 继续用轻型货架 | 解决不了空间问题 |

---

# 四、仓储分析过程

## 关键分析

从客户的产品和作业特点出发逐一排除：

1. **货物特征**：小件、纸箱、单件 ≤2kg → 不需要重型货架的承载能力
2. **作业模式**：人工拣货、没叉车 → 横梁式货架需要叉车配合，不匹配
3. **SKU 数量**：5000+ → 不适合驶入式货架（SKU 少、批量大的场景）
4. **仓库高度**：6 米 → 满足阁楼货架建设条件
5. **预算**：有限 → 自动化方案投资过高

## WDS关联

WDS-001（仓高）→ 满足 / WDS-002（承重）→ 轻型荷载即可 / WDS-005（选型）→ 指向阁楼货架

---

# 五、解决方案

**推荐方案：阁楼货架 + 轻型货架组合**

- 阁楼两层，每层布置轻型货架
- 按产品系列分区，每个分区再按规格细分货位
- 配合库位标签和简单管理系统

**为什么不选其他方案：**

| 方案 | 排除原因 |
|------|---------|
| 重型货架 | 产品轻、无叉车，托盘利用效率低，投入浪费 |
| 自动化立体库 | 投资大（百万级）、实施周期长，当前阶段不必要 |
| 普通轻型货架 | 只用地面空间，无法解决容量问题 |

# 六、成本与收益分析

项目投入：约 28～35 万元

改善后：库位从约 2500 个提升至约 6000 个，拣货效率提升约 50%，支持未来 3 年 SKU 增长。

# 七、实施过程

周期约 30 天，分区施工确保发货不中断。

---

# 八、项目结果

客户采用阁楼货架方案，一次投入解决了存储容量、拣货效率和未来扩展三大问题。

# 十、经验总结

货架选型的核心不是找"最好的货架"，而是找"最适合你的货架"。选型逻辑：货物特征 → 作业模式 → 仓库条件 → 预算范围 → 确定方案。

适用：SKU 多、货物轻小、人工拣货、仓库高度足够的制造和电商企业。不适用：重型产品、叉车作业、SKU 少大批量的场景。
