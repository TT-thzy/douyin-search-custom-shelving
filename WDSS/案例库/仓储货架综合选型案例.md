CASE-036

多行业混合（汽配 + 五金 + 电子小件）

# 一、客户背景

## 企业情况

企业主营业务：多品类工业品贸易与仓储配送

产品类型：汽配件（中大件）、五金件（中重件）、电子小件（轻小件）

生产模式：多品类混合存储，订单拣选发货

库存特点：

- 汽配件以纸箱和托盘为主，单件 5～50kg
- 五金件单件 1～20kg，品种多
- 电子小件单件 0.1～2kg，SKU 最多
- 全部 SKU 约 6000 个

## 仓储现状

仓库类型：

☑ 成品仓

当前面积：2000 平方米

当前高度：层高 6.2 米（梁下净高 5.8 米）

当前存储方式：

- 全部放在同一规格的层板货架上
- 层板货架承重上限 300kg/层，重件只能放一层
- 空间利用率低，通道不合理

---

# 二、客户问题

## 表面问题

仓库放不下，但不知道买什么货架。

## 深层问题

- 一种货架无法匹配三类重量差异巨大的货物
- 重件放轻型货架，安全风险高
- 轻小件占空间大，需要密集存储
- 通道和拣货动线混乱

## 客户目标

- 按货物重量分档选型，杜绝超载
- 库容提升 80% 以上
- 拣货动线顺畅，效率提升

---

# 三、采购决策过程

## 方案调研

客户考虑：

1. 全部换重型货架
2. 全部换阁楼货架
3. 按货物分档组合选型

## 方案比较

| 方案 | 优势 | 不足 | 适用情况 |
| ---- | ---- | ---- | -------- |
| 全重型货架 | 承载高、统一 | 轻小件浪费空间 | 重货为主 |
| 全阁楼货架 | 面积翻倍 | 重件存放受限 | 轻货为主 |
| 分档组合 | 匹配度高、无浪费 | 选型复杂 | 多重量等级 |

## 最终决策因素

客户最终关注：

☑ 安全性

☑ 空间利用率

☑ 拣货效率

☑ 长期成本

客户最终选择分档组合：汽配重件用重型横梁货架，五金中件用中型货架，电子小件用阁楼货架，按重量和周转率分区。

---

# 四、仓储分析过程

## 现场评估

- **仓库高度**：层高 6.2 米，净高 5.8 米，分区高度分配 → 满足（WDS-001）
- **承重**：汽配最重件 50kg/件，托盘位按 800kg/层核算；五金按 300kg/层；电子小件按 200kg/㎡ 楼面 → 满足（WDS-002）
- **消防**：喷淋覆盖、通道满足 → 满足（WDS-003）
- **地坪**：重载区 C30 地坪确认 → 满足（WDS-004）
- **货物特征**：重量分档明确 → 分档选型（WDS-005）

## WDS 关联

- WDS-001：6 米级层高按区域分配高度
- WDS-002：按最大单件和层载分档核算
- WDS-003：消防净空确认
- WDS-004：重载区地坪验证
- WDS-005：重型/中型/阁楼三档组合

---

# 五、解决方案

## 方案类型

☑ 重型货架

☑ 中型货架

☑ 阁楼货架

## 设计思路

仓库按三个区域配置：

- A 区（汽配重件）：重型横梁货架，近发货口，地牛/叉车作业
- B 区（五金中件）：中型层板货架，人工存取
- C 区（电子小件）：阁楼货架，楼上密集存储 + 楼下拣选

## 核心参数

| 参数 | 数值 |
|------|------|
| 仓库面积 | 2000 ㎡ |
| 层高 | 6.2 米 |
| A 区重型货架 | 4 层，800kg/层 |
| B 区中型货架 | 5 层，300kg/层 |
| C 区阁楼 | 楼面约 500 ㎡ |
| 总库位 | 约 15000 个（原约 8000 个） |

# 六、成本与收益分析

## 项目投入

总投资约 110 万元：

- 重型货架：约 45 万元
- 中型货架：约 25 万元
- 阁楼货架：约 28 万元
- 消防与安装：约 12 万元

## 收益分析

改善前：

- 库位约 8000 个，重件超载风险
- 拣货路径长，动线混乱

改善后：

- 库位约 15000 个，提升约 88%
- 按区域拣货，动线清晰，效率提升约 35%
- 杜绝超载，安全隐患消除

## ROI 分析

投入：约 110 万元

年收益：替代外租仓约 25 万元 + 效率提升约 10 万元 = 35 万元

回收周期：约 3.1 年

# 七、实施过程

## 项目流程

盘点分类 → 分区设计 → 消防评审 → 生产 → A 区安装 → B 区安装 → C 区阁楼施工 → 库位编号 → 验收

## 实施难点

问题一：6000 个 SKU 重新分类耗时。

解决方式：先按重量分档，再按周转率排区，盘点与设计同步进行，整体周期约 40 天。

问题二：三类货架同时施工协调。

解决方式：三个区域由同一总包协调，交叉施工，材料分批进场。

## 可制作 FAQ

问题：一个仓库多种货物，只买一种货架行吗？

回答：除非货物重量和形态高度统一，否则不建议。按重量分档组合（重型/中型/轻型或阁楼）能同时保证安全、空间利用和拣货效率。

# 十、经验总结

## 本案例解决的问题

一个同时存放汽配重件、五金中件、电子小件的 2000㎡ 仓库，通过三档货架分区组合，库位提升 88%、拣货效率提升 35%。

核心经验：多品类仓库选型的第一原则是按货物重量和形态分档，而不是"一票货架走天下"。

## 适用企业

- 货物重量跨度大的多品类仓库
- 需要同时兼顾重货存储和小件拣选的贸易/仓储企业

## 不适用企业

- 单一货物类型仓库（分档反而复杂）
- 面积很小、SKU 单一的仓库
