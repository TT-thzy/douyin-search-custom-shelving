# 一、客户背景

## 企业情况

企业主营业务：第三方物流仓储配送

产品类型：日用百货、纸箱小件与少量托盘货

生产模式：多客户混仓，按订单拣选发货

库存特点：

- 纸箱小件为主，占 70%
- 托盘货占 30%，单托 400～800kg
- SKU 约 5000 个
- 旺季出入库量是淡季的 2 倍

## 仓储现状

仓库类型：

☑ 第三方物流仓

当前面积：1800 平方米

当前高度：层高 5.2 米（梁下净高 4.8 米）

当前存储方式：

- 轻型货架 + 地面堆放混合
- 旺季货物溢出到通道
- 托盘货与纸箱货混区

---

# 二、客户问题

## 表面问题

仓库旺季不够用，扩容方案不知道怎么选。

## 深层问题

- 轻小件和托盘货存储逻辑不同
- 高度 4.8 米只用了 2 米
- 旺季外租仓成本高
- 不同供应商给了完全不同的扩容方案

## 客户目标

- 旺季不再外租仓
- 库容提升 70% 以上
- 拣货效率不下降

---

# 三、采购决策过程

## 方案调研

客户收到三套扩容方案：

1. 平面货架加密（轻型货架加高加密）
2. 阁楼货架（二楼存储）
3. 重型横梁货架（托盘化改造）

## 方案比较

| 方案 | 优势 | 不足 | 适用情况 |
| ---- | ---- | ---- | -------- |
| 平面加密 | 投入最低、周期短 | 容量提升有限 | 小面积微调 |
| 阁楼货架 | 面积翻倍、轻件适合 | 托盘货上楼困难 | 轻小件为主 |
| 全托盘化改造 | 规范、密度高 | 小件拣选效率下降 | 托盘货为主 |

## 最终决策因素

客户最终关注：

☑ 空间利用率

☑ 拣货效率

☑ 投资规模

☑ 旺季弹性

客户最终选择"阁楼货架 + 局部重型货架"组合：纸箱小件上二楼阁楼，托盘货留一楼横梁货架，兼顾两类货物并保留拣货效率。

---

# 四、仓储分析过程

## 现场评估

- **仓库高度**：层高 5.2 米，净高 4.8 米。一楼重型货架 3 层 2.6 米，二楼阁楼净高 2.0 米 → 满足（WDS-001）
- **承重**：托盘 800kg 按一楼横梁 1000kg/层设计；二楼轻件 300kg/㎡ → 满足（WDS-002）
- **消防**：二楼喷淋、疏散确认 → 满足（WDS-003）
- **地坪**：C25 地坪，重载区核算满足 → 满足（WDS-004）
- **货物特征**：纸箱 70% + 托盘 30% → 组合方案（WDS-005）

## WDS 关联

- WDS-001：4.8 米净高分区分配
- WDS-002：一楼重托、二楼轻件分档核算
- WDS-003：二楼消防专项
- WDS-004：重载区地坪验证
- WDS-005：轻件阁楼式、托盘横梁式

# 五、解决方案

## 方案类型

☑ 阁楼货架

☑ 横梁货架

□ 驶入式货架

## 设计思路

- 一楼：横梁货架存托盘货（叉车/地牛作业），靠近收货区
- 二楼：阁楼货架存纸箱小件，按客户分区，人工拣选
- 拣货动线：二楼拣选后经滑道下到一楼发货区
- 旺季弹性：预留二楼扩展区

## 核心参数

| 参数 | 数值 |
|------|------|
| 仓库面积 | 1800 ㎡ |
| 层高 | 5.2 米 |
| 二楼楼面 | 约 700 ㎡ |
| 库位数量 | 约 18000 个（原约 10000 个） |
| 楼面承重 | 300 kg/㎡ |
| 作业设备 | 电动地牛 + 拣选车 |

# 六、成本与收益分析

## 项目投入

总投资约 76 万元：

- 阁楼货架结构及楼面：约 40 万元
- 一楼横梁货架：约 18 万元
- 滑道与拣选设备：约 6 万元
- 消防配合：约 7 万元
- 安装施工：约 5 万元

## 收益分析

改善前：

- 库位约 10000 个，旺季外租 1200 ㎡（年租金约 16 万元）
- 通道被货物占用，拣货效率低

改善后：

- 库位约 18000 个，提升约 80%
- 旺季不外租仓，年省租金约 16 万元
- 拣货动线顺畅，效率提升约 30%

## ROI 分析

投入：约 76 万元

年收益：外租仓 16 万元 + 效率提升折约 8 万元 = 24 万元

回收周期：约 3.2 年

# 七、实施过程

## 项目流程

需求确认 → 货物盘点 → 分区设计 → 消防评审 → 生产 → 一楼安装 → 二楼施工 → 库位编号 → 拣货测试 → 验收

## 实施难点

问题一：旺季施工影响运营。

解决方式：选择淡季施工，先建二楼再转移纸箱货，一楼重型货架最后安装，整体周期约 35 天。

问题二：托盘货和纸箱货动线交叉。

解决方式：收货区分流，托盘货进一楼，纸箱货经提升机上二楼，发货在出口汇合。

# 十、经验总结

## 本案例解决的问题

一个纸箱小件与托盘货混合的物流仓，通过"阁楼货架 + 局部横梁货架"组合扩容，库位提升 80%、取消旺季外租仓。

核心经验：扩容方案的比较不能只看单价，要看方案与货物特征的匹配度，组合方案往往优于单一方案。

## 适用企业

- 轻小件与托盘货混合的仓储企业
- 旺季波峰明显、外租仓成本高的企业
- 层高 4.5 米以上、面积受限的仓库

## 不适用企业

- 纯托盘重货仓库（组合方案复杂化）
- 层高不足 4 米的仓库
- 业务萎缩、无需扩容的企业
