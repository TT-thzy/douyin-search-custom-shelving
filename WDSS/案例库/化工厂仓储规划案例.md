# 基础信息

## 案例名称

化工厂危化品分区仓储规划案例

## 案例编号

CASE-021

## 行业类型

化工

## 企业规模

☑ 中型企业

仓库面积：1500 平方米

---

# 一、客户背景

## 企业情况

涂料化工企业，存储原材料（树脂、溶剂、助剂）和成品。

## 仓储现状

仓库类型：☑ 原材料仓 / ☑ 成品仓

面积：1500 平方米

高度：层高 5 米

存储方式：桶装地面堆放，类别混杂

---

# 二、客户问题

## 表面问题

安全评估要求整改，化学品混放有燃爆风险。

## 深层问题

- 不相容化学品未隔离
- 无防泄漏托盘和导流设施
- 防爆电气缺失

## 客户目标

按危化品分类分区，防泄漏、防爆达标。

---

# 三、采购决策过程

## 方案调研

1. 局部隔离整改
2. 全面分区 + 防爆改造
3. 外包专业危化品仓

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 局部整改 | 便宜 | 合规不彻底 |
| 全面改造 | 一次达标 | 投入高 |
| 外包 | 省心 | 长期成本高 |

## 最终决策因素

☑ 安全合规 / ☑ 长期成本

客户选择全面分区 + 防爆改造。

---

# 四、仓储分析过程

## 现场评估

- 化学品按性质分类（易燃液体、腐蚀品、氧化剂）
- 不相容物分区/分库存放
- 桶装区配防泄漏托盘和导流沟
- 防爆电气、防静电接地

## WDS 关联

- WDS-003：消防分区与防爆要求
- WDS-002：桶装荷载核算
- WDS-005：防腐货架按分区选型

---

# 五、解决方案

☑ 分区隔离 / ☑ 防泄漏托盘 / ☑ 防爆改造

设计：三个危险区独立隔离；桶装区防泄漏托盘；防腐货架按类别分区；防爆照明与接地。

核心参数：

| 参数 | 数值 |
|------|------|
| 危险分区 | 3 个 |
| 防泄漏托盘 | 60 个 |
| 库位数量 | 约 2200 个 |
| 投资 | 约 85 万元 |

---

# 六、成本与收益分析

投入约 85 万元；安全评估一次通过，避免停产整改损失。

ROI：按避免事故与停产损失估算约 2.5 年回收。

---

# 七、实施过程

化学品分类清单 → 分区设计 → 防爆改造 → 防漏设施安装 → 评估验收，周期约 45 天。

难点：施工期间危化品转移；解决：先建一个合规区，逐区转移。

---

# 八、项目结果

- 安全评估一次通过
- 不相容化学品物理隔离
- 防泄漏、防爆设施到位

# 十、经验总结

解决的问题：危化品混放与防爆缺失。

适用企业：化工、涂料、油墨等危化品仓储企业。

不适用企业：普通常温货物仓库。
