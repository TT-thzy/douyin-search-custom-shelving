# 二、客户问题

## 表面问题

仓库看起来满，但经常找不到货，发货还发错。

## 深层问题

- 区域没有划分，原材料和成品混放
- 动线交叉：收货、发货互相干扰
- 库位无编号，找货靠记忆
- 不良品和合格品混放，质量风险

## 客户目标

- 区域分明、动线清晰
- 库位编号管理，找货 3 分钟内完成
- 不良品隔离存放

---

# 三、采购决策过程

## 方案调研

客户考虑：

1. 只买新货架，不调整布局
2. 重新规划布局 + 补充货架
3. 整体搬迁新仓

## 方案比较

| 方案 | 优势 | 不足 | 适用情况 |
| ---- | ---- | ---- | -------- |
| 只买货架 | 简单直接 | 布局问题依旧，治标不治本 | 布局合理仅缺货架 |
| 布局优化 | 治本、投入可控 | 需要短期停线配合 | 布局混乱、空间浪费 |
| 整体搬迁 | 一步到位 | 成本高、影响生产 | 原仓条件差 |

## 最终决策因素

☑ 管理效率

☑ 投入可控

☑ 扩展能力

客户选择重新规划布局：投入远低于搬迁，却能同时解决找货、动线和质量隔离问题。

# 四、仓储分析过程

## 现场评估

# 五、解决方案

## 方案类型

☑ 横梁货架

☑ 中型货架

□ 阁楼货架

## 设计思路

按"收货区 → 存储区 → 拣选区 → 发货区"一字动线重新布局：

- 原材料区靠近收货口，4 层横梁货架
- 半成品区在生产领料通道旁，中型货架
- 成品区靠近发货口
- 不良品区独立隔离
- 全仓库位编号 + 地面划线

## 核心参数

| 参数 | 数值 |
|------|------|
| 仓库面积 | 2200 ㎡ |
| 层高 | 6 米 |
| 库位数量 | 约 5200 个（原约 2800 个） |
| 动线 | 一字型单向 |
| 投资 | 约 58 万元 |

---

# 六、成本与收益分析

投入：约 58 万元（货架 40 万 + 划线标识 3 万 + 安装 5 万 + 消防配合 10 万）

收益：

- 找货时间从 10 分钟降至 2 分钟
- 发错货率下降约 80%
- 库位提升约 85%

ROI：年收益约 20 万元，回收约 2.9 年

---

# 七、实施过程

先规划动线 → 分期搬迁 → 划线编号 → 上货架 → 验收，分区施工约 30 天，生产未中断。

实施难点：生产不停。解决：按区迁移，先建成品区，再迁半成品和原材料。

---

# 八、项目结果

- 区域分明，动线单向不交叉
- 找货时间降至 2 分钟，发错货率下降
- 不良品隔离，质量风险消除

# 十、经验总结

本案例解决的问题：布局混乱导致的找货慢、发错货、空间浪费。

适用企业：制造企业仓库、区域无划分、动线交叉的企业。

不适用企业：新建仓库（按规划一次到位即可）。
