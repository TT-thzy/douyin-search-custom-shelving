# 一、客户背景

## 企业情况

企业主营业务：电商第三方仓储代运营，服务家居小件和美妆类客户

产品类型：纸箱小件为主，单箱重量 0.5～15kg

生产模式：多客户、多 SKU 混合存储，按订单拣选发货

库存特点：

- SKU 数量约 8000 个
- 日均订单量 3000～4000 单
- 货物以纸箱、周转箱为主，无托盘化需求
- 大促期间订单量翻倍，仓库明显承压

## 仓储现状

仓库类型：

☑ 电商仓

当前面积：1500 平方米

当前高度：层高 5.5 米（梁下净高约 5.0 米）

当前存储方式：

- 平面轻型货架 + 地面堆放混合
- 货架只有 2 层，高度利用率低
- 通道狭窄，拣货车通行困难
- 库位靠人工记忆，找货效率低

---

# 二、客户问题

## 表面问题

仓库放不下货，大促前需要大量外租临时仓。

## 深层问题

- SKU 持续增加，平面货架容量跟不上
- 5 米净高只用了一半，垂直空间浪费
- 拣货路径长，订单处理效率低
- 外租仓成本高、管理分散

## 客户目标

- 不扩大仓库面积，提升存储容量 60% 以上
- 缩短拣货路径，提升订单处理效率
- 取消大促临时外租仓

---

# 三、采购决策过程

## 方案调研

客户考虑过：

1. 平面轻型货架加高加密
2. 阁楼货架（两层存储）
3. 自动化立体库
4. 继续外租临时仓

## 方案比较

| 方案 | 优势 | 不足 | 适用情况 |
| ---- | ---- | ---- | -------- |
| 平面货架加高 | 投入低、周期短 | 容量提升有限，拣货效率改善小 | 小规模仓库 |
| 阁楼货架 | 面积翻倍、拣货集中 | 需评估消防和结构 | 小件、多SKU、人工拣选 |
| 自动化立体库 | 吞吐效率高 | 投资高，小件拣选不匹配 | 托盘、大批量场景 |
| 外租临时仓 | 解决短期爆仓 | 成本高、管理分散 | 应急方案 |

## 最终决策因素

客户最终关注：

☑ 使用面积

☑ 拣货效率

☑ 投资规模

☑ 施工周期

□ 最低初始投资

☑ 扩展能力

客户最终选择阁楼货架方案：SKU 多、单件轻、人工拣选的特点与阁楼货架高度匹配，5.5 米层高可做两层，投资远低于自动化方案，且能在大促前完成施工。

# 四、仓储分析过程

## 现场评估

- **仓库高度**：层高 5.5 米，梁下净高 5.0 米。一楼横梁货架净高 2.6 米，二楼阁楼货架净高 2.2 米，顶部预留 0.2 米 → 满足条件（WDS-001）
- **承重**：小件纸箱，楼面设计荷载 400kg/㎡，含人员作业余量 → 满足（WDS-002）
- **消防**：二楼设喷淋覆盖和疏散通道，货架与喷淋距离预留 → 满足（WDS-003）
- **地坪**：混凝土 C25，立柱点荷载分散后满足要求 → 满足（WDS-004）
- **货物特征**：纸箱小件、SKU 8000、人工拣选 → 阁楼货架匹配（WDS-005）

## WDS 关联

- WDS-001 仓高评估：5.0 米净高按两层设计，垂直空间利用率提升约 90%
- WDS-002 承重评估：楼面 400kg/㎡，按小件荷载设计避免过度投入
- WDS-003 消防评估：二层喷淋与疏散专项设计
- WDS-004 地坪评估：确认地坪承载满足立柱荷载
- WDS-005 货架选型评估：小件多 SKU 人工拣选 → 阁楼货架

# 五、解决方案

## 方案类型

☑ 阁楼货架

☑ 横梁货架（一层）

□ 阁楼平台

□ 驶入式货架

## 设计思路

采用"一层横梁货架 + 二层阁楼货架"组合：

- 一楼：横梁货架存放重箱、大件和整箱周转货物，叉车/地牛作业
- 二楼：阁楼货架按 SKU 分区，人工拣选，靠近拣货出口
- 拣货区：二楼设流利式滑道拣货位，订单波次拣选
- 库位编号：全仓库位编号，结合简易 WMS 管理

## 核心参数

| 参数 | 数值 |
|------|------|
| 仓库面积 | 1500 ㎡ |
| 层高 | 5.5 米 |
| 阁楼楼面 | 约 700 ㎡ |
| 楼面承重 | 400 kg/㎡ |
| 库位数量 | 约 12000 个（原约 6500 个） |
| 拣货效率 | 提升约 40% |
| 作业设备 | 电动地牛 + 人工拣选车 |

# 六、成本与收益分析

## 项目投入

总投资约 68 万元：

- 阁楼货架结构及楼面：约 38 万元
- 一楼横梁货架：约 12 万元
- 流利式拣货线：约 8 万元
- 消防配合（喷淋、疏散）：约 6 万元
- 安装施工：约 4 万元

## 收益分析

改善前：

- 库位约 6500 个，大促需外租仓约 1500 ㎡（年租金约 22 万元）
- 拣货路径长，日均 4000 单需拣货人员 18 人

改善后：

- 库位约 12000 个，容量提升约 85%
- 取消大促外租仓，年省租金约 22 万元
- 拣货人员减至 14 人，年省人工约 10 万元

## ROI 分析

投入：约 68 万元

年收益：约 32 万元

回收周期：约 2.1 年

# 七、实施过程

## 项目流程

需求确认 → 现场测量 → 方案设计 → 消防评审 → 生产 → 一楼安装 → 二层楼面施工 → 货架安装 → 库位编号 → 拣货动线测试 → 验收

## 实施难点

问题一：施工期间仓库不能停运。

解决方式：先装靠墙一侧，货物逐步转移，分两批施工，整体周期约 25 天。

问题二：二楼消防要求高。

解决方式：方案阶段与消防单位对接，二楼设置喷淋、疏散楼梯和应急照明，一次验收通过。

# 十、经验总结

## 本案例解决的问题

一个 SKU 8000 个的电商仓，通过"一层横梁货架 + 二层阁楼货架 + 流利式拣选"组合方案，库位提升 85%、拣货效率提升 40%，并取消了每年 22 万元的外租仓成本。

核心经验：电商仓的扩容优先靠"向上要空间"，但前提是货物特征（小件、轻、人工拣选）与阁楼货架匹配。

## 适用企业

- SKU 多、单件轻、人工拣选的电商仓
- 层高 4.5 米以上、面积受限的仓库
- 有大促波峰、临时外租仓成本高的企业

## 不适用企业

- 托盘化、叉车作业的仓库（选横梁式或重型货架）
- 层高不足 4 米的仓库（阁楼收益有限）
- 以重货、大件为主的仓库
