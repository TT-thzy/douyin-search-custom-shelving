# 基础信息

## 案例名称

纸品仓库货架消防评估案例

## 案例编号

CASE-013

## 行业类型

纸品制造

## 企业规模

☑ 中型企业

仓库面积：1800 平方米

---

# 一、客户背景

## 企业情况

纸箱厂成品仓库，存储瓦楞纸箱成品。

库存特点：纸箱可燃物，堆垛密集，SKU 约 200 个

## 仓储现状

仓库类型：☑ 成品仓

面积：1800 平方米

高度：层高 6 米

存储方式：地面堆垛为主

---

# 二、客户问题

## 表面问题

上货架后消防验收能不能过？

## 深层问题

- 纸品易燃，消防要求高
- 货架高度与喷淋净空冲突
- 通道宽度与消防通道要求冲突

## 客户目标

货架方案一次通过消防验收，不返工。

---

# 三、采购决策过程

## 方案调研

1. 先装货架再改消防
2. 消防与货架同步设计
3. 降低货架高度迁就喷淋

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 先装后改 | 快 | 返工风险大 |
| 同步设计 | 一次到位 | 需要前期对接 |
| 降高度 | 简单 | 空间利用率下降 |

## 最终决策因素

☑ 验收一次通过 / ☑ 空间利用

客户选择消防与货架同步设计。

---

# 四、仓储分析过程

## 现场评估

- 现有喷淋系统，喷头高度约 6.3 米
- 货架总高需预留顶部 ≥0.5 米净空
- 主通道需满足消防疏散宽度
- 纸品属丙类可燃物，需按规范分区

## WDS 关联

- WDS-003：消防净空、通道、分区专项评估
- WDS-001：按消防净空反推货架高度
- WDS-005：货架布局与消防分区匹配

---

# 五、解决方案

☑ 横梁货架（4 层，总高 5.6 米，喷淋净空 0.7 米）

设计：主通道 4 米，消防疏散通道贯通；货架分区按防火单元控制面积；顶部喷淋覆盖验证。

核心参数：

| 参数 | 数值 |
|------|------|
| 货架层数 | 4 层 |
| 货架总高 | 5.6 米 |
| 喷淋净空 | 0.7 米 |
| 主通道 | 4 米 |
| 投资 | 约 46 万元（含消防配合 8 万） |

---

# 六、成本与收益分析

投入约 46 万元；较先装后改方案预计节省返工费约 6 万元；库位提升约 90%。

ROI：约 3.1 年回收。

---

# 七、实施过程

消防评审先行 → 生产 → 安装 → 喷淋配合调整 → 一次验收通过，周期约 40 天。

难点：喷淋覆盖与货架层数冲突；解决：货架横梁开孔让位喷淋，布局按消防平面调整。

---

# 八、项目结果

- 消防验收一次通过，无返工
- 库位提升约 90%
- 建立了货架消防检查台账

# 九、内容资产转换

可制作 FAQ：货架顶部离喷淋多远？

回答：常见要求货架顶部与喷淋头保持不小于 0.5 米，具体按当地消防规定。设计货架高度时就要留足净空，避免验收返工。

# 十、经验总结

解决的问题：可燃物仓库货架与消防冲突。

适用企业：纸品、日化、纺织等可燃物仓库。

不适用企业：无消防要求的轻小件仓库。
