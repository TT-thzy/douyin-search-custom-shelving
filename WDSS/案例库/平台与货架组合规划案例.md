# 一、客户背景

## 企业情况

企业主营业务：汽车底盘零部件、发动机支架、传感器支架等金属加工件制造

产品类型：
- 重型原材料：铸件毛坯、锻造件、钢板原料（单件重量 50～500kg）
- 轻型成品：传感器支架、小五金件、电子线束组件（单件重量 0.05～5kg）

生产模式：按订单生产 + 常备标准件库存

库存特点：
- 原材料库 SKU 约 600 个，单品重量大，整托存储为主
- 成品库 SKU 约 2500 个，多品种小批量
- 重型原料需叉车搬运，轻型成品人工拣选
- 原料周转约 15 天，成品周转约 30 天

## 仓储现状

仓库类型：

☑ 原料仓

☑ 成品仓

当前面积：3000 平方米（原料区约 1200㎡，成品区约 1800㎡）

当前高度：层高 7.8 米（梁下净高约 7.2 米）

当前存储方式：
- 原料区：地面堆放 + 少量重型货架（3 层横梁式），堆放高度约 2 米
- 成品区：轻型货架（2 米高，5 层），人工存取
- 通道规划不合理，叉车通道和人行通道混用
- 两个区域完全独立，没有统一的空间规划

# 二、客户问题

## 表面问题

原料区堆满地面，叉车通行困难；成品区货架不够用，新到的成品堆在地上。两个存储区都满了，但仓库上方 5 米多的空间完全闲置。

## 深层问题

进一步分析后发现，这不是简单的"空间不够"，而是"两种完全不同的存储需求被错误地放在了同一个平面"：

- 原料区需要叉车通行（通道宽 ≥3 米）、重型承载（每托 ≥1 吨），但只利用了 2 米高度
- 成品区需要密集存储（多 SKU 小件）、人工拣选，但同样只用了 2 米高度
- 两种需求矛盾：重型区需要宽通道，轻型区需要密集排列。如果只用一种货架方案，必然有一方的需求被牺牲
- 企业曾被某供应商推荐"全做重型货架"，但重型货架的层板对小件存储效率极低
- 另一供应商推荐"全做阁楼货架"，但阁楼货架承重无法支撑重型原料
- 原料库存预计未来一年增长 40%，成品 SKU 预计增加 500 个

## 客户目标

- 在不搬仓的前提下，将总存储容量提升 80% 以上
- 原料区和成品区分别采用最适合的方案，而非一刀切
- 保持叉车作业通道畅通，同时提升小件人工拣选效率
- 控制总投资在 80～120 万元以内
- 施工期间不能停产超过 7 天

# 三、采购决策过程

## 发现问题

客户在生产旺季期间发现：
- 原料到货后找不到存放位置，只能在车间临时候放
- 成品出货时找货困难，一单出货需要 3 个人花 2 小时找货
- 仓库主管提出辞职，原因是"仓库管理靠吼、靠记忆，太累了"
- 企业老板参观同行工厂后，发现人家同样的面积存了三倍的货

## 方案调研

客户考虑过四个方案：

1. **全部使用重型横梁货架** -- 统一用高位重型货架覆盖整个仓库
2. **全部使用阁楼货架** -- 建两层阁楼，上层存原料下层存成品
3. **分区域钢平台 + 阁楼货架** -- 原料区建钢平台（重型存储），成品区建阁楼货架（轻型拣选）
4. **搬迁仓库** -- 直接找更大的仓库

## 方案比较

| 方案 | 优势 | 不足 | 适用情况 |
| ---- | ---- | ---- | -------- |
| 全部重型横梁货架 | 承重好、叉车可作业 | 小件存储效率低、空间浪费大、投资高 | 单一重型货物存储 |
| 全部阁楼货架 | 小件存得多、人工拣选方便 | 无法承载重型原料、叉车无法上楼 | 单一轻型货物存储 |
| 分区钢平台 + 阁楼组合 | 各区域按需设计、兼顾重型与轻型 | 设计复杂度高、需协调两种施工 | 混合存储需求（本案例） |
| 搬迁仓库 | 面积大幅增加 | 搬迁成本 60 万+、运营中断、合适仓库难找 | 现有仓库无法改造 |

## 最终决策因素

客户最终关注：

☑ 使用面积 -- 实际增加多少有效存储

☑ 安全 -- 重型区域的承重必须达标

☑ 功能匹配 -- 每种货物需要对应的存储方式

□ 价格 -- 不是主要考虑因素，只要方案合理

☑ 施工周期 -- 必须控制在合理范围内

☑ 长期扩展 -- 未来还能灵活调整

客户最终选择了"分区钢平台 + 阁楼货架组合"方案。核心原因是，原料区和成品区的存储需求本质不同，一刀切的方案无法满足两种需求。只有组合方案才能做到"重型区用重型的、轻型区用轻型的"。

# 四、仓储分析过程

## 现场评估

评估内容：

- **仓库高度**：层高 7.8 米，梁下净高 7.2 米。→ 满足钢平台和阁楼货架建设条件（参见 WDS-001）
  - 原料区设计：一层地面重型叉车作业 + 二层钢平台上存较轻原料（单托 ≤800kg）
  - 成品区设计：一层地面 + 两层阁楼货架，手工拣选
- **地面情况**：C30 混凝土，厚度 180mm，平整度良好。→ 满足重型立柱和叉车作业承载（参见 WDS-004）
- **柱距**：9 米 × 9 米柱网，空间规整 → 布局灵活
- **消防条件**：已有消防栓和自动喷淋系统，消防通道宽度达标。→ 需要在钢平台和阁楼每层增加喷淋（参见 WDS-003）
- **货物承载分析**：原料区单托最大 1.5 吨，叉车自重 + 载重约 3.5 吨 → 钢平台楼面荷载需设计 ≥1 吨/㎡（参见 WDS-002）
- **成品区**：单件 ≤5kg，周转箱存储 → 阁楼货架楼面荷载 250kg/㎡ 即可（参见 WDS-005）

## WDS 关联

对应标准：

- WDS-001 仓高评估：层高 7.8 米 → 原料区设计两层（地面 + 钢平台上层），成品区设计三层（地面 + 两层阁楼）
- WDS-002 承重评估：原料区钢平台楼面荷载 1000kg/㎡，叉车通道区单独加强；成品区阁楼楼面荷载 250kg/㎡
- WDS-003 消防评估：改造喷淋系统，确保钢平台和阁楼每层均有消防覆盖，钢平台下方增加烟感
- WDS-004 地坪评估：C30 混凝土 180mm 厚，满足重型立柱基础承载，钢平台立柱需做独立基础
- WDS-005 货架选型评估：原料区 → 钢平台 + 重型横梁货架组合；成品区 → 两层阁楼货架 + 轻型货架组合

# 五、解决方案

## 方案类型

选择：

□ 阁楼货架（仅成品区）

□ 阁楼平台（仅原料区）

□ 重型货架（仅原料区一层）

☑ 钢平台 + 重型货架（原料区）

☑ 阁楼货架 + 轻型货架（成品区）

□ 其他仓储方案

**说明**：本案例采用了两种方案的组合。这是混合存储需求的典型解决方案。

## 设计思路

**整体布局**：将 3000㎡ 仓库分为两个独立区域，分别采用最适合的存储方案。

**原料区（约 1200㎡）**：建设钢平台结构。
- 一层地面层（约 1200㎡）：叉车作业区，配置重型横梁货架，4 层存储，存放最重的铸件毛坯和钢板原料
- 二层钢平台（约 900㎡，扣除楼梯和通道）：人工 + 电动堆高车作业区，存放中等重量的半成品和较轻原料
- 预留叉车上货口（液压升降平台），可运输 ≤1 吨的托盘到二层
- 一层通道宽度 3.5 米（叉车通行），二层通道宽度 2 米（堆高车通行）

**成品区（约 1800㎡）**：建设两层阁楼货架。
- 一层地面层（约 1800㎡）：高频出库成品，配置轻型货架，人工拣选
- 二层阁楼（约 1400㎡）：中频出库成品，按品类分区
- 三层阁楼（约 1400㎡）：低频备货和包材存储
- 每层配置 3 处楼梯，1 处小型货运电梯（载重 300kg）

**核心逻辑**：不同类型的货物，其存储和搬运方式完全不同。重型原料需要的是承重和叉车通道，而轻型成品需要的是密集存储和高效拣选。组合方案的本质是"匹配"，而非"统一"。

## 核心参数

| 参数 | 原料区（钢平台） | 成品区（阁楼货架） |
|------|------------------|---------------------|
| 区域面积 | 1200 ㎡ | 1800 ㎡ |
| 设计方案 | 一层地面 + 二层钢平台 | 一层地面 + 两层阁楼 |
| 单层净高 | 一层 3.5m / 二层 3.2m | 每层约 2.5m |
| 楼面荷载 | 1000 kg/㎡（钢平台） | 250 kg/㎡（阁楼） |
| 通道宽度 | 一层 3.5m / 二层 2m | 每层 1.5m |
| 上下通道 | 楼梯 2 处 + 液压升降平台 1 处 | 楼梯 3 处 + 小型货梯 1 处 |
| 货架类型 | 重型横梁货架（一层） + 中型货架（二层） | 轻型货架（每层） |
| 库位数（改造前） | 约 600 托 | 约 3000 个 |
| 库位数（改造后） | 约 1800 托 | 约 10000 个 |
| 作业设备 | 叉车（一层）、电动堆高车（二层） | 手推车、手动液压车 |
| 建设面积合计 | 约 2100 ㎡（含二层） | 约 4600 ㎡（含二、三层） |

# 七、实施过程

## 项目流程

需求沟通与现场测量
↓
分区方案设计（原料区 + 成品区独立设计）
↓
结构计算与图纸确认（委托有资质的设计院复核）
↓
消防方案报审
↓
报价确认与合同签订
↓
材料采购与加工（约 30 天）
↓
分区域施工（先成品区、后原料区）
↓
消防验收
↓
整体验收投入使用

## 实施难点

问题一：两种不同结构在同一仓库内施工，施工协调难度大。

解决方式：分阶段施工，先完成成品区阁楼货架（施工周期约 20 天），在此期间成品暂时移至原料区一角。成品区完成后移回成品，再施工原料区钢平台（施工周期约 25 天）。整个仓库只停产 5 天（整体切换期间）。

问题二：原料区钢平台需要独立基础，原地坪局部需要破除。

解决方式：与土建单位配合，在立柱位置开挖基础坑（80cm × 80cm × 50cm），浇筑钢筋混凝土独立基础，养护 7 天后开始安装钢结构。

问题三：液压升降平台的安装位置受柱距限制。

解决方式：调整钢平台边缘布局，在靠近卸货口的一侧预留升降平台位置，该区域钢平台做局部加强处理。

## 客户价值

客户获得：
- 混合存储需求的系统化解决方案 -- 知道"什么货在什么区域用什么方式存储"
- 仓储能力支撑未来 3 年的业务增长
- 仓库作业标准化，不再依赖个人经验和记忆
- 分区域的设计为未来单独改造或扩展某个区域提供了灵活性
- 建立起"按照存储需求选择解决方案"的思维方式

## 可制作 FAQ

问题一：阁楼平台和阁楼货架有什么区别？怎么选？

回答：核心区别是承载能力。阁楼平台（也叫钢平台）是独立钢结构，承重可达 500～1500kg/㎡，适合重型货物和叉车作业；阁楼货架是货架+楼面一体化结构，承重通常 200～350kg/㎡，适合轻型货物和人工拣选。如果仓库既有重型原料又有轻型成品，可以像本案例一样分区组合使用。

问题二：一个仓库可以同时用两种不同的货架方案吗？

回答：完全可以。事实上，当仓库存储的货物类型差异很大时（比如既有几百公斤的原料，又有不到一公斤的小件），组合方案往往比统一方案更高效、更经济。关键是根据每种货物的存储需求分别设计。

问题三：钢平台和阁楼货架组合方案的投资会比单一方案高吗？

回答：不一定。组合方案的总投资可能在中间水平，但由于每个区域都用了最匹配的方案，综合效益通常更好。如果为了省钱而用单一方案（比如全部用重型货架存小件），长期运营成本和效率损失可能远超节省的投资。

# 十、经验总结

## 本案例解决的问题

一个汽车零部件制造企业，仓库既有需要叉车作业的重型原料，又有需要人工拣选的轻型成品。通过分区规划，在原料区采用"钢平台 + 重型货架"，在成品区采用"阁楼货架 + 轻型货架"，将总存储容量提升了 228%，同时大幅改善了作业效率。

核心经验：**混合存储需求不能用单一方案解决。仓库规划的本质是"匹配" -- 什么货物对应什么存储方式、什么搬运工具。一刀切的方案看似简单，实则是用错误的方式存储了一半的货物。**

## 适用企业

- 仓储产品类型差异大的制造企业（既有重型材料又有轻型成品）
- 需要叉车和人工两种作业模式并存的仓库
- 仓库层高 ≥6 米，具备立体化利用条件
- 希望根据货物特点分别设计存储方案的企业
- 愿意接受一定复杂度以换取更好长期效益的企业

## 不适用企业

- 产品类型单一、存储需求一致的企业 → 单一方案更经济
- 仓库面积过小（<500㎡） → 分区后每个区域面积不足以发挥优势
- 所有货物都需要重型叉车作业 → 全部用重型货架即可
- 预算极度有限、无法接受组合方案初期投入的企业
- 临时仓库、短期租用仓库 → 投资回收周期不够
