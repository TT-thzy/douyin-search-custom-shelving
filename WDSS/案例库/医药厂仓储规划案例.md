# 医药厂仓储规划案例

版本：v0.1

状态：Active

# 基础信息

## 案例名称

医药企业 GSP 合规仓储规划案例

## 案例编号

CASE-020

## 行业类型

医药

## 企业规模

☑ 中型企业

仓库面积：2000 平方米

---

# 一、客户背景

## 企业情况

医药批发企业，经营中西成药，需通过 GSP 认证。

## 仓储现状

仓库类型：☑ 成品仓

面积：2000 平方米

高度：层高 5.5 米

存储方式：地面堆放 + 层板货架，无温湿度监控

---

# 二、客户问题

## 表面问题

GSP 检查过不了，需要整体改造。

## 深层问题

- 分区不全（缺待验、不合格、退货区）
- 无温湿度连续监测
- 药品落地、无批次效期管理

## 客户目标

一次通过 GSP 认证，日常合规可维持。

---

# 三、采购决策过程

## 方案调研

1. 只补分区和温控
2. 货架 + 分区 + 温控整体改造
3. 外租专业医药物流仓

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 只补缺项 | 省预算 | 货架不达标仍不行 |
| 整体改造 | 一次到位 | 投入较高 |
| 外租仓 | 省心 | 长期成本高 |

## 最终决策因素

☑ 合规 / ☑ 长期成本

客户选择整体改造。

---

# 四、仓储分析过程

## 现场评估

- 分区：合格品/待验/不合格/退货四区独立
- 温湿度：10～30℃、35～75%RH 连续监测
- 离地：药品不落地，留检查间距
- 货架：按盒装和整托分档

## WDS 关联

- WDS-001：层高分区分配
- WDS-002：按药品包装荷载配置
- WDS-003：消防分区
- WDS-005：整托横梁式、盒装阁楼式

---

# 五、解决方案

☑ 横梁货架 / ☑ 阁楼货架 / ☑ 温湿度监控

设计：整托区横梁货架；盒装区阁楼货架；四区物理隔离；温湿度监控 + 超限报警。

核心参数：

| 参数 | 数值 |
|------|------|
| 库位数量 | 约 7500 个 |
| 温湿度探头 | 12 个 |
| 四区面积 | 各 100～200 ㎡ |
| 投资 | 约 96 万元 |

---

# 六、成本与收益分析

投入约 96 万元；对比外租专业仓年租金 60 万元，ROI 约 1.6 年。

---

# 七、实施过程

GSP 条款核对 → 分区改造 → 温控安装 → 货架安装 → 验证确认 → 认证，周期约 50 天。

难点：温湿度验证周期长；解决：提前安装监控，同步做验证记录。

---

# 八、项目结果

- GSP 一次通过
- 四区独立，合规可维持
- 温湿度全程可追溯

# 十、经验总结

解决的问题：GSP 合规缺失。

适用企业：医药生产、批发、零售企业。

不适用企业：非药品仓库。
