# 一、客户背景

## 企业情况

五金冲压件制造企业，产品为锁具、紧固件、冲压件。

库存特点：铸件重件、钢材长料、散装小件三类货物并存

## 仓储现状

仓库类型：☑ 原材料仓 / ☑ 成品仓

面积：1800 平方米

高度：层高 6.5 米

存储方式：地面堆放为主，重件轻件混放

---

# 二、客户问题

## 表面问题

仓库乱、重件压坏小件、长料倾倒有风险。

## 深层问题

- 重件、长料、散件混区存放
- 长料竖放靠墙，安全隐患
- 无分区和编号，找货慢

## 客户目标

三类货物分区存放，安全、好找、容量提升。

---

# 三、采购决策过程

## 方案调研

1. 只买货架不分区
2. 分区分档选货架
3. 扩建仓库

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 只买货架 | 简单 | 混放问题依旧 |
| 分区选型 | 治本 | 需要盘点分类 |
| 扩建 | 面积大 | 投入高 |

## 最终决策因素

☑ 安全性 / ☑ 空间利用 / ☑ 投入

客户选择分区选型方案。

---

# 四、仓储分析过程

## 现场评估

- 铸件单件 30～150kg，需重型货架
- 钢管、型材长 3～6 米，需长料架/悬臂架
- 散件按 SKU 分区，中型货架

## WDS 关联

- WDS-001：6.5 米层高按区域分配
- WDS-002：重件区按最大单托核算
- WDS-004：重载区地坪验证
- WDS-005：按货物形态分档选型

---

# 五、解决方案

☑ 重型货架 / ☑ 悬臂式货架 / ☑ 中型货架

设计：A 区铸件重件（重型货架+叉车）、B 区长料（悬臂架横放）、C 区散件（中型货架按品种分区）。

核心参数：

| 参数 | 数值 |
|------|------|
| 重件区层载 | 1000 kg |
| 长料架层数 | 4 层 |
| 库位数量 | 约 4800 个 |
| 投资 | 约 62 万元 |

---

# 六、成本与收益分析

投入约 62 万元；库位提升约 95%；消除长料倾倒隐患。

ROI：年收益约 21 万元，回收约 3 年。

---

# 七、实施过程

盘点分类 → 分区施工 → 重件区先行 → 转移货物，周期约 32 天。

难点：长料转运；解决：悬臂架侧装，行车配合，先装后移。

---

# 八、项目结果

- 三类货物分区存放，无互压现象
- 长料横放固定，安全隐患消除
- 库位提升约 95%

适用企业：重件、长料、散件并存的制造企业。
