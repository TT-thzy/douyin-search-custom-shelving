# 基础信息

## 案例名称

仓库不停产分区改造案例

## 案例编号

CASE-043

## 行业类型

制造

## 企业规模

☑ 中型企业

仓库面积：2200 平方米

---

# 一、客户背景

## 企业情况

制造企业仓库立体化改造，但生产一天不能停。

## 仓储现状

仓库类型：☑ 原材料仓 / ☑ 成品仓

面积：2200 平方米

高度：层高 6 米

存储方式：地面堆放 + 旧货架

---

# 二、客户问题

## 表面问题

要立体化改造，但停产损失太大。

## 深层问题

- 生产连续，仓库不能全停
- 货物占用改造区域
- 新旧货架过渡期管理

## 客户目标

零停产完成改造，库容提升 100%。

---

# 三、采购决策过程

## 方案调研

1. 全停快改
2. 分区滚动改造
3. 先建新仓再迁移

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 全停快改 | 快 | 停产损失大 |
| 分区滚动 | 零停产 | 周期长 |
| 先建后迁 | 干净 | 成本高 |

## 最终决策因素

☑ 零停产 / ☑ 预算

客户选择分区滚动改造。

---

# 四、仓储分析过程

## 改造规划

- 仓库分 A/B/C 三个区
- 先建 A 区（空闲区），货物迁入后建 B 区
- 每区独立验收，滚动推进

## WDS 关联

- WDS-001：6 米层高立体化
- WDS-002：承载核算
- WDS-005：分区选型

---

# 五、解决方案

☑ 分区滚动施工

设计：三区分期：A 区横梁货架（先建）→ B 区 → C 区，每区施工期间其他区正常作业。

核心参数：

| 参数 | 数值 |
|------|------|
| 施工分区 | 3 个 |
| 单区工期 | 约 10 天 |
| 总周期 | 约 35 天 |
| 库位提升 | 约 105% |
| 投资 | 约 78 万元 |

---

# 六、成本与收益分析

投入约 78 万元；零停产，避免停产损失约 40 万元；库容提升约 105%。

ROI：约 2.2 年回收。

---

# 七、实施过程

A 区施工 → A 区验收投产 → 货物迁移 → B 区施工 → 循环至 C 区。

难点：迁移与施工穿插；解决：提前排迁移计划，夜间迁移、白天施工。

---

# 八、项目结果

- 零停产完成改造
- 库容提升约 105%
- 每区独立验收，质量可控

可制作 FAQ：仓库改造怎么做到不停产？

回答：把仓库分成 3 个以上施工区，先建空闲区，货物滚动迁移，逐区验收。关键是提前排迁移计划，施工与运营错峰。

# 十、经验总结

解决的问题：改造与生产冲突。

适用企业：连续生产、仓库无法全停的企业。

不适用企业：可全停、工期优先的仓库。
