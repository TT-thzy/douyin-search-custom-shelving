# 一、客户背景

## 企业情况

企业主营业务：电子元器件制造

产品类型：连接器、线束组件、PCB 半成品

生产模式：原材料集中采购，多型号小批量生产

库存特点：

- 原材料以托盘为主（铜材、塑胶粒），单托 800～1200kg
- 半成品和成品 SKU 超过 300 个，批量小、型号杂
- 成品需防尘防静电包装

## 仓储现状

仓库类型：

☑ 原材料仓

☑ 半成品仓

☑ 成品仓

当前面积：1200 平方米

当前高度：层高 6.8 米（梁下净高 6.3 米）

当前存储方式：

- 原材料地面堆放
- 成品放在普通轻型货架上，只占一层
- 空间混乱，原材料和成品区相互干扰

# 二、客户问题

## 表面问题

仓库要重新规划，供应商给了横梁货架和阁楼货架两种方案，不知道选哪个。

## 深层问题

- 原材料（托盘重货）和成品（小件多 SKU）的存储逻辑完全不同
- 单一方案无法同时满足两类货物
- 选错方案会浪费空间或无法存取

## 客户目标

- 原材料托盘化存储，叉车高效作业
- 成品按型号分区，人工快速拣选
- 在 1200㎡ 内同时解决两类存储

---

# 三、采购决策过程

## 方案调研

客户收到两种方案：

1. 全部使用横梁式货架
2. 全部使用阁楼货架

## 方案比较

| 方案 | 优势 | 不足 | 适用情况 |
| ---- | ---- | ---- | -------- |
| 全横梁货架 | 托盘存取方便、通用 | 小件成品托盘化浪费空间 | 托盘货物为主 |
| 全阁楼货架 | 面积翻倍、拣选方便 | 重托上楼困难，叉车受限 | 轻小件为主 |
| 组合方案 | 各取所长 | 设计复杂、造价略高 | 混合存储需求 |

## 最终决策因素

客户最终关注：

☑ 使用面积

☑ 存取效率

☑ 投资合理性

客户最终选择组合方案：一楼横梁货架存原材料托盘（叉车作业），二楼阁楼货架存成品（人工拣选），两类货物各得其所。

---

# 四、仓储分析过程

## 现场评估

- **仓库高度**：层高 6.8 米，净高 6.3 米。一楼横梁货架 4 层高 3.2 米，二楼阁楼净高 2.8 米 → 满足（WDS-001）
- **承重**：原材料单托 1200kg，一楼横梁按 1500kg 设计；二楼轻件 400kg/㎡ → 满足（WDS-002）
- **消防**：二楼喷淋覆盖、疏散通道确认 → 满足（WDS-003）
- **地坪**：C30 混凝土，立柱荷载核算满足 → 满足（WDS-004）
- **货物特征**：托盘重货 + 小件多 SKU → 分区组合选型（WDS-005）

## WDS 关联

- WDS-001：6.3 米净高分区设计，上下两层净高分别满足作业需求
- WDS-002：一楼按重托核算、二楼按轻件核算，避免统一高荷载浪费
- WDS-003：二楼消防专项设计
- WDS-004：重载立柱地坪验证
- WDS-005：托盘区横梁式、拣选区阁楼式

# 五、解决方案

## 方案类型

☑ 横梁货架（一楼）

☑ 阁楼货架（二楼）

□ 阁楼平台

## 设计思路

一楼设 4 层横梁货架存放原材料托盘，叉车从主通道作业；二楼沿仓库一侧做阁楼货架存放成品，按型号分区，人工拣选后经滑道或电梯口下货。

## 核心参数

| 参数 | 数值 |
|------|------|
| 仓库面积 | 1200 ㎡ |
| 层高 | 6.8 米 |
| 一楼货架层数 | 4 层 |
| 二楼楼面 | 约 400 ㎡ |
| 库位数量 | 托盘位约 900 个 + 成品位约 3500 个 |
| 作业设备 | 叉车 + 人工拣选车 |

# 六、成本与收益分析

## 收益分析

改善后：

- 原材料叉车直达，成品人工快速拣选，互不干扰

## ROI 分析

# 七、实施过程

## 项目流程

需求确认 → 现场测量 → 分区设计 → 消防评审 → 生产 → 一楼安装 → 二楼楼面施工 → 成品区安装 → 库位编号 → 验收

## 实施难点

问题一：楼上楼下的消防和结构衔接。

解决方式：方案阶段统一设计，立柱布置避开消防通道，二楼喷淋与疏散一次到位。

问题二：施工期间原材料周转。

解决方式：先建一楼一侧，货架可用后立即上架，逐步腾挪，周期约 30 天。

# 十、经验总结

## 本案例解决的问题

一个既有托盘重货又有小件成品的电子元器件仓库，用"一楼横梁 + 二楼阁楼"组合方案，库位提升约 190%，两类货物互不干扰。

核心经验：横梁货架和阁楼货架不是"二选一"，混合存储仓库按货物特征分区组合，往往比单一方案更优。

## 适用企业

- 同时存在托盘重货和小件多 SKU 的仓库
- 层高 6 米以上、空间充足的企业

## 不适用企业

- 单一托盘货物仓库（全横梁即可）
- 单一轻小件仓库（全阁楼即可）
- 层高不足 5 米的仓库
