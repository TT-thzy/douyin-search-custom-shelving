# 一、客户背景

## 企业情况

第三方物流仓采购横梁货架 260 组，含安装。

## 仓储现状

仓库类型：☑ 第三方物流仓

面积：2000 平方米

高度：层高 7 米

新购：横梁货架 260 组（4 层）

---

# 二、客户问题

## 表面问题

安装质量怎么保障、工期怎么控制？

## 深层问题

- 安装人员资质参差
- 垂直度、水平度难监督
- 施工与运营交叉

## 客户目标

按期完成，安装质量一次达标。

---

# 三、采购决策过程

## 方案调研

1. 厂家自装
2. 第三方安装队
3. 厂家自装 + 监理抽检

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 厂家自装 | 责任清晰 | 质量凭自觉 |
| 第三方安装 | 便宜 | 责任分散 |
| 自装+监理 | 质量可控 | 增加监理费 |

## 最终决策因素

☑ 质量 / ☑ 责任

客户选择厂家自装 + 监理抽检。

---

# 四、仓储分析过程

## 管控要点

- 进场核对材料规格
- 安装过程抽检垂直度（≤3mm）
- 安全销逐层检查
- 每日施工日志
- 完工按清单验收

## WDS 关联

- WDS-002：规格与承载核对
- WDS-004：地坪安装条件确认

---

# 五、解决方案

☑ 分区安装 / ☑ 监理抽检

设计：按 A/B 区安装，先装 A 区验收后启用，再装 B 区，运营不停。

核心参数：

| 参数 | 数值 |
|------|------|
| 货架数量 | 260 组 |
| 安装周期 | 18 天 |
| 抽检比例 | 30% |
| 投资 | 约 68 万元（含安装） |

---

# 六、成本与收益分析

投入约 68 万元；监理费约 1.5 万元，避免返工估算节省 8 万元。

ROI：按库位投入使用收益估算约 2.5 年回收。

---

# 七、实施过程

进场核对 → A 区安装 → 抽检验收 → 启用 → B 区安装 → 总验收。

难点：施工与运营交叉；解决：分区施工、错峰作业、每日清场。

---

# 八、项目结果

- 18 天按期完成
- 抽检全部达标
- 运营未中断
