# 一、客户背景

## 企业情况

物流企业接手一个闲置旧仓库，预算有限，要求利旧改造。

## 仓储现状

仓库类型：☑ 第三方物流仓

面积：2500 平方米

高度：层高 4.8 米

现状：旧地面、旧照明、无货架

---

# 二、客户问题

## 表面问题

旧仓库怎么用最省钱？

## 深层问题

- 预算有限，不能大改
- 4.8 米层高不高，立体化空间有限
- 旧设施能用则用

## 客户目标

预算 30 万以内完成可用仓库改造。

---

# 三、采购决策过程

## 方案调研

1. 全新高标准改造
2. 利旧 + 局部新购
3. 直接地面堆放

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 高标准改造 | 一步到位 | 超预算 |
| 利旧+局部 | 预算内 | 标准略低 |
| 地面堆放 | 零投入 | 空间利用率低 |

## 最终决策因素

☑ 预算 / ☑ 快速可用

客户选择利旧 + 局部新购。

---

# 四、仓储分析过程

## 现场评估

- 旧地面局部找平即可
- 旧照明检修复用
- 4.8 米层高用 3 层横梁货架

## WDS 关联

- WDS-001：3 层布局匹配层高
- WDS-004：旧地坪评估找平
- WDS-005：二手+新购货架组合

---

# 五、解决方案

☑ 3 层横梁货架（部分利旧）

设计：旧地坪局部找平；照明检修复用；货架部分用集团旧架、部分新购。

核心参数：

| 参数 | 数值 |
|------|------|
| 货架层数 | 3 层 |
| 库位数量 | 约 4800 个 |
| 利旧比例 | 约 40% |
| 投资 | 约 28 万元 |

---

# 六、成本与收益分析

投入约 28 万元（预算内）；对比全新改造节省约 20 万元；库位满足初期业务。

ROI：按仓库投入使用后的仓储收入估算约 1.5 年回收。

---

# 七、实施过程

设施盘点 → 找平 → 利旧货架检修 → 新购货架安装 → 验收，周期约 20 天。

难点：利旧货架规格不统一；解决：按规格分类，同规格集中组装。

---

# 八、项目结果

- 预算内完成，仓库快速可用
- 利旧货架复检合格
- 为二期升级预留空间

# 十、经验总结

解决的问题：预算有限的旧仓快速启用。

适用企业：预算紧张、要求快速投入使用的企业。

不适用企业：长期高标准仓储需求。
