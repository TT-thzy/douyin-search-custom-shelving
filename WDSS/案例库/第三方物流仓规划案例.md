# 基础信息

第三方物流仓多客户分区规划案例

CASE-025

第三方物流

---

# 一、客户背景

## 企业情况

第三方物流仓储企业，服务 8 个客户，货物混合存储。

## 仓储现状

仓库类型：☑ 第三方物流仓

面积：3000 平方米

高度：层高 6 米

存储方式：客户货物混区，靠人工识别

---

# 二、客户问题

## 表面问题

货物串客户、盘点混乱、客户不满。

## 深层问题

- 客户区域无物理分区
- 托盘和纸箱货物混放
- 无库位系统，靠人工记忆

## 客户目标

按客户物理分区 + 库位编号，账实相符率提升。

---

# 三、采购决策过程

## 方案调研

1. 只做库位编号
2. 物理分区 + 库位编号
3. 上 WMS

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 只编号 | 快 | 串客户风险仍在 |
| 分区+编号 | 治本 | 需迁移 |
| 上 WMS | 全面 | 投入高 |

## 最终决策因素

☑ 账实相符 / ☑ 投入

客户选择"物理分区 + 库位编号"，WMS 二期再上。

---

# 四、仓储分析过程

## 现场评估

- 按客户面积占比分物理区
- 托盘客户与纸箱客户分库区
- 通道按叉车和拣货双需求设计

## WDS 关联

- WDS-001：6 米层高立体化
- WDS-002：托盘客户重载核算
- WDS-005：托盘横梁式、纸箱中型/阁楼式

---

# 五、解决方案

☑ 横梁货架 / ☑ 中型货架 / ☑ 库位编号

设计：8 个客户物理分区，托盘区横梁货架，纸箱区中型货架，全部库位编号。

核心参数：

| 参数 | 数值 |
|------|------|
| 客户分区 | 8 个 |
| 库位数量 | 约 9500 个 |
| 投资 | 约 85 万元 |

---

# 六、成本与收益分析

投入约 85 万元；账实相符率从 92% 提升至 99%+；客户续约率提升。

ROI：按避免赔偿和客户流失估算约 3 年回收。

---

# 七、实施过程

客户沟通 → 分区迁移 → 编号 → 盘点校准，周期约 35 天。

难点：迁移期间不能停收发货；解决：分批按客户迁移，错峰作业。

---

# 八、项目结果

- 客户物理隔离，串货归零
- 账实相符率 99%+
- 盘点时间缩短约 60%

# 十、经验总结

解决的问题：多客户串货、账实不符。

适用企业：多客户混合存储的第三方物流仓。

不适用企业：单一客户自用仓。
