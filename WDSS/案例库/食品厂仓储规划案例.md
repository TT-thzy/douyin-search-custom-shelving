# 食品厂仓储规划案例

版本：v0.1

状态：Active

# 基础信息

## 案例名称

食品厂仓库卫生与先进先出规划案例

## 案例编号

CASE-019

## 行业类型

食品制造

## 企业规模

☑ 中型企业

仓库面积：1400 平方米

---

# 一、客户背景

## 企业情况

休闲食品厂，成品有保质期要求（6～12 个月），SKU 约 300 个。

## 仓储现状

仓库类型：☑ 成品仓

面积：1400 平方米

高度：层高 5 米

存储方式：地面堆垛 + 普通货架，靠人工记效期

---

# 二、客户问题

## 表面问题

临期品积压、退货多，仓库鼠虫隐患。

## 深层问题

- 先进先出靠人工，做不到
- 货物落地存放，防虫难
- 批次无标识，过期难发现

## 客户目标

强制先进先出，货物离地，效期可查。

---

# 三、采购决策过程

## 方案调研

1. 普通货架 + 人工管理
2. 流利式货架（先进先出）
3. 阁楼货架 + 批次管理

## 方案比较

| 方案 | 优势 | 不足 |
| ---- | ---- | ---- |
| 普通货架 | 便宜 | FIFO 靠人 |
| 流利式 | 天然 FIFO | 造价略高 |
| 阁楼+批次 | 面积+管理 | 需配套制度 |

## 最终决策因素

☑ 效期管理 / ☑ 卫生 / ☑ 空间

客户选择"流利式 + 普通货架 + 批次制度"组合。

---

# 四、仓储分析过程

## 现场评估

- 纸箱小件，单箱 5～20kg，适合流利式
- 层高 5 米，可做两层阁楼放低频货
- 需留鼠虫防治空间（离地、留检距）

## WDS 关联

- WDS-003：食品仓库消防与分区
- WDS-005：流利式匹配纸箱小件 FIFO

---

# 五、解决方案

☑ 流利式货架 / ☑ 阁楼货架 / ☑ 批次管理

设计：高频品流利式货架 FIFO；低频品阁楼；批次号 + 效期标签管理；货物全部离地。

核心参数：

| 参数 | 数值 |
|------|------|
| 流利式滑道 | 80 条 |
| 阁楼楼面 | 约 300 ㎡ |
| 库位数量 | 约 6000 个 |
| 投资 | 约 52 万元 |

---

# 六、成本与收益分析

投入约 52 万元；临期报废减少约 60%，年省约 15 万元。

ROI：年收益约 18 万元，回收约 2.9 年。

---

# 七、实施过程

批次制度设计 → 货架安装 → 效期标签上线 → 培训 → 试运行，周期约 20 天。

难点：旧库存效期混乱；解决：先清临期品，再按批次重新上架。

---

# 八、项目结果

- 先进先出制度落地，临期报废减少约 60%
- 货物全部离地，鼠虫风险下降
- 批次效期可查，审核通过

# 十、经验总结

解决的问题：临期积压、鼠虫风险、效期不可控。

适用企业：有保质期要求的食品、日化企业。

不适用企业：无保质期要求的工业品仓库。
